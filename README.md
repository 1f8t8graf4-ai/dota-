# «Языки по кино» — мини-апп Telegram

Учим немецкий по сценам из фильмов и сериалов: смотришь кусок кино, разбираешь фразы, повторяешь, играешь (Deadlock-дуэли). Открывается из бота [@languagegamesbot](https://t.me/languagegamesbot) как Telegram Mini App. Ведёт Z.ai (GLM), хозяин проекта — Андрей, код-ревью делает Клауд (второй Claude).

## Как это устроено

- **index.html** — вход. Грузит шрифты (асинхронно), данные из `data/*.json` и код `js/app.js`. Версия релиза `V` стоит здесь.
- **js/app.js** — вся логика приложения (~4 800 строк): вкладки «Словарь · Сцены · Профиль», плеер сцен, разбор фраз, повторение, игры, админка. `APP_V` стоит здесь (строка ~992).
- **styles/** — 4 слоя: `main.css` (старый вид), `nd.css` («Новый» по макетам), `zai.css` (тема Z.ai), `znew.css` («Кино 2.0» — спокойный вид, включён по умолчанию).
- **data/** — `scenes.json` (сцены/эпизоды/фразы), `topics/scenewords/glossary/games.json`, сборка `all-data.js` через `tools/rebuild_all_data.py`.
- **bot/** — воркер на Cloudflare (`worker.js`): бот + раздача видео из R2 по `/m/…`. **Не трогаем без запроса Андрея.**
- **tools/** — скрипты: `r2_up.py` / `dd_r2_up.py` (заливка в R2), `hero_loop.sh` (бесшовный герой-луп), `rebuild_all_data.py`, `check_data.py`, промт-страница `dd-prompts.html`.
- **Видео/картинки** — Cloudflare R2 (бакет `kino-media`), раздаёт воркер. Ключ от R2 лежит **вне репо** в песочнице (`scripts/.cf-token`, формат: email + ключ на двух строках). В репо ключей нет и быть не должно.

  - шрифты грузятся асинхронно и не блокируют первый рендер, лишний Inter убран;
  - вход экрана — спокойный каскад 0,3 с, нажатия карточек отзываются — как в типовых приложениях.
