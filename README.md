# «Языки по кино» — мини-апп Telegram

Учим английский и немецкий по сценам из фильмов, сериалов и интервью: смотришь кусок кино, разбираешь фразы, повторяешь, играешь (Deadlock-дуэли). Открывается из бота [@languagegamesbot](https://t.me/languagegamesbot) как Telegram Mini App. Код пишут Z.ai / Z Code (GLM) и Claude, хозяин проекта — Андрей.

**ИИ-агенту (Z Code, Claude и любому другому): начинать с [`README-ZCODE.md`](README-ZCODE.md)** — карта репо, правила, проверка, форма отчёта. Свежее состояние за день — в файле `z.ai`.

## Как это устроено

- **index.html** — вход. Грузит шрифты (асинхронно), данные из `data/*.json` и код `js/app.js`. Версия релиза `V` стоит здесь.
- **js/app.js** — вся логика приложения (~4 800 строк): вкладки «Словарь · Сцены · Профиль», плеер сцен, разбор фраз, повторение, игры, админка. `APP_V` стоит здесь (строка ~992).
- **styles/** — 4 слоя: `main.css` (старый вид), `nd.css` («Новый» по макетам), `zai.css` (тема Z.ai), `znew.css` («Кино 2.0» — спокойный вид, включён по умолчанию).
- **data/** — `scenes.json` (сцены/эпизоды/фразы), `topics/scenewords/glossary/games.json`, сборка `all-data.js` через `tools/rebuild_all_data.py`.
- **bot/** — воркер на Cloudflare (`worker.js`): бот + раздача видео из R2 по `/m/…`. **Не трогаем без запроса Андрея.**
- **tools/** — скрипты: `r2_up.py` / `dd_r2_up.py` (заливка в R2), `hero_loop.sh` (бесшовный герой-луп), `rebuild_all_data.py`, `check_data.py`, промт-страница `dd-prompts.html`.
- **Видео/картинки** — Cloudflare R2 (бакет `kino-media`), раздаёт воркер. Ключ от R2 лежит **вне репо** в песочнице (`scripts/.cf-token`, формат: email + ключ на двух строках). В репо ключей нет и быть не должно.

- **13.9.64** — войс реальных реплик Deadlock:

## Впредь — правила процесса (закреплено)

1. **Версия — в трёх местах одновременно**: `APP_V` в `js/app.js`, `var V` в `index.html`, `version.txt`; запись в журнал `CLAUDE.md`. Пустой `version.txt` = брак (был в 13.9.56/57).
2. **Русский язык, короткие ответы** — в чате с Андреем.
3. **Никакой самодеятельности**: механику (резка, задания, экраны) не меняю без прямого запроса Андрея.
4. **Анимации — только transform/opacity, без backdrop-filter** (правило 13.9.23); бесконечные эффекты — нельзя.
5. **Перед пушем — смоук-тест**: `node --check js/app.js` + Playwright 390×844 и 1440×900, консоль чистая (по протоколу Клауда). Скрипт — `scripts/test_*.py`.
6. **main = только проверенное.** GitHub Pages раздаёт main — если нужно, чтобы Андрей увидел изменение, после смоука пушу и в main (и пишу об этом прямо).
7. **Ключи — никогда в репо.** R2-ключ живёт в `scripts/.cf-token` вне репо (chmod 600).
8. **bot/worker.js и BotFather** — не трогаю без запроса.
