# Дота: языки

Telegram-бот и мини-приложение для изучения **английского или немецкого через то, что человек и так любит: игры, фильмы и сериалы**. Название бренда пока не выбрано (бот пока называется «Дота: языки»). Миры: **Dota 2** (предметы, умения, имена героев, полезные слова, фразы, лор), **CS 2** (слова из раунда), **Сцены** (эпизоды из фильмов и сериалов с субтитрами и разбором фраз) и **«Солянка»** (лучшие слова из игр). Слово доводится до «выучено» (3 правильных ответа), потом повторяется по дням. Вокруг — игры с друзьями: дуэли, «Шпион», турнир недели.

Интерфейс на русском. Учится один язык на выбор: английский или немецкий. Аудитория: русскоязычные игроки и зрители, в том числе живущие в Германии.

**Текущая версия: 4.6.1** (приложение и бот 4.6).

## Для ИИ, который продолжает проект: прочитай сначала

1. **Не переписывай с нуля.** Все изменения — правками поверх текущих `js/app.js`, `styles/main.css`, `data/*.json` и `worker.js`. Одна из прошлых версий («3.5» из другого чата) была написана заново и сломала всё: кнопка «Дальше» вызывала несуществующую функцию, пропали режимы, словарь, лор и прогресс. Её пришлось откатывать.
2. **Автор не программист.** Отвечай по-русски, коротко и по делу. Инструкции — по шагам и по кнопкам. Код отдавай **целыми файлами**, а не кусками для вставки.
3. **Имена файлов с версией.** Выдавай `worker-3.2.js`, а не `worker.js`: у автора в «Загрузках» копятся одинаковые файлы, и однажды он залил старую версию. Первая строка worker.js и текст на главной воркера содержат номер версии — по ним автор проверяет, что залилось.
4. Код копируется через Блокнот, иначе в него попадают невидимые символы.
5. **Не меняй ключи хранилища** (`dota_quiz_v4`, `dota_m_v1`, `dota_r_v1`, `dota_sc_v1`) и `id` слов и сцен без миграции: пропадёт прогресс игроков.
6. **Приложение разбито на файлы (с 4.3):** `index.html` — только разметка и загрузчик (2 КБ), `styles/main.css` — стили, `js/app.js` — вся логика, `data/*.json` — только данные без функций. Загрузчик в `index.html` скачивает JSON в `window.__DATA`, затем подключает `js/app.js` (там `const TERMS=window.__DATA.TERMS` и т. д.). Правь логику в `js/app.js`, слова и сноски — в `data/*.json`, при выпуске поднимай версию `V` в загрузчике (сбрасывает кэш). Внешние зависимости: `telegram-web-app.js`, Google Fonts, CDN Valve для иконок, видео сцен по `window.ASSET_BASE`. Больше ничего не подключай.
7. Иконки только с CDN Valve, ключи сверяй с `odota/dotaconstants` (`build/items.json`, `build/abilities.json`, `build/heroes.json`, `build/hero_abilities.json`).
8. Перед выдачей проверяй (см. «Как тестировали»): все вопросы генерируются без `undefined`, у каждого 4 разных варианта и есть правильный, сессия доходит до итогов, онлайн-режимы работают с несколькими игроками.
9. Принятые решения, которые не надо переигрывать: **нет ставок на деньги между игроками** (вместо них турнир с призом от организатора), **нет админки и промокодов на стороне клиента**, **нет дотерского сленга в учебных материалах**.

## Архитектура

Четыре части:

1. **Приложение на GitHub Pages** (репозиторий `dota-`): `index.html` (разметка, адрес видео `window.ASSET_BASE`, загрузчик), `styles/main.css`, `js/app.js`, `data/` — `icons.json` (ICONS, ITEM_IMG), `dota.json` (TERMS, ITEMS, BUILDS, SKILLS, HEROES, HERO_POS), `words.json` (WORDS, PHRASES; слова CS 2 добавляются в WORDS из кода с меткой `g:'cs2'`), `lore-vocab.json`, `tips.json` (TIPS), `spy.json`, `scenes.json` (сцены: части, реплики `[начало, конец, en, ru, de]`, фразы).
4. **Видео сцен** — отдельный репозиторий `scenes` (GitHub Pages), ключи `scenes/<id>/<NN>.mp4|jpg`, `scenes/<id>/cover.jpg`. Отдельно, чтобы жалоба на видео не задела приложение. Адрес строит только `assetUrl(key)`; переезд в Cloudflare R2 или другое S3 — `docs/object-storage.md` и `scripts/migrate-assets.mjs` в том репозитории, в приложении меняется одна строка `ASSET_BASE`.
2. **`lore.json`** (~390 КБ) — официальный лор предметов и умений на en/ru/de, 782 текста. Собирает `tools/build-lore.mjs` из файлов локализации игры (зеркало `dotabuff/d2vpkr`) и оставляет только то, что есть в игре сейчас: предметы из лавки и актуальные нейтральные, умения из текущих списков героев (по `odota/dotaconstants`). У каждого умения записан герой. Запускается GitHub Action «Обновить лор из игры» (`.github/workflows/main.yml`): вручную и каждый понедельник.
3. **`bot/worker.js`** — Cloudflare Worker: бот (webhook) и API для мини-аппа. Код вставляется в Cloudflare вручную.

**База D1** подключена к воркеру под именем `DB`. Таблицы создаются сами: `spyg` (комнаты «Шпиона»), `tour` (турнир недели). Таблица `spy` осталась от версии 2.3 и не используется.

**Переменные воркера:** `BOT_TOKEN`, `APP_URL`, `WEBHOOK_SECRET`. Необязательные: `APP_LINK`, `BOT_USERNAME`, `ADMIN_ID` (Telegram ID организатора турнира, узнаётся командой `/myid`), `TOUR_PRIZE` (текст приза).

**Эндпоинты воркера:**
- `/webhook` — апдейты Telegram (проверка `X-Telegram-Bot-Api-Secret-Token`).
- `/setup?secret=…` — ставит вебхук, команды, кнопку меню, описание, создаёт таблицы. В ответе `spyDatabase` должно быть `ok`.
- `POST /api/spy`, `POST /api/tour` — API мини-аппа. Заголовок `x-init-data` = `Telegram.WebApp.initData`, воркер проверяет подпись (HMAC-SHA256 от токена бота) и берёт пользователя оттуда. CORS открыт. Адрес API зашит в `index.html` в константе `API`.

### Карта `js/app.js`

Скрипт разбит комментариями `/* ================= раздел ================= */` в таком порядке: иконки → данные (основы, предметы, скиллы, имена героев, полезные слова, фразы, слова для лора) → режимы, роли, языки, ранги → хранилище → Telegram → звук → утилиты → эффекты → иконки/слоты → прогресс слов → лор (включая `HERO_POS`) → генераторы вопросов (`BUILD`) → дуэль → сессия (таймер, ответы, `finish`) → озвучка → сноски `TIPS` и новые задания (`newQ`, `extraKinds`, `buildAny`, повторение `RV`, цель дня) → итоги → вкладки (`renderTab`: Учить, Шпион, Арена, Профиль, достижения `ACH`, заставка `splash`, отсчёт `countdown`) → словарь → выбор языка и ролей → онбординг (квиз: как учить, язык, игры, роль) → настройки → шпион → турнир → сцены (`renderScene`, `renderScEp`, `renderScQuiz`) → CS 2 (`CS2_WORDS`, `BEST_WORDS`) → миры (`setWorld`, `learnTabHTML`, `renderDotaWorld`, `renderCSWorld`, карточка нового слова `renderIntro`, словарь `renderWiki`) → старт (разбор `startapp`).

Параметры запуска (`startapp`): `d_…` — дуэль, `spy_КОД` — комната шпиона, `tour` — турнир, `en`/`de` — язык при первом запуске.

### Режимы обучения

| Режим | Что учит | Объём |
|---|---|---|
| Основы | Базовые слова игры: урон, броня, опыт, победа. Есть «соедини пары» | 28 слов |
| Предметы | Слово из названия (Bottle → бутылка → die Flasche), сборка составных названий из кусочков | 24 слова + 14 составных |
| Умения | Что значат названия умений, слово из названия | 63 умения (все 4 у Disruptor) |
| Имена героев | Слово из имени: Witch Doctor → witch → ведьма → die Hexe | 64 слова |
| Полезные слова | Глаголы, прилагательные, существительные с подсказкой из Доты | 83 слова |
| Фразы | Нормальные фразы для общения, без сленга | 32 фразы |
| **Лор (хай тир)** | Слова в контексте настоящих текстов из игры | 224 слова, 782 текста |

- **Быстрая игра** — 10 вопросов из всех обычных режимов, последний — «Рошан» с двойным золотом.
- **Роли** (керри, мид, оффлейн, саппорт; 1–2 или все) фильтруют предметы, умения, героев и лор. Для лора у каждого из 127 героев в `HERO_POS` записаны позиции.
- **Язык:** английский или немецкий (один на выбор, с 4.2). Для немецкого — вопросы на артикли с подсказками-правилами.
- **Типы вопросов:** перевод в обе стороны, артикль, сборка названия, соедини пары, слово в контексте, пропуск в тексте, угадай предмет по описанию. С 4.0 ещё: ввод с клавиатуры (`type`, только для слов, которые уже встречались), аудирование (`listen`, голос телефона), пропуск в живом предложении (`fill`), угадай предмет по иконке (`icon`), в имени какого героя это слово (`hero`), ситуация → фраза (`situ`), собери фразу из слов (`order`).
- **Сноски к каждому переводу** (объект `TIPS`, 532 записи, проверено, что есть у каждого слова): «Как запомнить» (мнемоника, ложные друзья, родственные слова) и «В жизни» — живой пример на английском и немецком с переводом. У фраз — «Когда говорить» и «Ещё можно сказать», у слов лора — живое словосочетание. Показываются после каждого ответа. Формат: `[как запомнить, пример EN, пример DE, перевод]` или 5 элементов, если переводы примеров разные.

### Как устроено обучение

- **Прогресс слова:** правильный ответ +1, ошибка −1, максимум 3. На 3 — «Слово выучено». Ключ: `режим|id|язык` (английский и немецкий учатся отдельно).
- **«Убирать выученные слова»** (по умолчанию включено): выученные больше не попадаются в обычных играх.
- **Повторение по дням** (4.0): выученное слово возвращается на проверку через 3, 7, 21 и 60 дней (карточка «Повторение» на вкладке «Учить»). Ошибка на повторении возвращает слово в изучение. Хранится в `dota_r_v1`: `{ ключ: [этап, когда повторять] }`.
- **Повтор ошибки в той же игре** (4.0): неверно отвеченное слово ещё раз спрашивается перед Рошаном, другим типом вопроса (до 3 за игру; не в дуэлях).
- **Цель дня** (4.0): 10/20/30 ответов в день (настройка), за выполнение +200 золота.
- **Автопереход** после верного ответа выключен по умолчанию, чтобы спокойно прочитать сноску (включается в настройках).
- **Словарь:** вкладки «Изучаю» и «Выучено», кнопка «Вернуть».
- **Ошибки:** каждая ошибка сохраняется как вопрос, их можно прорешать отдельно.
- **Ранги** по числу выученных слов: Рекрут 0, Страж 10, Рыцарь 25, Герой 50, Легенда 80, Властелин 120, Божество 170, Титан 230. Множитель золота x1–x2. Нажатие на ранг открывает объяснение.
- **Игровая обёртка:** таймер-полоска маны, золото (быстрый ответ и серия дают больше), First Blood, Double Kill и дальше, «Победа Сил Света / Тьмы».
- **Озвучка:** голос телефона (Web Speech API). С 4.4.1 выключена по умолчанию (звучит как робот), включается в настройках (`store.tts`); без неё нет кнопок «послушать» и заданий на слух. План: заранее записанные mp3 нейроголосом.
- **Слово дня** — одно и то же в приложении и в боте.
- **Полезные слова:** в вопросе «как это по-английски» сразу видна связь с Дотой («Phase Boots помогают бегать быстрее»), чтобы иконка предмета не путала. В плашке указана часть речи.
- **Умения:** после ответа показывается строка лора этого умения из игры.

### Лор (хай тир)

Учатся обычные полезные слова (сила, душа, древний, ковать…), а лор — контекст. Для каждого слова заданы формы на английском и немецком, приложение само находит их в текстах. Три задания: слово в контексте, пропуск, угадай предмет или умение по описанию (название в тексте закрыто). После ответа — официальный русский перевод всего текста. Варианты ответа одной части речи и не синонимы.

### Дуэли

С 4.0: отсчёт 3-2-1 перед началом, история дуэлей на вкладке «Арена» (с результатом соперника, когда он прислал ссылку), кнопка «Реванш». Без сервера. Вопросы строятся детерминированно из seed, поэтому у всех одинаковые, независимо от настроек. Ссылка: `…?startapp=d_<seed base36>_<en|de>`, после игры к ней дописывается результат `_<верно>_<секунд>_<имя base64url>`. Друг открывает ссылку, играет те же вопросы и видит сравнение. `/duel` в боте присылает кнопку вызова.

### «Шпион»

127 героев, 130 предметов и 63 умения (категория «Умения» с 4.0). Все, кроме шпиона, видят загаданное.
- **За одним телефоном:** 3–12 игроков, можно вписать имена, телефон передаётся по кругу, таймер 5/8/10 минут.
- **По ссылке:** комната с кодом из 5 символов, у каждого своя роль на своём телефоне. Хозяин настраивает и начинает раунды. Состояние в D1, изменения с проверкой версии (одновременные нажатия не теряются), приложение опрашивает сервер раз в 2 секунды. Шпиону не отдаётся загаданное, мирным — кто шпион. Имена — полное имя из Telegram.
- **Ходы:** видно, кто спрашивает; он выбирает, кого спросить; тот отвечает и ходит следующим; спросить в ответ нельзя. «Подсказать вопрос» даёт пример.
- **С 4.0 онлайн:** общий таймер раунда 5/8/10 минут (сервер хранит `endAt`, клиент учитывает разницу часов), хозяин может убрать игрока между раундами (`kick`), очки за раунды (мирные +1 каждому за пойманного шпиона, шпион +2 за победу), таблица счёта после раунда, анимация переворота карточки роли, звук смены хода.
- **Конец раунда:** голосование (большинство за шпиона — победа мирных) или шпион раскрывается и угадывает из 8 вариантов.
- Языковой режим «вопросы только по-английски / по-немецки».

### Турнир недели (приз чеком)

С 4.0: отсчёт 3-2-1 до старта попытки (до запуска серверного таймера), у каждого игрока свой порядок вариантов (перестановка по `hash(неделя|язык|игрок|вопрос)`, «ответ Б» подсказать нельзя), победители прошлой недели, кнопка «Поделиться». Бесплатный, 10 вопросов по словам из бота, 15 секунд на вопрос, одна попытка в неделю на язык (en и de — разные таблицы). Вопросы генерирует и проверяет **только сервер**: клиент не знает правильный ответ, время считает сервер, опоздание = ошибка. Приз: организатор создаёт чек в @CryptoBot и пишет боту `/prize МЕСТО ССЫЛКА` (плюс `de`, `last`), бот отправляет ссылку победителю в личку. `/tour` показывает таблицу.

### Бот

`/start`, `/quiz [en|de]` (нативный Telegram-квиз), `/duel [en|de]`, `/spy [items|mix|en|de]`, `/tour [de] [last]`, `/prize`, `/word`, `/myid`, `/help`. Работает в группах (реагирует только на команды).

### Оформление

С 4.0 приложение построено на **нижних вкладках** (с 4.3 их пять):
- **Учить** (нейтральная тема): шапка, цель дня, «Солянка», «Повторение», карточки миров Dota 2 и CS 2, сцены, слово дня, ошибки. Порядок зависит от ответа в квизе (`store.path`). Внутри мира Доты — прежний экран: «Быстрая игра», режимы, словарь, лор.
- **Сцены:** фильмы и сериалы.
- **Шпион:** выбор режима (за одним телефоном / по ссылке) и правила.
- **Арена:** дуэль, турнир недели, история дуэлей.
- **Профиль:** ранг и прогресс до следующего, статистика (выучено, точность, дни подряд, золото, ответы, лучшая серия), 15 достижений (`ACH`, всплывают при получении), словарь, повторение, ошибки, настройки.

Анимации: заставка при запуске (дуги Сил Света и Тьмы, руна, буквы названия; по нажатию пропускается), живой фон из медленных цветных пятен, скольжение вкладок и индикатора, появление карточек по очереди, заполнение полос и кольца цели, отсчёт 3-2-1. Всё отключается настройкой «Анимации и эффекты».

Тема зависит от мира (с 4.3, выбора темы в настройках больше нет): нейтральная тёмная с фиолетовым акцентом (`t-clean`) на главной и в общих экранах, дотерская (`t-hud`, тёмная с золотом, вопросы как тултип предмета) внутри Доты, сталь и оранжевый (`t-clean t-cs`) в CS 2, у сцен свои (`noir` — «Сопрано», `bone` — «Психопат»). Переключает `setWorld()`. Шрифты: Golos Text, Alegreya SC (Дота), Playfair Display, Cormorant Garamond, Inter (сцены). Звуки синтезируются Web Audio API, мягкие короткие тоны.

### Хранилище

`localStorage` + Telegram CloudStorage:
- `dota_quiz_v4` — настройки и статистика (языки, роли, золото, серия дней, ошибки, `hideLearned`, `theme`, `tab`, `auto`, `goal`, `day`, `ach`, статистика `games`/`bestStreak`/`perfect`/`spyRounds`/`tourPlayed`/`goalsDone`/`reviews`, звук, эффекты, `duels`, `spy`, `tourLang`). Мигрирует со старого `dota_deutsch_v3`.
- `dota_m_v1` — прогресс слов `{ "режим|id|язык": 0..3 }`. В CloudStorage режется на куски `dota_m_v1_0…` и счётчик `dota_m_v1_n` (лимит 4096 символов на ключ), при загрузке берётся максимум.
- `dota_r_v1` (4.0) — повторение по дням, в CloudStorage тоже кусками.

### Правила контента

Полезные слова и нормальный язык, без сленга (GG, фарм, катка, ульта). Немецкие существительные с артиклем. Немецкие названия умений — дословный перевод, об этом есть пометка. Ложные друзья отмечаются (Gift по-немецки — яд). Лор — только контекст, а не ответ.

## Как обновлять (для автора)

- **Приложение:** GitHub → `dota-` → Add file → Upload files → перетащить `index.html`, `lore.json`, `README.md` и папки `styles`, `js`, `data` целиком → Commit changes. Через 1–2 минуты полностью закрыть и открыть мини-апп.
- **Видео сцен:** GitHub → `scenes` → Upload files → папка `scenes` (и при необходимости `scripts`, `docs`, `manifest`) → Commit.
- **Лор:** Actions → «Обновить лор из игры» → Run workflow.
- **Бот:** Cloudflare → Workers → `dota` → Edit code → Ctrl+A, удалить, вставить новый код → Deploy. Проверить версию на главной воркера, потом открыть `/setup?secret=…`.
- **Переменные:** Cloudflare → `dota` → Settings → Variables and Secrets.
- **База:** Storage & databases → D1 → `dota-spy`, привязана к воркеру как `DB` (Settings → Bindings).

## Что пробовали и не взяли

- **Ставки на крипту между игроками.** Выигрывает тот, у кого открыт переводчик, а приём чужих денег на кон — это азартные игры и хранение чужих средств, для этого нужны лицензии. Вместо этого — турнир с призом от организатора.
- **Промокоды и админка в клиенте.** Всё хранится на телефоне игрока: промокоды видны в коде, `?admin=1` открывал админку любому.
- **Хранение игр в памяти воркера.** Память Cloudflare Worker не сохраняется между запросами. Для общих данных — только D1.
- **Лор целыми предложениями как ответ** и имена собственные в вариантах — учить там нечего.

## Известные ограничения

- В обычных режимах и дуэлях очки считает телефон игрока, результат дуэли зашит в ссылку — подделать можно. Для игры с друзьями это нормально; на сервере проверяется только турнир.
- В турнире слова одинаковые у всех на неделе (порядок вариантов у каждого свой). От переводчика защиты нет, только таймер 15 секунд.
- В «Шпионе» по ссылке игрок, закрывший приложение в лобби, остаётся в списке, пока хозяин его не уберёт. Комнаты живут 24 часа.
- Аудирование есть только при включённой озвучке и там, где у телефона есть голос для языка; в дуэлях аудирования и ввода нет (у всех должны быть одинаковые вопросы).
- В сносках «Как запомнить» иногда упоминается второй язык (например, немецкое слово в английском вопросе) — это сделано специально, но может быть непривычно.
- `HERO_POS` и список предметов «Шпиона» ведутся вручную, после патчей Доты их надо проверять.
- Предметы в лоре не фильтруются по роли.
- Озвучка зависит от телефона: на некоторых Android её нет.
- Картинки грузятся с CDN Valve; если он недоступен, показываются запасные значки.
- Турнирные вопросы берутся только из словаря бота (179 слов и фраз), без лора и предметов.

## План на 5.0

Главная мысль: до 5.0 нужно понять, как люди реально пользуются 4.0. Пока все фичи добавлялись наугад. Поэтому первым идёт статистика, потом то, что возвращает игроков, и только потом новый контент. Порядок — по убыванию пользы.

### Шаг 0. Перед разработкой
Дать 4.0 друзьям на неделю и собрать отзывы: что понравилось, что бесит, где непонятно. Это ценнее любого списка идей.

### 1. Статистика использования
- **Зачем:** без цифр непонятно, что улучшать.
- **Что считать:** сколько человек зашло за день и неделю, какие режимы запускают, на каком вопросе бросают игру, сколько вернулось на следующий день и через неделю.
- **Как сделать:** анонимные счётчики в D1 (таблица `stats`: день, событие, число), приложение шлёт события через `POST /api/stat` с проверкой `initData`. ID пользователя хранить только хешем. Команда `/stats` в боте показывает сводку организатору (`ADMIN_ID`).

### 2. Напоминания от бота
- **Зачем:** главный способ, чтобы люди возвращались.
- **Что:** вечером бот пишет «Серия 5 дней сгорит, ответь на 10 вопросов» с кнопкой «Играть».
- **Как сделать:** при `/start` и при открытии мини-аппа сохранять `chat_id`, серию и дату последней игры в D1. Cron Trigger воркера раз в день рассылает тем, у кого серия под угрозой. Обязательно кнопки «Не напоминать» и «Напоминать в другое время», иначе бота будут блокировать. Учитывать лимиты Telegram на рассылку (около 30 сообщений в секунду).

### 3. Рейтинг в групповом чате
- **Зачем:** дотеры соревнуются. Рейтинг в чате — бесплатная реклама: люди видят бота и заходят сами.
- **Что:** бот раз в неделю публикует в группе «Топ недели: Вася 120 слов, Петя 95». Плюс команда `/top`.
- **Как сделать:** приложение отправляет на сервер число выученных за неделю слов (с `initData`). Связь «игрок — группа» — когда игрок открыл мини-апп по кнопке из группы или написал `/top` в группе. Подделать клиентские очки можно, для дружеского рейтинга это приемлемо.

### 4. Режим «Немецкий для жизни в Германии»
- **Зачем:** большая часть аудитории живёт в Германии. Приложение станет полезным не только «про игру».
- **Что:** фразы и слова для врача, ведомств (Ausländerbehörde, Jobcenter, Bürgeramt), аренды, работы и собеседования на Ausbildung. Подача в стиле Доты: темы как «квесты», итоговая проверка как «босс».
- **Как сделать:** новый режим в `MODES` со своим словарём и сносками `TIPS` в том же формате. Только немецкий (английский по желанию). Все тексты проверять особенно тщательно.

### 5. Произношение
- **Что:** говоришь слово в микрофон, телефон распознаёт, правильно ли.
- **Как сделать:** Web Speech Recognition (`SpeechRecognition` / `webkitSpeechRecognition`) с языком `en-US` / `de-DE`. Работает не везде: где нет поддержки, кнопку не показывать. В дуэлях не использовать.

### 6. Порядок в коде
- **Сделано в 4.3:** код, стили и данные разнесены по файлам (см. «Архитектура»). **Осталось:** автотесты в репозитории и GitHub Action, который прогоняет их перед публикацией.
- **Зачем:** index.html уже около 350 КБ, каждая новая нейронка рискует что-то сломать (как было с «3.5»).
- **Что:** разбить код на файлы (данные, сноски, движок вопросов, вкладки, шпион, турнир) со сборкой в один index.html через GitHub Action. Положить автотесты в репозиторий (jsdom и SQLite вместо D1, см. «Как тестировали») и запускать их в Action перед публикацией: сломанная версия не должна попасть на сайт.
- Со временем — работа через Claude Code или git, чтобы не загружать файлы вручную.

### Ещё идеи (после главного)
- **Повторение в быстрой игре:** подмешивать 1–2 слова из `dueList()`.
- **Турнир:** автоматическая выплата приза через Crypto Pay API (`transfer` или `createCheck`, нужен токен приложения CryptoBot), вопросы из лора и предметов, архив прошлых недель.
- **«Шпион»:** свои наборы слов, автоматический выход игроков, которые давно не заходили.
- **Колесо чата:** официальные фразы колеса чата из файлов локализации игры с официальными переводами.
- **Inline-режим бота:** `@languagegamesbot слово` в любом чате — карточка слова со сноской.
- **Статистика для игрока:** график выученных слов и точности по дням в профиле.
- **Больше достижений** и награды за них (рамки аватара, темы).
- **Интерфейс на украинском или английском.**

### Чего не делать
- **Ставок на деньги между игроками** (почему — в «Что пробовали и не взяли»).
- **Магазина за реальные деньги**, пока нет статистики и постоянных игроков.
- **Новых мини-игр**, пока не ясно, играют ли в «Шпиона», дуэли и турнир. Сначала статистика.
- **Переписывания с нуля.** Только правки поверх текущего кода.

## Как тестировали

Всё прогоняется автотестами в Node перед каждой выдачей:
- **jsdom** загружает `index.html` и проходит онбординг, все режимы, все типы вопросов (генерируется ~4000 обычных и ~2300 лор-вопросов, проверяется, что нет `undefined`, у каждого 4 разных варианта и есть правильный), словарь, ошибки, настройки, сброс, миграцию со старых версий.
- **Дуэли:** одинаковый seed на двух «телефонах» с разными настройками даёт одинаковые вопросы, сравнение результатов, ссылки не длиннее 64 символов.
- **Онлайн-«Шпион» и турнир:** несколько jsdom-«телефонов» с настоящей подписанной `initData` ходят в `worker.js` напрямую, вместо D1 — настоящий SQLite (`node --experimental-sqlite`). Проверяется, что шпион ровно один, загаданное не утекает, одновременные нажатия не теряются, поддельная подпись отклоняется, в турнире нет правильного ответа в ответе сервера, вторая попытка и опоздание не засчитываются.
- **Бот:** 3000 сгенерированных квизов проверяются на лимиты Telegram (вопрос ≤300, вариант ≤100, пояснение ≤200 символов).
- **Внешний вид:** скриншоты всех экранов через Playwright в размере телефона.
