# Ссылки YouTube — на будущее (версия для App Store / Google Play)

Зачем: в версии для сторов видео не храним у себя, а встраиваем официальный клип с YouTube.
Наши субтитры и задания — под плеером. В Телеге (РУ) остаются наши файлы, как сейчас.

Правила для ссылки:
1. Только **официальный канал** (студия, Movieclips, HBO, сам подкаст) — не перезалив. Перезаливы удаляют, и это не легально.
2. Проверка встраивания: открой `https://www.youtube.com/embed/<код видео>` — если играет, годится. Если пишет «видео недоступно» — встраивание запрещено, ищи другой.
3. Клип может быть длиннее нашей сцены — не страшно, тайминги подгоню сам.
