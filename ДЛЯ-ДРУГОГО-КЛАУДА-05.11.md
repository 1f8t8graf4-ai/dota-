### Что на сайте есть
- **Профиль** как League of Graphs: ранг, «Что знать» (метки), «Часто играет» (30 дн / 3 мес / всё), последние игры с оценкой S+…D−, место на герое (мир + регион), коуч.

## 3. Мод Restless (в игре)
### Как устроен
- Скрипт `mod/restless-probe/panorama/scripts/restless.js`. Подключён к копиям игровых layout: `citadel_hud_subtitles.xml`, `hud_movement_speed.xml`, `hud_escape_menu.xml`, `dashboard.xml`, `popups/popup_join_or_create_party.xml`, `unit_status_overlay_v2.xml`.
- Работает одна копия скрипта («владелец»). Настройки — атрибутами корня `RESTLESS_<ключ>`, память между запусками — через `restless/store.html`.
- Окно настроек: Esc → **RESTLESS**. Наборы Lite / Medium / Enchanted. Внизу «Что видит мод» — диагностика, по ней чиним.
- **GlobalClassListener ставит класс своему РОДИТЕЛЮ**: `gDetailView` = зажат Alt, `gShopOpen`, `gScoreboardOpen`, `gInCombat`.

### Сборка и тесты (без Valve-инструментов)
```
S=<скретчпад>
$S/s2/s2bin compile mod/restless-probe $S/b/v1.vpk citadel_addons/restless_probe   # компилятор — Modlock (MIT), обёртка mod/tools/s2cli.go
python3 mod/tools/vpk2.py $S/b/v1.vpk pak42_dir.vpk                                 # перепаковка в VPK v2
cp pak42_dir.vpk mod/build/ && cp pak42_dir.vpk restless/app/                       # программа 0.4.5+ сама качает мод с сайта
node mod/tools/mock_panorama.js mod/restless-probe/panorama <датамайн>/panorama/layout/hud_escape_menu.xml   # заглушка Panorama, 216 PASS
```
- Датамайн игры — `SteamDatabase/GameTracking-Deadlock` (из облака доступен через raw.githubusercontent.com).
- `s2bin` в скретчпаде пропадает с сессией. Собрать заново — из `mod/tools/s2cli.go` (пакеты `source2/*` Modlock, коммит `5198246`).

## 7. Грабли
- `splice.py` применять только к базе из `c03b648` — к уже собранному файлу правки не лягут.
- Классы `.it`, `.q-hl`, `.hm`, `.rk`, `.me`, `.bd`, `.nm` заняты базой — новые классы только с префиксом своего слоя.
- `MutationObserver`, который сам меняет атрибуты в наблюдаемом дереве, зацикливается — фильтровать свои изменения.
- В моде — никаких вечных `CitadelHTMLPanel` в матче: только открыл → прочитал → закрыл.
- `FindChildTraverse` ищет по id. Класс от `GlobalClassListener` — у родителя слушателя.
- Мод не может делать сетевые запросы. Данные из сети — картинкой (`Image.SetImage(url)`) или заголовком страницы скрытого браузера (`HTMLTitle`).
- Песочница игры ≠ живой матч: многое (метки лагерей, полосы над героями) ведёт себя по-разному. Не обещать, что работает, пока Андрей не проверил в матче.
