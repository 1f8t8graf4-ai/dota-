## 1. Субтитры реплик героев (captions)

**Где лежат.** Тексты ВСЕХ реплик — в одном файле локализации:

```
game/citadel/resource/localization/citadel_generated_vo/citadel_generated_vo_english.txt
```

- Формат — стандартный Valve-словарь: `"atlas_use_power4_01_ult_3d"  "No one's taking the tome from me…"`. Сейчас в файле **78 453 строки** (реплики героев + реплики патрона-аннонсера). Префикс ключа = код героя (`atlas_` — Абрамс, `priest_` — Венатор и т. д., как мы уже выяснили в диалогах).
- Субтитры в игре — это настройка (токены `citadel_settings_showsubtitles_search` «closed captions VO voiceover CC» в `citadel_main_english.txt`), текст они берут из этих же токенов.
- Игра читает файл языка клиента: английский — `..._english.txt`, русский — `..._russian.txt`.

**Есть ли русские.** Да: русская локализация у Deadlock официальная, появилась в конце августа 2024 (SteamDB фиксирует новые языки; перевод периодически правят — на офиц. форуме есть тема «Bug fixes in the Russian translation»). В GameTracking лежит **только английский** — они трекают один язык. Русский файл лежит в VPK игры на диске; достать его можно так же, как `tools/restless_assets.py` достаёт данные (распаковка pak или чтение прямо из VPK на машине Андрея). Точный состав русских файлов надо один раз посмотреть на живой установке.

**Можно ли подменить модом.** Да, и это самый простой вид мода:
- мод ставится аддон-VPK в `citadel/addons` — наш Restless 0.10 уже так работает (`mod/build/pak42_dir.vpk`);
- файл локализации — обычный текстовый файл внутри VPK; аддон-VPK может содержать такой же путь с файлом, и игра прочитает его вместо базового (стандартный механизм Source 2);
- прецедент: в Dota 2 перевод-моды официальны (Steam Workshop), в Deadlock в DMM уже живут моды на модели/тексты, игроки играют с ними в рейтинге — банов по этим поводам на форуме не видно.

**Двуязычные субтитры — как я это вижу.**
- Вариант А (проще всего): мод переопределяет файл языка КЛИЕНТА. Если Андрей играет с русским — в `citadel_generated_vo_russian.txt` каждая реплика — русский перевод, а мы кладём «русский перевод \n английская строка». Родные субтитры игры показывают обе строки, кода мода почти нет. Риски: поддерживает ли Panorama-текст `\n` внутри токена (в Source 2 обычно да, проверить на одной реплике), кавычки в строках, размер файла (файл вырастет вдвое — не страшно).
- Вариант Б (страховка): своя панель мода рядом с родными субтитрами, показывает перевод активной реплики. Свой текст из файла мод показывает умеет (подтверждено ресёрчем 27.10 — CitadelHTMLPanel/свой текст). Минус — надо ловить событие «какая реплика сейчас играет», это в моде ещё не делалось.
- Порядок работы: достать русский файл → сравнить набор токенов с английским (всё ли переведено) → собрать пилот на одном герое (Абрамс, 11 реплик) → смотреть в игре → раскатывать.

## 2. Экран после матча

**Что там есть.** Итог (победа/поражение), таблица всех 12 (убийства/смерти/помощь, души), график душ по времени, «Souls by Source». **Match ID в клиенте виден**: при подключении к игре он в правом нижнем углу, плюс история матчей в клиенте — по нему игроки смотрят разборы на трекерах. Реплей запускается из истории матчей.

**Откуда мод может взять ID текущего матча для кнопки «Разбор этого матча»:**
- Путь 1 (нужен живой прогон): блок «Что видит мод» в 0.10 уже печатает всё, что мод видит из состояния игры. Добавить туда перебор известных мест (поля панели результатов, GameEvents, счётчик матча) — и Андрей пришлёт фото: видно ли там Match ID. Если да — кнопка открывает `https://1f8t8graf4-ai.github.io/dota-/restless/?match=<id>`.
- Путь 2 (работает уже сейчас, без мода): кнопка «Разбор последнего матча» — сайт Restless берёт историю матчей по Steam ID из открытого deadlock-api (он уже это делает для страницы профиля) и открывает свежий. ID игры при этом читается только из открытого API — граница «не читаем память» не нарушается.
- Моё предложение: в 0.11 сделать путь 2 (он гарантированно рабочий), путь 1 проверить тем же отладочным блоком в следующем прогоне мода.

## 3. Что не проверила и почему

- Русский файл реплик не открыла — его нет в GameTracking, нужен доступ к файлам игры (машина Андрея).
- `\n` в токенах и реальный вид субтитров в игре — только на живой игре (пилот на Абрамсе, 11 реплик).
- Возможность перехвата конца матча из Panorama — следующий прогон мода с отладочным блоком.
