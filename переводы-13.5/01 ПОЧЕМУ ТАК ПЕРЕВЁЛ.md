# Почему я так перевёл (13.5)

Это пояснения к переводам: какими правилами я пользовался и где принимал спорные решения. Сами переводы всех строк — в Excel-файлах этой папки и в `текстом/`. ID строки субтитров — `сцена|время`, ID фразы — `сцена|эпизод|№`.

**Нейронке-проверяющему:** проверь в первую очередь места из списков «Не уверен», а потом решения из «Спорно». Если не согласен — дай свой вариант и скажи почему.

## 1. Общие правила (для всех сцен)

1. **Перевожу то, что реально звучит.**
   - В английских сценах — английскую реплику.
   - В немецких сценах (дубляж) — **немецкую реплику дубляжа, а не английский оригинал**. Дубляж часто говорит по-другому, а ученик слышит именно немецкий. Английский оригинал стоит рядом в колонке EN — для сравнения.
2. **Живой русский, а не калька.** Перевожу так, как сказал бы человек в этой ситуации. Длина — примерно как у субтитра, чтобы успеть прочитать.
   - «Das ist eine mathematische Gewissheit» → «Это математически неизбежно», а не «Это математическая уверенность».
   - «Das wird schon» → «Освоится».
3. **Мат и грубость — той же силы, что в оригинале.** Не смягчаю и не усиливаю. Слово подбираю по ситуации, а не по словарю:

   | В реплике | Перевод |
   |---|---|
   | Scheiße | «блядь» (восклицание), «дерьмо» / «херня» (про вещь) |
   | Arschloch | «мудак» |
   | Wichser | «дрочила» |
   | Pisser | «сопляк» |
   | Drecksack | «говнюк» |
   | Scheiß auf … | «насрать на …» |
   | im Arsch sein | «нам крышка» |
   | für den Arsch | «полная херня» |

4. **Сленг — сленгом:** Kohle → «бабки», Knast → «сидел», mies → «хреново», kriegen → «получать / достать», sich verziehen → «свалить».
5. **Оскорбления по национальности и ориентации** (Itaker, Spaghettifresser, Schwuchtel) переведены точно — «макаронники», «пидор»: так говорят герои. Учебных фраз из них нет, только строки субтитров.
6. **«Когда применяется»** — всегда ситуация из жизни («Когда …»), без грамматики. Грамматика — в «важных словах».
7. **Пример из жизни** — бытовая фраза с той же конструкцией, уровня A2–B1, не из фильма. Для немецких сцен — немецкий пример, русский перевод и английский эквивалент.
8. **Ложные переводы** (вопрос «что значит фраза?»): те же слова, но смысл неверный — перепутан глагол, время, кто кому, отрицание. Без абсурда. Ни один ложный вариант не должен случайно оказаться верным.
9. **Пассивные фразы** (только понять, без заданий):
   - узко-сюжетное («Die Titanic wird untergehen», «Ihr Name ist Theresa. Sie schneidet Haare»);
   - наркотики и секс («Kokain…», «Ich hol mir zweimal täglich einen runter»);
   - угрозы убийством («Wenn du ihn umlegst…», «eine ganze Scheißfamilie ausradieren»).
10. **Песни не перевожу и не записываю.** Напев Ханны с ударами в грудь в конце «Ланча» идёт без субтитров.
11. **Факты** — только то, что можно проверить: Википедия, IMDb. Например, кто играет героя или откуда название серии. Закулисье не выдумываю.

## 2. Немецкие сцены (дубляж) — спорные решения

## 3. Глоссарий немецких слов (+956)

- Для нажатия на слово в субтитрах я перевёл каждую словоформу, которая встречается в немецких сценах (absinkt, gefahren, hieß…).
- Формат: перевод, а в скобках — словарная форма или выражение. Например, «absinkt»: «опускается, тонет (absinken)».
- Имена — с пометкой «(имя)».
- Грубые слова — с пометкой «(груб.)».
- Проверить: верны ли переводы форм и не перепутаны ли значения у многозначных слов: Laden, Kohle, kriegen, erleichtern, umlegen.

### Правки русского

**Принято:**
- «Я тот, кто к нему стучит» → «Я тот, кто стучится к нему в дверь».
- «кровь носом» → «кровь из носа».
- «Союз с Хокли — безупречная партия» → «Брак с Хокли — блестящая партия».
- «Меня тошнит слушать этого мудака» → «Меня уже тошнит слушать этого мудака».
- Pisser: «сопляк» → «засранец». «Сопляк» слабее оригинала.
- «больной ты дрочила» → «урод больной». Так естественнее по-русски, грубость та же.
- «душить змея» → «душить удава». Я ошибся, когда спорил: устойчивое русское выражение — «душить удава».

**Не принято (с причиной):**
- «Освоится» оставлено. Реплика «Ist sein erster Tag an der Wall Street. Das wird schon» — про новичка, «освоится» по смыслу точно.
- «Гремучая смесь», «врачебная тайна», «ни шиша», «Тоже нюхнёшь?», «„Титаник“ утонет», «14 футов» — нейронки сами их одобрили, оставлено.
- Перевод шутки про Махаффи оставлен. Это адаптация рифмы, она помечена как спорная.
