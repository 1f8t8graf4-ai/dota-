# Как залить 7.9.2, чтобы всё заработало

## Почему сейчас ничего не работает
1. **В основном репо файлы легли не туда.** Новые файлы оказались внутри папки `js` (`js/js/app.js`, `js/img/…`, `js/data/…`), а в корне остался старый код 7.8. Поэтому нет словаря, подсказок, круглого Бейтмана и свежих исправлений.
2. **В репо `scenes` нет видео.** Там только обложки и музыка, а самих `01.mp4…` нет ни у одной сцены, кроме Таксиста 2 и Сопрано 6×09. Плеер честно пишет «видео не загрузилось».

## Шаг 1. Основной репо (dota-)
1. Распакуй `dota-7.9.3-full.zip` у себя на компьютере. Внутри: `index.html` и папки `js`, `styles`, `img`, `data`, `bot`, `tools`.
2. Открой репо на GitHub **на главной странице** (там, где видно `index.html`, `js`, `styles`…), а **не внутри папки `js`**.
3. **Add file → Upload files** → перетащи **всё содержимое** распакованной папки (сами папки `js`, `styles`, `img`, `data` и файл `index.html`, а не папку целиком) → **Commit changes**.
4. `data/scenes.json` и `data/all-data.js` в архиве нет специально — твои остаются в репо.
5. Мусор `js/js`, `js/img`, `js/data`, `js/styles`, `js/index.html`, `data/.github` ничему не мешает. Удалишь, когда будет время.

## Шаг 2. Видео в репо scenes
1. Распакуй `scenes-720-1.zip`, `-2`, `-3`. Внутри — папки сцен (`wolf-of-wall-street`, `sopranos-s01e01`…).
2. Открой репо **scenes на главной странице** (где видны папки сцен) → **Add file → Upload files** → перетаскивай **по одной-две папки сцены за раз** → **Commit changes**. Файлы встанут к уже лежащим обложкам и музыке.
3. Если браузер виснет на больших загрузках — поставь **GitHub Desktop**: клонируешь репо, кидаешь папки в него мышкой, нажимаешь Commit и Push.
4. Видео теперь легче (720p): грузятся быстрее и у людей на телефонах.

## Шаг 3. Проверка
Подожди 1–2 минуты после загрузки (GitHub Pages обновляется), открой бота → **Профиль → Админ-панель → «Проверить установку»**. Покажет ✅ или ❌ по каждому файлу и сцене и подскажет, чего не хватает.
