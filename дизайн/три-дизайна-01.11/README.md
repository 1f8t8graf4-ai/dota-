# Три дизайна «Языков по кино» (01.11)

Кликабельное тестовое приложение: один код, три дизайна (`#app[data-d]`: studio · night · bright) и тема (`data-t`). Страница: https://claude.ai/artifact/Hhyb8c7MXuvxGgiHCVHQ23

- `build.py` — берёт 10 сцен из `data/scenes.json`, значения слов «тут» из `data/ctx-*.json`, качает постеры/кадры/2 эпизода из R2 и пишет `data.js`, `a/`, `v/`, `h/` (медиа в репо не кладём — пересобирается). Запуск из папки рядом: `python3 build.py` (пути внутри — `/home/user/work/app3`).
- Видео: эпизод 1 «Титаника» и «Волка» (540p, mp4 + webm). Остальные эпизоды — кадр и фразы.
- Публикация: `publish_files` всех файлов (index.html, app.css, app.js, data.js, a/*, v/*, h/*) на ту же ссылку.
- Что из заметок к макетам — в левой колонке страницы («Что взял из твоих заметок»).
