Как устроен `glavnaya-dd.tpl.html`: варианты — объекты в массиве `V` (`g` — группа `home|dd|ob`, `id`, `n`, тексты под телефоном, `mount(R,ctx)` — рисует экран и вешает анимации; `ctx` убирает таймеры при переключении). Помощники: `an()` (WAAPI), `SP/SPs/SPb` (пружины через `linear()`), `drag()` (касания и мышь; на iPhone — touch-события с `preventDefault`), `FX()` (частицы на canvas), `kara()` (слова загораются по очереди), `emb()` (гербы героев ДД в SVG). Отзыв Андрея по каждому варианту — в `ПЛАН-24.10.md` в корне репо.

v2 (группы `h2` — главная, `d2` — ДД, `o2` — первый запуск; старые — `home`, `dd`, `ob`):
- `stories(host,ctx,слайды,с_какого,{end,x})` — общий движок сторис (полоски, тап вправо/влево, зажал — пауза, ✕); `daySlides()` — слайды дня: цель, фраза дня, серия, выучено, что посмотреть.
- `FILMS` — сцены колоды «что посмотреть»: «о чём» без вырванных фраз, уровень, польза ★, длительность.
- `.ff.<фильм>` — шрифт фильма: `wolf` (золотая антиква Playfair), `titanic` (курсив Cormorant), `psycho` (капитель с разрядкой), `taxi` (PT Mono), `sopranos` (узкий Oswald).
- `TB2(класс, № активной вкладки)` — нижние вкладки с любой выбранной.

v3 (группы `h3` — главная, `d3` — ДД, `k3` — комикс, `x3` — тёмный дизайн; ключ «последний экран» в localStorage — `kd7`):
- `v3Stories(R,ctx,ряд,окно)` — кружки сторис + просмотр; первый кружок «новое» — `newsSlide()` из массива `NEWS` (в приложении — `data/news.json`). `v3Deck` — колода «Что посмотреть» внутри прокрутки, `v3Games()` — Versus · Шпион · Дуэль по сцене, `v3Two()` — Коллекция и Магазин.
- `ha` «Лента» — всё одной прокруткой; `hb` «Вкладки под сторис» — «Смотреть · Играть · Магазин», плашка едет, содержимое уезжает вбок.
- `da` — герои карточками-портретами (наклон к пальцу, блик), ▦/☰ перетекает FLIP-ом, фильтры «С голосом / Мои»; тап — `heroCard()` вырастает из карточки.
- `heroCard(host,ctx,герой,R,{back})` — уровень 1–5, опыт, «интересные фразы» `FUN` (только настоящие реплики из `data/games.json` с голосом `a` и проверяемой пометкой «отсылка / идиома / игра слов / акцент»); закрытые — штриховка «Откроется на N-м уровне»; «Демо: победа» показывает, как открывается следующая. В приложении опыт — `store.heroXP` из П12.
- `ka` — комикс: страницы `CMX`, камера `cam()` наезжает на панель, ▶ у каждой реплики (в макете — голос браузера, в приложении — mp3 реплики), подчёркнутые слова `CMW` — перевод по тапу, «Авто» листает под голос, свайп, переворот страницы, штамп «Глава пройдена».
- `dsg(R,ctx,тема)` — 4 экрана (Сегодня, Сцена, Задание, Словарь) в темах `kino` / `neon` / `film`; атмосфера — частицы на canvas (`fx.ambient`), сам листает экраны, пока не тронешь.
- **Грабли v3:** классы шаблона `.hb` (полоска «домой»), `.sg` (экран v1) и правило `.scr h2,.scr h3,.scr p{margin:0}` действуют и на новые экраны — у корня экрана не ставить `hb`, отступы у `h3`/`p` писать через `.scr .класс`.

v4 (25.10, отзыв на v3; группы `h4` — главная, `k4` — комикс, `x4` — дизайн; ключ localStorage — `kd8`):
- `SC4` — 6 сцен с настоящими данными из `data/scenes.json` (о чём, год · режиссёр, сложность и почему, что выучишь, эпизоды); `w4Full(R,ctx,сцена,откуда)` — окно «Подробнее» (растёт из карточки, ✕ / свайп вниз за кадр); `TB4` — вкладки с «Главная».
- `h4a` «Афиша», `h4b` «Меню как в игре» (живой фон `vidHTML`, меню, ряд постеров), `h4c` «Лента как в TikTok» (scroll-snap по вертикали).
- `kb` (группа `k4`) — комикс: `K4L` = реплика, перевод, подпись «что происходит», накал 0–1; `k4Scene()` — тоннель SVG; накал двигает лампу, капли (`fx.ambient`), глаза, красную виньетку, наезд камеры.
- `x4Run(R,ctx,{out,in,kids,good,reset})` — общий движок трёх дизайнов (экраны, переходы, задание, авто-тур); `xf` «Кинолента», `xe` «Журнал», `xg` «Игра».
- Грабли: у анимации с `fill:'forwards'` в `onfinish` сначала `cancel()`, иначе следующая анимация того же свойства не видна (заголовок «Волка» пропадал).

v5 (25.10, отзыв на v4; группы `h4` — главная (`h4a` «Афиша», `h4b` «Меню»; `h4c` убран — лента теперь функция), `d3` — ДД, `k4` — комикс, `x5` — дизайн «Свой стиль» (`xs`); ключ localStorage — `kd9`):
- `w4Feed(R,ctx,с какой сцены,откуда)` — лента как в TikTok поверх экрана: слайды `.w4c-feed`, текст `s.ab2` (2 предложения; в обычном виде — `s.ab`, 1), шапка «✕ · Что посмотреть · N / 6», свайп вниз по шапке — закрыть, «Подробнее» → `w4Full`.
- `upDrag(ctx,el,R,{move,end})` — вертикальный жест поверх кнопок (`drag()` кнопки пропускает); ставит `R._pkd`, чтобы тап по постеру после свайпа не открыл «Подробнее».
- `w5Coll` / `w5Shop` / `w5Open` — Коллекция (вкладки, замки) и Магазин (`SHOPD` — настоящие цены, `tier(цена)` — редкость, превью `.pv-fx/.pv-cs/.pv-snd/.pv-st`, «Новинка дня» на одном общем canvas `.w5-fxc`, покупка в два нажатия); иконки `ICOLL`, `ISHOP`, `IFR`.
- Комикс `kb`: `lis(вкл)` — режим «Слушать диалог» (`.k4.lis`, субтитры `.k4-sub`, выход `.k4-lx`). `GEN` — номер текущего `go()`: старые таймеры и голос не листают дальше. Штамп в конце — классом `.on`, без `fill:'forwards'`. У голоса браузера есть запасной таймер (`1800 + 80 мс × символ`): в Telegram на iPhone `onend` может не прийти.
- ДД: обёртка над `da.mount` — кнопка `.da-icb`, `giArt(герой,размер)` — заглушка арта, `R.classList 'gi'`, ключ `kd-ic`; карточка героя подхватывает арт через `MutationObserver` на `.da-ov`.
- `xs` «Свой стиль» — `x4Run(R,ctx,{ord:[…]})` теперь с любым порядком экранов; сторис — общие `v3Stories`.
- Тесты (скретчпад): `t5.js` — главная v5, `t6.js` — комикс «Слушать», иконки ДД, «Свой стиль».

v6 (25.10, отзыв на v5; группы `h6` — главная (`h6a` «Афиша», `h6b` «Афиша · понятная», `h6m` «Меню как в игре»), `d3` — ДД (без изменений), `k4` — комикс (`kb` + режим «Герои»), `x6` — дизайн (`x6a` «Свой стиль», `x6b` «светлый», `x6c` «без рамок»); v5 — под «v5:»; ключ localStorage — `kd10`; копия страницы — https://claude.ai/artifact/4zkzTThikXJxpdx45yTmMg):
- `afisha6(R,ctx,{clear})` — одна функция на обе Афиши. `clear` = «понятная»: `.a6-how` (3 шага), `a6Tour` (подсветка `.hole` по `AF_TIP`, «?» — `.a6-q`), `a6Next` (шторка «Что будет дальше»), подписи, без автопрокрутки. Общее: карточка-лента `.a6-fc` (веер `FAN`), метка `.a6-lt`, `w6Feed` = `w4Feed` + шкала `.a6-vp` + «выглядывание» следующей сцены (прокрутка с выключенным scroll-snap) + в «понятной» плашка `.a6-fp`.
- `h6m` «Меню»: `M6` — пункты (заголовок, подпись, карточка, кнопка), слои фона `.m6-l` (видео, `.m6-wall`, `.m6-ph`, `.m6-hv`, `.m6-shp`), первый тап выбирает, второй — `enter()`; `m6Lv(R,ctx,откуда,назад)` — выбор сцены каруселью 3D (постеры — `div`, не `button`: `drag()` кнопки пропускает), вверх — `w4Feed`. Коллекция/Магазин — `w5Coll/w5Shop`, возврат меню — по исчезновению `.w5o`.
- Комикс: обёртка над `kb.mount` (IIFE после `V.push`): `.k6-hv` в `.k4-pn` (портреты `.k6-p` с роликами `hv_venator/hv_rat` из `assets/vid`, кадр — `K6FX` + `fit()`, как `dvFit` в приложении), пузыри `.k6-bs` — по смене подписи `.k4-cap` (её меняет `go()`), кнопки `.hv` (в ряду) и `.k6-lh` (в «Слушать»). В режиме «Герои» скрыты `.k4-who/.k4-bl/.k4-cov`.
- Дизайн: `x6Mount(R,ctx,{cls})` = `xs` + переключатель `.x6-ths` + `x6Theme(R,k)` по `X6TH` (обложка, подпись, чипы, эпизоды, акцент `--xa`); сам перебирает темы, пока не тронешь (`MutationObserver` на класс экрана). Грабли: `.xs-cv>div` ловит и вставленный блок гербов — текст ищем `.xs-cv>div:not(.x6-gem)`; у Bangers нет кириллицы — русские названия игры шрифтом Russo One (добавлен в Google Fonts).
- В Playwright из контейнера H.264 не играет — ролики видны постерами; переход между вариантами в тесте — через `about:blank` (смена одного `#хэша` не перезагружает страницу). Тест — скретчпад `v6t.js`.
