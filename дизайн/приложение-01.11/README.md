# Приложение из макетов (01.11)

Чистый HTML «Языков по кино» в нашем дизайне: экраны — те самые одобренные варианты из `дизайн/макеты-24.10/` (раздел «Итог» v20–v22), связанные переходами, плюс плеер эпизода, 3 задания и «хватит или ещё» на настоящих данных.

Страница: https://claude.ai/artifact/1aNN8S8wxCfKTz9BioRobY

## Что куда ведёт
- **Главная (Меню, z22m):** «Продолжить» → эпизод «Титаник · Я выживу»; «Игры» → список игр → Deadlock; «Что посмотреть» → список сцен → путь сцены (у Психопата и Таксиста — лента); «Повторить» → повторение по 3; «С друзьями» → Versus; аватарка → профиль-бенто → настройки.
- **Вкладки:** Главная · Сцены · Игры (Deadlock «На сегодня», z21d) · Словарь.
- **Путь сцены (p11t/w/s/b):** «Смотреть эпизод N» и шторка эпизода → плеер; прогресс помнится в браузере (`localStorage ap01`).
- **Плеер (свой):** видео 16:9, субтитры загораются по словам (`wt.json`), тап по слову — шторка «что значит тут» (значения `ctx-en.json`), «С паузами» — плашка на полезной фразе, точки фраз на шкале. Видео есть у Титаника 1–2, Волка 3, Сопрано 2, Во все тяжкие 2; у остальных эпизодов — кадр и фразы.
- **3 задания (свои, вид макета l11a):** собери (2 попытки, верные кубики остаются) · что значит (перевод реплики — после ответа) · на слух. Потом «нажатые слова» (если нажимал) → «Хватит или ещё» (вид l13d): дальше смотреть / углубить (l11d) / все слова (l15c).
- **Deadlock:** хаб, герои, карточка героя, уровень, комикс, проверка главы, реплики, Versus — варианты макетов как есть; «Радар» ведёт на одобренный сонар g8r.
- **Все экраны:** на ПК — список слева, на телефоне — кнопка «все экраны» внизу.

## Как собрать
1. `cd ../макеты-24.10 && python3 build.py --pub` — макеты с картинками отдельными файлами.
2. `python3 data.py <папка>` — данные 4 фильмов и видео 480p (качает из R2, пережимает ffmpeg).
3. `python3 build.py <папка>` — `index.html` = макеты + `app.css` + `app.js`; `a/` — ссылка на картинки макетов.
Публикация — `publish_files`: `index.html`, `data.js`, `v/*.mp4|jpg`, `a/**`.

## Устройство `app.js`
- Оболочка прячет галерею макетов, телефон — на весь экран (телефон: без рамки и нарисованной строки состояния, верх обрезан на 34 px) или по центру (ПК).
- Роутер: стек экранов `APP.stack`, `go / replace / back / tab / jump`; экран = вариант макета (`VM(id)`) или своя функция.
- Кнопки-заглушки макетов перехватываются одним обработчиком на `#dev` в фазе захвата (`CAP[экран]` — селектор → действие); кнопки внутри шторок макетов (`.g11-ov` и др.) не трогаем, если не помечено.
- Вкладки макетов на вложенных экранах скрыты; на корневых — своя `q7TB`.
