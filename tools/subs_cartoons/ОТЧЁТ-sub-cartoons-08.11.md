## Метод

1. Опознание серий: ASR-сниппеты (z-ai) + контакт-листы + поиск цитат.
2. Скачивание SRT: subf2m.co (список сезона → деталка по id → архив → SRT,
   декодинг utf-8/cp1252/latin-1).
3. Выравнивание: клип → WAV 16к → ASR-чанки 28с (и 8–14с доуточнение) →
   токен-матчинг (difflib, стоп-слова) против потока SRT: грубая цепочка
   (±30с → ±80с → глобально), fine-сетка, кластеризация офсетов, границы
   по scene-cut'ам ffmpeg и покадрово.
4. Верификация: прожиг SRT в кадры по 6 точкам на клип; сверка текста на
   кадре с ASR-текстом того же момента. Все 4 клипа — ОК.
