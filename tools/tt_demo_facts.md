# Факты в роликах-образцах (`tools/tt_demo_ru.py`) и откуда они

Правило: в ролике только то, что есть здесь, с источником. Нет источника — нет факта.
Нельзя: дозировки, «как употреблять», где взять. В описании ролика — номер помощи страны.

## Кокаин (`cocaine`)
| В ролике | Источник |
|---|---|
| Эффект через нос уходит за 15–30 минут, тянет повторить | NIDA, Cocaine Research Report — https://nida.nih.gov/publications/research-reports/cocaine |
| В первый час после дозы риск инфаркта выше примерно в 24 раза | Mittleman M.A. et al. «Triggering of myocardial infarction by cocaine», Circulation, 1999; 99: 2737–2741 (в 23,7 раза) |
| Кокаин + алкоголь → в печени кокаэтилен, токсичнее для сердца и держится дольше | NIDA, Cocaine Research Report (раздел о смешивании с алкоголем) |
| В кокаин подмешивают левамизол — лекарство от глистов для скота | CDC MMWR, 2009, «Agranulocytosis associated with cocaine use — four states» |
| Бывает фентанил; около 2 мг могут убить | DEA, Facts about Fentanyl — https://www.dea.gov/resources/facts-about-fentanyl |

## ВИЧ (`hiv`)
| В ролике | Источник |
|---|---|
| ПКП — начать как можно раньше, не позже 72 часов, курс 28 дней | CDC, PEP — https://www.cdc.gov/hiv/prevention/pep ; WHO, рекомендации по ПКП |
| Через 2–4 недели может быть похоже на грипп, а может не быть ничего | CDC, About HIV / Symptoms |
| Анализ из вены (4-е поколение) ловит вирус примерно через 18–45 дней; после ПКП — контроль через 3 месяца | CDC, HIV Testing (window period); CDC PEP guidance |
| Поцелуй, комары, общая посуда ВИЧ не передают | CDC, Ways HIV is not transmitted |
| Неопределяемая вирусная нагрузка = не передаётся половым путём (Н = Н) | CDC, HIV treatment as prevention; исследования PARTNER |

## Таблетка в клубе (`pill`)
| В ролике | Источник |
|---|---|
| Накрывает примерно через 45 минут | NIDA, MDMA Research Report — https://nida.nih.gov/publications/research-reports/mdma-ecstasy-abuse |
| Выброс серотонина, потом тоска на 2–3-й день | NIDA, MDMA Research Report |
| Перегрев — одна из главных опасностей | NIDA, MDMA Research Report |
| Много воды → натрий падает, мозг отекает (гипонатриемия) | NIDA, MDMA Research Report |
| Сводит челюсть, нет сна | NIDA, MDMA Research Report |
| PMMA действует медленнее, человек добавляет и передозирует | EMCDDA, отчёты о PMMA |

## Порно (`porno`)
| В ролике | Источник |
|---|---|
| Компульсивное сексуальное поведение — диагноз в МКБ-11 | ВОЗ, МКБ-11, код 6C72 |
| «Всплеск дофамина, потом ниже нормы» | Упрощение для зрителя (Lembke A., «Dopamine Nation», 2021). Подавать как «по-простому», не как точную науку |
| Тяга накатывает волной и спадает за 20–30 минут | Приём «сёрфинг тяги» из профилактики срывов (Marlatt G.A., Gordon J.R., «Relapse Prevention») |
| Нельзя: «через 30 дней — суперсила» | Исследования о пользе воздержания спорные |
