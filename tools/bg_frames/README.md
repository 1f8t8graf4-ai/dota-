# Фоны из настоящих кадров (25.10, Андрей: «кадры доставать со сцен и оживлять — тогда 100 % хуйни не будет»)

Рабочая папка (`BGF`, по умолчанию текущая) — в ней `vid/<сцена>__NN.mp4` (эпизоды из репо `scenes`: `git -C ../scenes show origin/main:<сцена>/NN.mp4 > vid/<сцена>__NN.mp4`).

1. `python3 calm.py` → `calm.json`: спокойные окна по 4 с без склеек (мало движения, не тёмные, полосы срезаны).
2. `python3 faces.py` → `calm2.json`: доля кадра под лицами (OpenCV Haar; нужен `pip install "opencv-python-headless<5"` — в 5.x Haar нет).
3. `python3 pick.py` → `sel.json` + `out/`: по 4–10 кадров на фильм / сезон (без лиц — первыми, не больше 2 с эпизода).
4. `python3 mkloop.py` → `loops/`: петля из самого фильма (самый длинный кусок без склеек ≤ 9 с → `tools/loop_bg.py`).

Вывод по первому прогону: петля из фильма идеальна, когда камера стоит (офис Бейтмана, «Лос Поллос»); склейка или люди, идущие на камеру, — брак. В наших эпизодах почти везде актёры (это диалоги); общие планы без людей — только в полных фильмах. Страница выбора кадров: https://claude.ai/artifact/38bb315JjeT1a3N4R5KZZk
