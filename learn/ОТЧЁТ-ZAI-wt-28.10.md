# ОТЧЁТ-wt — время каждого слова в репликах героев

**Ветка:** `zai/dd-wt` (от `zai/dd-lines`, влит свежий `main`). **Статус: готово.**

## Что сделано
- **374 файла** — все поля `a` из `data/games.json` (main, 17 шт: `rk-*`, `ven-*`) + `data/games-new.json` (357 шт). Локально: `heroes-voice/` (357 из ветки dd-lines) + 17 скачанных GET-ом с воркера (лежат в `heroes-voice/v/`).
- Распознавание: faster-whisper **medium.en**, int8, `word_timestamps=True`, без VAD, вход — ffmpeg 16 кГц моно. Сырьё (тайминги распознанных слов) — `data/dd-wt-raw.json`.
- Сборка `data/dd-wt.json` (tools/dd_wt_build.py): слова — из поля `en` реплики, как написано у нас; время — из распознавания, сопоставление по порядку (difflib, без регистра/знаков); ненайденные слова — время поровну между соседями найденными. Ключи — полные пути `scenes/games/deadlock/v/*.mp3`.
