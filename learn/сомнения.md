# Сомнения по разметке

- sopranos-arc#3.2 «can't stop» — вариант «не могу остановить» близок к ответу, оставил как ловушку на дословность: stop тут непереходный.
- taxi-driver-lonely#2.3 «lonely» — у слова нет честной ловушки по звуку/значению; ловушка «милый» на путаницу lovely/lonely.
- taxi-driver-lonely#2.2 «escape» — ответ описательный, потому что «побег» тут тоже по смыслу подходит.
- sopranos-arc#1.1 «feel like» — выбрал значение «чувствуешь, будто», а не «хочется»: в реплике именно про чувство.
