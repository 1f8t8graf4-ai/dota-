# /learn — правила из повторяющихся правок

Запускает только Андрей командой `/learn`. Ничего не пишется в файлы без его «ок».

## 1. Собрать

Источники:
- этот чат: где Андрей поправлял одно и то же второй раз и больше («опять…», «я же говорил…», «впредь…», «никогда…», мат на одно и то же);
- `shorts/log/*.md` и раздел роликов в CLAUDE.md за последние дни — повтор той же правки в разных роликах;
- `docs/critic.md`, журналы критика — проблема, которую критик находит в каждом раунде.

Брать только правку, которая встречается **2+ раза** или сказана как правило («впредь», «никогда», «всегда»). Разовую правку одного ролика не брать.

Каждой правке — дословная цитата Андрея и где она была (чат / файл / дата).

## 2. Проверить

- Нет ли этого правила уже: `grep -rn "<ключевое слово>" CLAUDE.md shorts/CLAUDE.md docs/ restless/CLAUDE.md mod/CLAUDE.md`.
- Не спорит ли с жёсткими правилами ядра CLAUDE.md (они главнее): «го», ничего платного без «да», без Three.js, HUD как у Династии можно, рук кодом не рисуем, без простыней текста.
- Если правило уже есть, но его нарушают — предложить не новое правило, а уточнение старого (что именно непонятно было).

## 3. Предложить

Для каждой находки — одним сообщением, коротко:

```
Правило N: <о чём, 3–5 слов>
Цитаты: «…» (чат, 26.11) · «…» (shorts/log/duhless.md)
Куда: ядро CLAUDE.md / shorts/CLAUDE.md / docs/visual_patterns.md / …
Варианты:
  А. <формулировка — одна строка, проверяемая>
  Б. <строже>
  В. <мягче или другой угол>
Как проверить: <скрипт / шаг критика, если есть>
```

Не больше 5 правил за раз. Самое частое — первым.

## 4. Записать — только после «ок»

- Андрей отвечает: «1А, 2 не надо, 3Б с правкой …».
- Записать выбранное **дословно как утверждено** в указанный файл, в нужный раздел.
- В ядро CLAUDE.md — только жёсткие правила на все проекты; всё про конкретный формат — в его файл.
- Показать дифф, закоммитить в текущую рабочую ветку с сообщением `learn: <о чём>`.
- Без «ок» — ничего не писать, даже «на всякий случай».
