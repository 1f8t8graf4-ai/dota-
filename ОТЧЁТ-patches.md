# ОТЧЁТ-patches — последние 5 патчей в данных

**Версия:** код приложения не трогала (ветка данных: `data/patches.json`, `data/patch-words.json`, сборщик `tools/patches_build.py`).

**Сделала:**
1. Последние 5 официальных патчей с deadlock.wiki (страницы `Update:October …, 2026`), у каждой — прямая ссылка на Steam-пост:
   - 20.10 «Shh... This Won't Hurt a Bit.» — новый герой Нёрс Харроу + карта (без упоминания);
   - 16.10 «Paint the Town» — новый герой Вайолет + карта + фикс Соломона (без упоминания);
   - 14.10 «Minor Update - 10-14-2026» — Баба (нерф), Дэнни (бафф), Street Brawl, предмет Radiant Regeneration;
   - 9.10 «Make Your Move.» — новый герой Соломон + карта + ремастер VO Визкоуса (без упоминания);
   - 6.10 «Mind the Birds!» — новый герой Баба + рейтед-сезон продлён до 5 ноября.
2. Формат по ТЗ v14 п.1: `{date, title, src, size, changes[{k, t, ty, h, rows, src}]}`. Числа «было → стало» как в патчноуте, чего не было — `—`, способности и предметы по-английски, заголовки по-русски, мат не добавляла.
3. `size`: у всех пяти `big`. Пояснение: у релизов героев — новый герой (это big по смыслу бота), а 14.10 формально «Minor», но там меняли героев и предмет числами — по правилу ТЗ («big — меняли героев или предметы числами») ставлю `big`. Если для бота «Minor Update» должен быть короткой новостью — flipping one field, скажи.
4. Неподтверждённые изменения подписаны «без упоминания в патчноутах» и ведут на секцию Undocumented_changes.
5. `data/patch-words.json` — 30 слов из этих патчноутов (nerf, cooldown, spirit scaling, AP, T2/T3, on hit, VO, pushed back, turnout…), у каждого перевод и живой пример из этих пяти патчей.

**Проверила:** json собирается сборщиком (`python3 tools/patches_build.py`), оба файла валидные, все ссылки `src` на Steam и вики ведут на нужные посты (Steam-ссылки из поля `source` вики-страниц, не руками).

**Не сделала / почему:**
- скрины изменённых мест из игры (`map/ingame/…` из v15) — на страницах этих пяти патчей скринов изменённых мест нет, только арты релизов; брать картинки из чужих постов не буду без ссылки, это против правила «только настоящие со ссылкой»;
- 21–22.10 на вики есть ещё два «undocumented»-дня (фиксы Нёрс Харроу/Виктора, бафф Вардена) — это не патчи с нотами, в patches.json не клала; если боту нужны и они — скажи, добавлю отдельными записями с `size: small`.

**Предлагаю:** полю `size` у «Minor Update» можно доверить автоправило (есть числовые changes → big), а заголовки `h` уже русские — бот может брать их без обработки.
