## Самое главное — жёсткие правила (главнее любых внешних навыков и плагинов)

- **Без «го» ничего не начинать.** «Го» / «давай» = начинать. «Делай …» посреди обсуждения и ТЗ от Gemini / других нейронок — не «го», переспросить. (Андрей: «без моей команды „го“ ничего не делаешь».)
- **Ничего платного без его «да»** — голос, музыка, звуки, генерация картинок, любые платные API. Сначала сказать, что и сколько уйдёт.
- **Ключи и пароли — никогда в чат.** Только переменной окружения или формой, которую Андрей заполняет сам.
- **Никогда не давать текст сплошняком** — ни в ответах, ни в приложении, ни на сайте: строки, списки, карточки. (Андрей, 03.11: «запомни — никогда в жизни».)
- **На экране — без пояснений** («нажми, чтобы…», «как считаем»). Объяснять — в ответе Андрею.
- **Факты — только проверенные.** Лучше без факта, чем выдуманный.
- **Мат в репликах и переводах — как в оригинале.**
- **Ролики:**
  - **Three.js — нельзя** (картинка кодом на canvas / SVG, «чистый 2.5D»);
  - **HUD как у «Династии» — можно** (тонкая строка места и времени, часы, полоса глав);
  - **руки и пальцы людей кодом не рисовать** («руки-картошки» в реализме — нельзя): предмет без руки, уходящий за край кадра, или кадр без рук;
  - видео, стоки, кадры фильмов, чужие расшифровки — **в git не класть** (репо публичное).
- **Git:**
  - коммитить и пушить только в рабочую ветку сессии (или ветку, которую назвал Андрей);
  - `main` — это сайт на GitHub Pages: туда только проверенное и по его слову.
- **С Зеткой (Z.ai) общаемся уважительно** — в ТЗ и ревью тон коллеги. Её «готово» сверять с кодом.

## Что это
Telegram Mini App + бот для изучения **английского (и немецкого)** по сценам из фильмов/сериалов: смотришь эпизод → разбор фраз → проверка → интервальное повторение. Дуэли с другом по сценам; вкладка «Игры» (Deadlock) — за флагом `games` (13.9.60, данные сырые).

## Архитектура — НЕ МЕНЯТЬ
- **Без сборщиков, без npm, без ES-модулей.** Статический сайт: `index.html`, один большой `js/app.js` (~4750 строк), `styles/main.css` (~5050 строк), лениво — `js/dictlab.js` + `styles/dictlab.css` (словарь), `styles/nd.css` («Новый»), `js/sfx-*.js` (звуки). 3D-фона и маскота больше нет (13.9.42).
- Андрей открывает `index.html` двойным кликом (`file://`) → для этого есть `data/all-data.js` (все JSON одним скриптом).
  **После ЛЮБОЙ правки `data/*.json` запускай `python3 tools/rebuild_all_data.py`.**
- `index.html` грузит обязательные JSON (`icons, scenes`) и необязательные (`topics, scenewords, glossary`).
- Версия: `const APP_V` в `js/app.js` + `var V='…'` в `index.html` (сбивает кэш через `?v=`) + **`version.txt`** в корне (13.9.36: по нему открытое приложение узнаёт о новой версии и перезагружается). **Поднимай все три при каждом релизе.**
- CSS пишется **слоями в конце файла** (`/* ==== 9.2 — … ==== */`). Новые правки — новым слоем внизу, старое не переписывать.
- Правки — **точечные** (поиск/замена конкретных мест), не переписывать файлы целиком.
- Ключи хранилища **не менять**: `dota_quiz_v4` (store), `dota_m_v1`, `dota_r_v1`, `dota_sc_v1` (прогресс сцен), `dota_flags_v1`. Прогресс: localStorage + Telegram CloudStorage.
- `.screen` — без `transform` (ломает полноэкранное видео).

## ЖЁСТКИЕ ПРАВИЛА
1. **Тексты песен не воспроизводить, не переводить, не проверять** (клип Lil Pump: Андрей сам кладёт `orig.srt/ru.srt/de.srt` в папку клипа, приложение их подтягивает — `clipLoad`). Отдельные слова/сленг объяснять можно.
2. **Мат в репликах и переводах оставлять как есть.**
3. Не делать фальшивых «проверок ИИ». Свободный ответ с проверкой нейросетью — только через сервер с API-ключом (не сделано).
4. Факты в `fact` — только проверяемые. Не выдумывать закулисье.
5. Фразы для обучения — **полезные в жизни**, не узко-сюжетные («She cuts hair» — плохой пример, такое → `passive`).
6. После каждой новой/изменённой сцены — **выгрузить файл переводов** `переводы-<версия>.md` (оригинал, перевод, когда применяется, пример, факт, важные слова) — Андрей отдаёт его другим нейросетям на проверку.

Видео тянутся из R2 через воркер (браузер Playwright его видит: `open({realMedia:true})` в `от-второго-клауда/тесты/st.js`; без этого флага медиа мокается из кэша); для офлайн-теста подменить `ASSET_BASE` или замокать маршруты (Playwright `page.route`).
