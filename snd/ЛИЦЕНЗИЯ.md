# Звуки приложения — лицензия

**Все звуки в этой папке и в `js/sfx-kino.js`, `js/sfx-ios.js` — CC0 1.0 (общественное достояние).**
Их можно использовать где угодно, в том числе в App Store / Google Play и в рекламе, без указания автора.

## Откуда они
- Синтезированы с нуля скриптом `tools/sfx_make.py` (13.9.21) — numpy + ffmpeg.
- Чужих записей, сэмплов и библиотек звуков нет: каждый звук — формула в коде (затухающие синусы, отфильтрованный шум, синтезированная реверберация).
- Пересобрать: `python3 tools/sfx_make.py` — те же файлы получатся заново (генератор случайных чисел с фиксированным зерном).

## Наборы
- **«Кино»** (`snd/kino/`, по умолчанию): затвор, кадровая рамка, бумага, челеста, войлок, стрёкот проектора, звон билетов.
- **«Как в iPhone»** (`snd/ios/`, на выбор в магазине): короткий «ток», тик колёсика, чистый колокольчик, мягкий двойной «бзз».
  - Это звуки «в духе» iOS, а **не копии звуков Apple**: ни один не взят из iOS и не повторяет их мелодию.
  - Название набора в магазине — описательное («Как в iPhone»), без логотипов и товарных знаков. Для версии в сторах лучше переименовать в нейтральное, например «Чистые».

## Файлы
- `snd/<набор>/<событие>.mp3` — моно, 44,1 кГц, 64 кбит/с, каждый ≤ 30 КБ.
- `snd/отчёт.json` — длина, размер, пик и громкость каждого звука после проверки.
- `js/sfx-<набор>.js` — те же mp3 в base64; приложение грузит только выбранный набор.
