# README для ИИ — Z Code, Claude и любой другой агент

Проект: **«Языки по кино»** — Telegram Mini App ([@languagegamesbot](https://t.me/languagegamesbot)): английский и немецкий по сценам из фильмов, сериалов и интервью. Плюс раздел «Игры» в «Кино» — диалоги героев Deadlock с живыми портретами и настоящими репликами из игры.

Хозяин — **Андрей, не программист**. Пишет по-русски, коротко, с матом и опечатками. Отвечать так же: по-русски, коротко, прямо, без воды. «Го» / «давай» — начинать; «не начинай» — ждать.

**Сайт = ветка `main` через GitHub Pages.** Что попало в `main`, сразу видят игроки (приложение само перезагружается по `version.txt`). Поэтому в `main` — только проверенное.

Обновлён: 24.10.2026, версия **13.9.65**.

## 3. Нельзя никогда

1. Менять id фраз (`i_j`), номера и порядок эпизодов (`parts`, `ph`), ключи хранилища (`dota_quiz_v4`, `dota_sc_v1`, `dota_m_v1`, `dota_r_v1`, `dota_flags_v1`) — на них прогресс игроков в облаке Telegram.
2. Класть в репо ключи, токены, пароли (и в `scripts/`, `tools/`). Ключи — только файлом вне репо. Не просить ключи «через форму» или в чат. Глобальный ключ Cloudflare не использовать — только токен на R2.
3. Сборщики, npm, ES-модули, переписывать файлы целиком, переформатировать JSON целиком.
4. `backdrop-filter`, `filter: blur`, `mask` на больших и фиксированных слоях (лаги на iPhone). Анимировать только `transform` и `opacity`. `.screen` — без `transform`.
5. Выдумывать механику без просьбы (пример: резка эпизодов `zaiChunk` в 13.9.56 сломала видео и прогресс у всех).
6. Переделывать словарь «Мои фразы и слова» (Андрей его любит) и бота.
7. Сцены 18+ без `"age":18`. Выдуманные факты (`fact`). Тексты песен. Мат в репликах — оставлять как в оригинале.
8. Писать в отчёте неправду: «проверено», если не запускал; «убрал всё», если убрал часть.
9. Коммитить симлинки (ярлыки на папки). Сайт собирается Jekyll'ом, и на симлинке он падает: в 13.9.66 так попал `от-второго-клауда/тесты/cache` → сборка красная, игроки остались на 13.9.65. Перед пушем: `git ls-files -s | grep ^120000` — должно быть пусто. После пуша в `main` — проверить, что сборка сайта зелёная («pages build and deployment» в Actions) и `version.txt` на сайте новый.

## 4. Как делать

1. Ветка от свежего `main` (`git fetch origin && git checkout -B <ветка> origin/main`): Z.ai — `z-ai-version` или `zai/<задача>`, Claude — своя `claude/…`.
2. Правки точечные. CSS — новым слоем в конец файла с шапкой `/* ==== 13.9.xx — что это ==== */`.
3. Версия — новая, **в трёх местах сразу**: `APP_V`, `var V`, `version.txt`.
4. Поменял `data/*.json` → `python3 tools/rebuild_all_data.py`; сцены → ещё `check_data.py` и `check_ctx.py`.

## 5. Проверка перед `main`

```bash
node -e "new Function(require('fs').readFileSync('js/app.js','utf8'))"      # синтаксис
python3 -m http.server 8080 --bind 127.0.0.1                                  # сайт (в корне репо)
cd от-второго-клауда/тесты && cp ../../bot/worker.js botw.mjs && node stand2.mjs   # стенд воркера (нужен pay.js и дуэлям)
NODE_PATH=/opt/node-tools/node_modules node s1.js                             # и т. д., ph и pc
grep -n backdrop-filter styles/*.css                                          # новых не добавлять
```

- Минимум: `s1.js`, `nd.js`, `ndplay.js`, `qlen.js`, `tr.js` (ph и pc) + тест своей темы. Deadlock — `dd.js ph|pc`.
- Размеры: телефон 390×844 и ПК 1440×900, консоль без ошибок.
- Тест упал — сначала проверь, красный ли он на чистом `main` (`git worktree add /tmp/base origin/main`, сайт на другом порту, `ST_PORT=8090 node …`). Красный и там — не твой, напиши в отчёте. Красный только у тебя — чини причину, тест «под себя» не правь.
- Видео для стенда лежат в `тесты/cache/` (в `.gitignore`, имя = путь в R2 через `__`, формат webm — Chromium Playwright не играет H.264).
- После пуша в `main`: `git push origin <ветка>:main` только fast-forward (`git merge-base --is-ancestor origin/main HEAD`).
