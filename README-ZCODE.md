# README для Z Code — с чего начать работу в этом репо

Проект: **«Языки по кино»** — Telegram Mini App (@languagegamesbot): английский/немецкий по сценам
из фильмов, плюс раздел «Игры» (диалоги героев Deadlock с живыми портретами и настоящими репликами).
Хозяин — Андрей (не программист, пишет по-русски, коротко и по делу). Сайт = ветка `main` через
GitHub Pages: что в `main`, то видят игроки.

## Чтение по порядку (первое сообщение в чате Z Code)

1. **`ДЛЯ-ZAI.md`** — правила работы с проектом (писал Claude): что нельзя, как проверять, форма отчёта.
2. **`z.ai`** — свежий контекст от Z.ai: что сделано (сейчас 13.9.64) и **задача №1 с ТЗ**.
3. **`CLAUDE.md`** — общий журнал проекта (шапка + конец файла).
4. `от-второго-клауда/тесты/README.md` — стенд тестов.

перевод — панелью внизу. Войс (▸ + автовойс) уже работает — сохранить. Мобильный формат 390×844 —
первый. Дальше по списку — хвосты в `z.ai`.
