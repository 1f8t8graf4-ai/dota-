## 3. Архитектура (не менять!)

- **Без сборщиков, без ES-модулей.** Один большой файл **`js/app.js`** (~430 КБ), `styles/main.css`, `index.html`. Андрей открывает `index.html` двойным кликом — поэтому есть `data/all-data.js` (все JSON одним скриптом) для режима `file://`.
- `index.html` грузит обязательные JSON (`icons, dota, words, lore-vocab, tips, spy, scenes`) и необязательные (`topics, scenewords, glossary`). Нет обязательного — пишет, какого файла не хватает.
- **После любого изменения JSON — пересобрать `data/all-data.js`** (Python: объединить все JSON в `window.__DATA_ALL={...}`).
- Хранилище: localStorage + Telegram CloudStorage. Ключи **не менять**: `dota_quiz_v4` (store), `dota_m_v1`, `dota_r_v1`, `dota_sc_v1` (прогресс сцен), `dota_flags_v1`.
- 3D-маскот (`js/mascot/mascot-engine.js`, model-viewer) грузится только на телефонах; на ПК — класс `lite` (без тяжёлых эффектов). Все **заставки маскота на весь экран отключены** — Андрей их ненавидит. Остался маленький значок в шапке проверки.

## 5. Как устроено обучение (9.0)

**Принципы (научно подтверждённые):** понятный ввод (сцены) → **вспоминание, а не узнавание** → **интервальное повторение 1-3-7-21-60 дней** → своё (слова, на которых споткнулся) → понемногу каждый день.

### Эпизод — 3 вкладки: ① Смотри · ② Разбор · ③ Проверка
- **Смотри:** чистое видео; субтитры лежат на видео (градиент снизу, английский крупный жирный, перевод меньше). **Слова на видео НЕ нажимаются** (Андрей попросил). Под видео — подсказка, кнопка, список **«Все реплики · нажми на любое слово»** (тап → карточка снизу: перевод слова, выражение если есть, «▶ Услышать», «☆ В мои слова»; на ПК — подсказка при наведении).
- **Разбор:** фразы **по одной карточкой** («Фраза 1 из 4»): фраза (слова нажимаются), перевод, короткое пояснение, слова эпизода из фразы, пример «в жизни», кнопки «▶ Услышать / 🐢 Медленно / 🔁 Вслух», листание ‹ › и свайпом. В конце — «К проверке» / «Проверить слова эпизода».
- **Проверка (до 5 заданий, типы чередуются):**
  - «Послушай и собери» — видео показывает момент, собрать реплику из кубиков;
  - «Что это значит?» — с ручными ловушками (`trap`), объяснение ловушки;
  - «В жизни · собери пример» по русскому переводу;
  - «Собери фразу»;
  - «Впиши пропущенное слово» — **ввод руками**, опечатка в 1 букву засчитывается (жёлтое), подсказка «N букв, начинается на…», вставка отключена.
  - **Кубики:** без точек/запятых/заглавных (I остаётся I; немецкий регистр сохраняется); **сначала «вспомни сам»** — кубики появляются по кнопке или через 3,5 с; **ловушки — другие формы тех же слов** (been/being/be, come/came, by/to, a/the — только настоящие слова из `GLOSS`); фраза впервые — без ловушек; длинные (>9 слов) — кусками по 2; «Проверить»/«Сбросить» только когда положен кубик; **3 попытки** с зелёными/красными кубиками («на месте 3 из 6»); собрал со 2–3 попытки = для повторения это ошибка.
  - Серия «🔥 3 подряд», итог с точностью %.
- Ошибка не стирает выученное — фраза вернётся.

### 9.1 — подача фразы (по просьбе Андрея)
- **«Зачем запоминать» убрано везде.** У фразы теперь: перевод → **«Когда применяется»** (+ «Например» — пример из жизни) → **«Интересный факт»** (если есть, напр. Just Say No — лозунг Нэнси Рейган). Одинаково в «Разборе», после ответа в проверке и в итогах «Что закрепили». Функция `phInfoHTML(f)`.
- **Важные слова** (`f.kw`) подсвечены цветом фильма: на ПК — навести, на телефоне — нажать → карточка: слово, перевод, когда применяется, пример, «☆ В мои слова». Функции `kwWrap`, `kwShow`, `kwBind`.
- Кнопки «▶ Услышать / 🐢 Медленно / 🔁 Вслух» → **«▶ Послушать в сцене»** и **«🐢 Медленнее»** («Вслух» убрана).
- Задание «В жизни» → **«Примени в жизни»**: ситуация по-русски + явно показана фраза из сцены, по схеме которой надо сказать.
- Контент (use/fact/lx/kw для 230 фраз) написан в 9.1; факты — только проверяемые. Если Андрей найдёт неточность — править в `scenes.json` и пересобрать `all-data.js`.

### 9.2 — затягивание
- **Сцены по сложности:** `lvl<=2` открыты сразу, `lvl 3` — 400 монет, `lvl 4+` — 800 (`SC_PRICE`, покупка `scBuy`, открытые — `store.scOwn`). Админ видит всё.
- **Путь сцены (как Duolingo):** эпизод открывается после проверки предыдущего (`scEpOpen`), за эпизод 1–3 звезды (`P.st[i]`), в конце **«Финал сцены»** — 8 фраз на слух без субтитров (`scBossStart`, `P.boss`).
- **Монеты:** первая проверка эпизода +20 и +8 за верный, улучшение звёзд, финал +150, верный ответ на задание в видео +5 (один раз на фразу).
- **Задания прямо в видео** (`scVQ`): при просмотре целиком видео встаёт после ключевой фразы; если субтитры с оригиналом — «когда так говорят?», без субтитров — «что он сказал?» (одно слово подменено). 12 с, потом видео идёт дальше. Выключается галочкой / в настройках (`store.vtask`).
- **Тест уровня** (`renderLevelTest`, 8 вопросов) перед первым эпизодом → `store.lvl` `a` (новичок) / `b`. Новичку: выбор перевода, сборка без лишних слов с первым словом, слово из вариантов, без «примени в жизни».
- **Любое слово во фразе нажимается** (`phBind`): подсвеченные — карточка с примером и «когда применяется», остальные — перевод из словаря + фраза. Факт показывается один раз за заход.
- **«Все фразы сцены»** (`renderSceneSum`) — столбики «Можно везде / Среди своих / Грубо» + «Важные слова»; открывается со страницы сцены и после финала.
- **Музыка:** тише (0.18), случайный трек, плавное появление; тап по плашке → плеер (`musSheet`).
- **3D-фон** (`js/bg3d.js` + `js/vendor/three.min.js`): app — кинозал, noir — стол с клетчатой скатертью, taxi — улица под дождём, wolf — офис и котировки, bone — визитки, bunker — лампа над картой, pump — клуб. 30 fps, замирает во время видео, сам выключается на слабых устройствах; выключатель в Настройках (`store.bg3d`).
- Перевод фраз выгружается в `переводы-9.2.md` — Андрей отдаёт другим нейросетям на проверку. **Делать такой файл после каждой новой сцены.**

### «Повторение на сегодня» (главная) — одно ежедневное повторение
Очередь из фраз (интервалы `P.r[id]=[шаг, когда]`, `SC_DAYS`) и «Моих слов» (свои интервалы). Задания: **диктант** (звучит реплика актёра → напиши; регистр/знаки/сокращения/опечатки прощаются, после — зелёным услышанное, подчёркнуто пропущенное; 🐢 медленно; подсказка), «вспомни по-английски» (показать ответ → вспомнил/нет), карточка своего слова. Не вспомнил — вернётся через 3–4 шага и завтра.

### Прочее
- **«Мои слова»** — сохранение из карточки слова; список с репликой и моментом; тренировка (пары, «что значит»).
- **Субтитры «Авто»** (по умолчанию): первый просмотр — с переводом, повторный — только оригинал.
- **«📚 Все фразы сцены»** на странице сцены — список фраз сцены с фильтрами (мои/все, темы, тон, поиск). Общий словарь с главной убран.
- **Фраза дня** на главной, **🔥 серия** в шапке, «Освоение сцены» (золотая рамка на 100%).
- **«Как пользоваться»** в Профиле + обучающие карточки при первом входе в эпизод (кнопка «?»).

## 7. Видео

- Исходники Андрея слабые (1080p, но 1–2,5 Мбит/с — качались через сайты-резалки). Чтобы было «как в тиктоке», нужны **исходники получше** (файл фильма / yt-dlp в максимальном качестве, сцена целиком — резать самим).
- Текущая обработка (архивы `scenes-clean-1…4`): нарезка из исходника по `parts[i].a/b` → **`hqdn3d=2.5:2:6:5` (убрать зерно/«пыльцу») → `unsharp=5:5:0.55:3:3:0`** → x264 veryfast **CRF 17**, `aq-mode=3`, yuv420p, faststart; Бункер — `crop=iw:ih*0.8:0:0` (вшитые субтитры внизу); звук — **только `loudnorm=I=-16:TP=-1.5:LRA=11`** (компрессор/EQ убраны — вытягивали фон). Без исходников (Сопрано 2×06, первые Психопат и Таксист) — чистка существующих 1080p.
- **Ошибка, не повторять:** резкость без шумоподавления усиливает шум (так было «мыльно-шумно»).
- Превью эпизода — `01.jpg`…; обложки — `cover.jpg` (сцена), `poster.jpg` (фильм); музыка — `m1.m4a`… (список в `music[]` сцены).
- Тайминги фраз: 19 фраз выровнены по репликам; звук фразы ждёт перемотки (`seeked`) перед воспроизведением, хвост +0,12 с; субтитры показываются с задержкой `SUB_LAG=0.18 с`.

## 10. Открытые задачи / идеи

- **Проверка свободного ответа нейросетью** («ответь в ситуации») — единственная серьёзная дыра в методике (нет своей речи/письма). Нужен ключ API на сервере.

- Новые сцены (присылает Андрей с srt) и **исходники лучшего качества**.
- Уровни (тест на старте), прогресс на сервере (сейчас только устройство), режим «пауза после каждой реплики», сцены на других языках, PWA/магазины (только через YouTube-встраивание и свой маскот — из-за прав).
