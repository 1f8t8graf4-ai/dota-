# Тесты аудита (Playwright)

Скрипты, которыми проверялся аудит: `от-второго-клауда/аудит-кода.md`.

## Подготовка
1. Сайт из корня репо:
   ```
   python3 -m http.server 8080 --bind 127.0.0.1
   ```
2. Воркер на `node:sqlite` (нужен для `s2.js` и флагов):
   ```
   cp ../../bot/worker.js botw.mjs && node stand2.mjs
   ```
   Поднимается порт 8788, `BOT_TOKEN` = `123:TEST`.
3. Медиа сцен — в `./cache`. Имя файла — путь с `__` вместо `/`, например `american-psycho__01.mp4` (webm внутри). Если файла нет, сервер отдаёт 404: приложение это переживает, просто видео не играет.
4. Playwright из `/opt/node-tools/node_modules`:
   ```
   NODE_PATH=/opt/node-tools/node_modules node s1.js
   ```

## Что делает каждый
- **`st.js`** — сам стенд:
  - фейковый `Telegram.WebApp` с `CloudStorage` в памяти (`window.__cloud`, `__cloudFail`, счётчик `__sets`);
  - `telegram.org` подменён пустым скриптом;
  - `workers.dev` → 8788 (с `worker:true`);
  - подпись initData — `initData(id, имя)`.
- **`s1.js`** — 29 сценариев по пунктам аудита. Пишет PASS/FAIL и итог.
- **`s2.js`** — дуэль двумя игроками по `wolf-lunch-de` со ставкой 25. Проверяет: вопросы на немецком, банк начисляется сразу, не задваивается.
  - Строка «текст без рода» ждёт заголовок вида «Аня — точнее». В `main` 13.7.1 другой текст: «Побеждает Аня — …». Это нормально, проверка устарела.
- **`kn5.js [ph|pc] [real|demo]`** — 13.9.5, скрины «как у Андрея» (реальный прогресс, ~14 фраз и 5 слов) или демо: Кинотека на весь экран, фильм, «Мои фразы и слова» (экран, раскрытая тема, страница фильма, слова).
- **`kn4.js [ph|pc]`** — «Новый словарь» 13.9.5 (вариант `kino`, демо-карты), PASS/FAIL: Кинотека без списка фраз, фильм — сцены строками, сцена — эпизоды свёрнуты и раскрываются, окно фразы, «смотреть» с фильма/эпизода, поиск; «Мои фразы и слова» — переключатель, один экран (темы, «Все»), тренировка темы и возврат, слово в окне, пустые экраны.
- **`kf.js [ph|pc]`** — 13.9.1, Кинотека на весь экран: заголовки разделов — кнопки, окно «1 / N», живой момент только у текущего слайда, листание (свайп / ←→ / точки), «Открыть» → страница фильма, «Смотреть» → сцена, выход ✕ / «назад» / Esc / свайп вниз, кнопка «назад» Телеграма показывается и прячется, интервью — фон из обложки; 13.9.4 — «‹» на странице фильма и сцены настоящим кликом.
- **`km.js [ph|pc]`** — 13.9.7, «Мои фразы и слова» в двух видах: старый выбор вида → «Карточки»; поиск виден сразу и ищет по фразам и словам (✕ очищает); карточки по фильмам (числа, Волк первым, раскрыл — «Сцена 1 / 2», эпизоды, строки, окно листает всю карточку), ▶ на кадре — «подряд» без раскрытия, открытые помнятся, «Тренировать» без самопроверки и назад, «По темам» с разными кадрами; постеры, чип темы, страница фильма (тема ✕, сцены, эпизоды 6/3/3, окно листает весь фильм), **«‹» настоящим кликом** и «назад» Телеграма; слова — постеры и карточки, «Добавлено мной» последним; окошко слова без дубля; без анимаций. **13.9.8 — окно фразы:** само не играет, видео свёрнуто; «Послушать» — звук, слова фразы загораются; «Смотреть» — видео раскрыто; «Подробнее» без статуса и открытого факта; факт раскрывается; «▶ подряд» играет само; слово — «Слово · Смотреть».
- **`tr.js [ph|pc]`** — 13.9.5, тренировка/повторение `renderDaily`: нет «Вспомни по-английски» и «Знал / Не знал», кубики (ошибка → разметка и «Попытка 2 из 3», сброс, верно), слово — выбор из 4 разных вариантов, ошибка — слово возвращается ещё раз, итог.
- **`sub.js [ph|pc]`** — 13.9.4, слово в субтитрах эпизода (`wolf-of-wall-street`, эп. 1; медиа `wolf-of-wall-street__01.mp4` в `./cache`): «Name of the game» — без «часть выражения», фраза один раз; «Fuck the clients» — настоящее выражение на месте.
- **Выход проверять настоящим кликом** (`page.click` по «‹»), а не вызовом `DL.back()`: в 13.9.3 кнопка на странице альбома не была привязана, а тест, жавший `DL.back()`, этого не видел.
- **`pf.js [ph|pc]`** — 13.9.6, фон в профиле: «В профиль» в Коллекции, карточка игрока на фоне, «назад» из Коллекции в Профиль, дуэль двумя игроками (воркер-стенд): ожидание, приглашение, экран «ты против друга», победа, реванш; профиль игрока по тапу (окно `.pfv`, цифры из комнаты); старт ролика перед событием (поддельное `filmbgev`/`bgev` = 6 с). Фоны — `cache/<сцена>__film-bg.mp4` и др. (webm), скрины — в `SHOTS` (по умолчанию `./shots-pf`).
- **`s3.js [ph|pc]`** — все вкладки и экраны плюс все сцены (страница, эпизод, «Все фразы», проверка до итога). Долгий: ~15–25 минут на устройство.

Начальные данные подсаживаются один раз на контекст (`sessionStorage.__seeded`). Иначе перезагрузка страницы заново подложит прогресс, и тест сброса покажет ложный FAIL.
