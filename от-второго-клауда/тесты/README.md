# Тесты аудита (Playwright)

Скрипты, которыми проверялся аудит: `от-второго-клауда/аудит-кода.md`.

## Подготовка
1. Сайт из корня репо:
   ```
   python3 -m http.server 8080 --bind 127.0.0.1
   ```
2. Воркер на `node:sqlite` (нужен для `s2.js` и флагов):
   ```
   cp ../../bot/worker.js botw.mjs && node stand2.mjs
   ```
   Поднимается порт 8788, `BOT_TOKEN` = `123:TEST`.
3. Медиа сцен — в `./cache`. Имя файла — путь с `__` вместо `/`, например `american-psycho__01.mp4` (webm внутри). Если файла нет, сервер отдаёт 404: приложение это переживает, просто видео не играет.
4. Playwright из `/opt/node-tools/node_modules`:
   ```
   NODE_PATH=/opt/node-tools/node_modules node s1.js
   ```
