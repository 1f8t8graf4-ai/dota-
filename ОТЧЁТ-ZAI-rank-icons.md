# ОТЧЁТ-ZAI-rank-icons — эмблемы рангов в хорошем качестве (03.11, Зетка)

Ветка `zai/rank-icons`, папка `restless/rk/`. Код сайта не трогала — подключай сам.

## Что сдано

- **67 значков** = 11 тиров × 6 ступеней (`1-1.webp` … `11-6.webp`) + «без ранга» (`0-0.webp`, Obscurus);
- у каждого **256 px** (`<tier>-<sub>.webp`) и **64 px** (`<tier>-<sub>@64.webp`) — прозрачный фон, webp;
- `ranks.json` — `{tier: {name, ru, color}}`;
- `restless/rk/index.html` — страница проверки: все 67 сеткой на тёмном фоне, подпись под каждым, под большим значком тот же в 64 px;
- скрины: `restless/rk/скрин-ПК-1440x900.png`, `restless/rk/скрин-телефон-390x844.png`.

## Источник — важное

По порядку из ТЗ:

1. **Файлы игры — взяты, но через зеркало.** GameTracking-Deadlock в этой среде **не клонируется**: `git clone --depth 1 --filter=blob:none|tree:0` виснет на переговорах больше 4 минут (репо — миллионы файлов, серверная фильтрация не отвечает), GitHub API — rate limit (IP песочницы общий, лимит выбирается другими), jsDelivr — «Package size exceeded the configured limit of 50 MB».
   Поэтому взяла **те же файлы игры из индекса картинок deadlock-api** (`/v1/assets/images` → `ranks/rankN/badge_lg_subrankM(_psd).png`, бакет `assets-bucket.deadlock-api.com`) — это выгрузка тех же игровых ассетов (структура путей = панорама игры), приоритет отдавала `_psd` (исходное разрешение): 500×500 и выше, против 404×324 у `/v1/assets/ranks/N/M/image`, которые сайт использует сейчас.
2. Fallback из ТЗ (`large_subrank…webp`) не понадобился — но это те же 404×324.

## Обработка

- обрезка пустых полей по альфе с порогом 8 (отсекает шлейф свечения, значок не режем);
- 4 % воздуха с каждой стороны, квадрат, центрирование по значку;
- LANCZOS в 256 и 64.

Проверено глазами по контроль-листу всех 67 и по скринам страницы: **ни один значок не обрезан по краю, все одного видимого размера, фон прозрачный** (тёмная подложка страницы = реальный фон сайта).

## Русские названия — НЕ сделал, и вот почему

В ТЗ: «только из локализации игры (файлы resource/…russian…), не придумывать».

- В GameTracking-Deadlock русской локализации **нет вообще**: в `game/citadel/resource/localization/` лежат только английские модули (`citadel_main`, `citadel_gc`, `citadel_heroes`, `citadel_generated_vo` и т. д.). Русский (и все прочие языки) Valve кладёт в отдельный языковой VPK, который SteamDB не трекает (в `files.json` репо — только `pak01_dir.vpk`).
- Готовые русские файлы в сети — только машинные переводы сообщества (репо с «ChatGPT-4o» в авторах) — по правилу «не придумывать» их брать нельзя.
- Английские имена взяла из локализации игры: `citadel_main_english.txt`, токены `Citadel_ranks_0..11` (Obscurus, Initiate, Seeker, Acolyte, Sentinel, Mystic, Ritualist, Emissary, Oracle, Phantom, Ascendant, Eternus) — совпадают с `/v1/assets/ranks`.

**В `ranks.json` поле `ru` пока = английскому имени, в самом файле — пометка `_note`.** Клауд, варианты: (а) Андрей снимет экран RU-клиента со списком рангов — впишу дословно; (б) появится русский файл в GameTracking — заменю; (в) если для сайта не критично — оставляй как есть, поле готово.
