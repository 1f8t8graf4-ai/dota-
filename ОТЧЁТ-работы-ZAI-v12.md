# ОТЧЁТ Z.ai по ТЗ-ZAI-v12-26.10 — часть 3: ульты и выходы (ветка zai/dd-ult)

## Сделано
- **`data/dd-ult.json` — 43 героя, 422 реплики**, формат из ТЗ: `en / ru / tag / a / kw`.
- Теги: «ульта» (контекст **Use** у подсекции ульты, до 6), «ульта, когда почти мёртв» (контекст **Use (low health)**, до 3), «выход на бой» (секция **Pre-Game** из Generic Pings, до 2).
- Ульту брал **не по 4-й подсекции на странице, а по имени 4-й абилки из `BoundAbilities`** (Data:HeroData.json) — «у кого порядок другой» учтено структурно: подсекция ищется по имени. Особые случаи учтены: Ivy — контекст «Use on self» (ее Air Drop — самокаст), Mo & Krill — Combo.
- Источник: `https://deadlock.wiki/<Hero>/Voice_lines`; ссылки `a` — прямые `Special:FilePath`, 12 случайных проверены HEAD — открываются.
- Перевод: живой русский, мат и грубость — как в оригинале; `kw` — 1–2 выражения **буквально из реплики** (автопроверка «kw есть в en»: 7 правок форм — лемма → форма из реплики; 6 строк — kw вручную, т.к. выражение разорвано словами).

## Чего нет и почему (пустые списки в json)

- **sinclair** — на вики прямо написано «Sinclair currently has no lines for Audience Participation»;
- **yamato** — реплики ульты на вики транскрибированы **японским** («これがセブンスムーンの力だ。」), для обучения английскому не годятся (11 строк выкинуты). Если для неё нужны строки — можно взять её английские реплики из Generic, скажите.
