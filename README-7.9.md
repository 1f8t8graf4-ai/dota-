# Языки по кино — полный README (версия 7.9)

Telegram-бот **@languagegamesbot** + мини-приложение: учим английский и немецкий по сценам из фильмов и сериалов, плюс игры. Этот файл — сводка по всем темам, которые поднимались: что сделано, что нет, что ждёт тебя, словарь терминов и словарь фраз по темам.

## 1. Что сделано в 7.9 (поверх 7.8 от другой нейросети)

1. **Видео не грузились у всех сцен — две причины.**
   - Неверный адрес. Репозиторий `scenes` публикуется как `https://1f8t8graf4-ai.github.io/scenes/`, папки сцен лежат в его корне, а приложение просило `…/scenes/scenes/<сцена>/…`. Исправлено в `index.html`: `ASSET_BASE='https://1f8t8graf4-ai.github.io'`. Проверено: адрес стал `…/scenes/wolf-of-wall-street/01.mp4`.
   - **Видео в репозитории нет.** Проверил репозиторий: у 10 сцен из 12 лежат только обложки и музыка, а `01.mp4…` и превью нет. Целиком есть только Таксист 2 и Сопрано 6×09. Недостающие видео — в `scenes-video-1/2/3.zip` (папки сцен в корне архива, как в репозитории).
2. **ПК лагал.** Причина — 3D-маскот: при каждом запуске грузился model-viewer (~1 МБ кода) и WebGL. Теперь 3D грузится только на телефонах; на ПК маскот — картинка, а тяжёлые эффекты (размытие фона, бесконечные анимации, «аврора») выключены (класс `lite`).
3. **Маскот-картинка.** Из присланного кадра сделан круглый портрет с золотым кольцом (`img/bateman.png`, прозрачный фон) вместо прямоугольной фотографии с потолком.
4. **Словарь фраз с темами.** Блок «Словарь фраз» на главной: все 165 учебных фраз из сцен, фильтры «Все / Только мои», **12 тем** и **тон** (грубо / разговорное / официально / нейтрально), поиск, звук из фильма, переход к моменту. Темы — на карточках фраз в эпизоде. Темы лежат в `data/topics.json` (+ `data/topics.js` для запуска двойным кликом), `scenes.json` не трогается.
5. **Починил то, что сломалось при сборке 7.8:** вернул пропавшие `scTag`, `scPattern`, `scClip`, `remindSync` (без них падали карточки, звук фраз и напоминания); защитил плеер от ошибки после выхода из эпизода. Словарь слов из игр (`renderDict`) не задет — словарь фраз назван `renderPhraseDict`.
6. Проверено в браузере (телефон и ПК): главная, словарь, фильтры, проверка эпизода в режимах English и Deutsch — ошибок нет.

### 7.9.6 — выражения в субтитрах
- Если в реплике есть учебная фраза (например «Fuck the clients»), её слова в субтитрах подчёркнуты пунктиром.
- **Нажал** на такое слово — видно и слово («clients — клиент»), и смысл всего выражения («Fuck the clients — да похуй на клиентов» + короткое пояснение). Видео на паузе, «Дальше» / «Ещё раз реплику».
- **ПК: навёл мышкой** — маленькая подсказка без паузы: слово, перевод, «выражение: …».
- Слова вне выражений — как раньше: перевод слова, а если его нет в словарике — перевод реплики. Чем больше слов в `data/scenewords.json`, тем больше слов переводится по одному.

### 7.9.5 — полный экран на ПК без прыжков
- Выход из видео на весь экран больше **не сворачивает сам мини-апп** — именно это на ПК выкидывало обратно в маленькое окно с багами. Мини-апп остаётся на весь экран, видео возвращается в обычный вид.
- Если выйти из полного экрана кнопкой Telegram или Esc, видео тоже аккуратно возвращается в обычный вид.
- Видео на весь экран отступает от кнопок Telegram сверху (⋮ и ×) — плашка сверху больше не налезает на кадр.
- Крестик закрывает приложение сразу: подтверждение закрытия включается только в онлайн-«Шпионе» и выключается при уходе оттуда.

### 7.9.4 — «Не загрузились данные»
- Причина: в репо не стало `data/scenes.json` и `data/all-data.js` (при перезаливке папки `data` их не было в архиве). Без списка сцен приложение не запускается.
- Теперь оба файла снова в архиве. Клип Lil Pump в `scenes.json` — только описание и ссылки, без текста песни: строки клипа приложение берёт из твоих `orig.srt` / `ru.srt` в папке клипа (см. раздел про клипы).
- Загрузчик стал умнее: если нет необязательных файлов (`topics`, `scenewords`) — приложение всё равно открывается; если нет обязательного — пишет, **какого именно файла** не хватает.

### 7.9.3 — бот: статистика и метки источников
- **`/stats`** (только админу): всего людей, новые за сутки и неделю, активные, **сколько вернулось на 2-й день и через неделю**, откуда пришли (по меткам), что делали (открыли, досмотрели эпизод, прошли проверку, тест слов, словарь, повторение), сцены с наибольшим числом проверок. Ты сам в статистику не попадаешь.
- **Метки для рекламы:** ссылка на бота `t.me/languagegamesbot?start=tiktok` (или `insta`, `chat_de`, `vasya` — любое слово) — человек записывается с этим источником. Прямо в мини-апп: `t.me/languagegamesbot/<app>?startapp=src_tiktok`.
- Приложение тихо отправляет события в бота (`/api/ev`), таблицы `users` и `events` в D1 создаются сами.
- После заливки **обнови воркер** в Cloudflare (`bot/worker-6.0.js` → Edit code → Deploy).

### 7.9.3 — пилот «слова вместо зубрёжки фраз» (Волк, эпизод 1)
- **Слова в субтитрах нажимаются.** Тап по любому слову оригинала — видео на паузе, перевод слова (★ если это слово эпизода, плюс немецкий). Слова нет в словарике — показывается перевод всей реплики. «Ещё раз реплику» — переиграть её.
- **«Слова эпизода»** на экране эпизода: 12 ключевых слов (job, client, firm, excited, responsibility, girlfriend, married, wife, money, pocket, advantageous, congratulations) — перевод, немецкий, реплика из сцены с подсветкой, «▶ услышать в сцене». Вводная эпизода показывает слова, а не цитаты.
- **Подсказка в плеере** на этих репликах — «★ слова: job — работа…» вместо целой фразы.
- **Тест по словам** (≈10 заданий): «Соедини пары» (слово ↔ перевод), «Что значит слово?» (слово подсвечено в реплике), «Послушай реплику — какое слово услышал?» (звук из фильма), «Вставь слово», в конце снова пары. Итог по словам, ошибки вернутся.
- Данные: `data/scenewords.json` (+ `scenewords.js` для запуска двойным кликом): по сцене и эпизоду — ключевые слова `[слово, перевод, немецкий, формы]` и словарик остальных слов. Добавить слова другому эпизоду = дописать туда запись, код не трогать.
- **Проверка установки** в админке (7.9.2): одной кнопкой видно, что не залито.

### 7.9.1 — полный экран на ПК и подсказки в плеере
- **Полный экран на ПК снова работает.** В 7.8 его вернули «только для телефонов» (`canFull`). Теперь мини-апп разворачивается на весь экран и на ПК, а кнопка «на весь экран» у видео сначала разворачивает сам мини-апп — иначе видео растягивалось только внутри маленького окна Telegram.
- **Подсказки в плеере при каждом просмотре.** Раньше они появлялись только на втором просмотре (с остановками). Теперь, когда звучит учебная фраза, сверху в кадре появляется плашка «★ учим эту фразу» с коротким пояснением — без паузы, в маленьком плеере компактно в одну-две строки, в полном экране целиком (`scChip`). Второй просмотр с остановками и разбором остался.
- Разбор «шаблона» из пояснения стал строже (не путает части пояснения).

## 3. Что сделать тебе

1. **Долить видео в репозиторий `scenes`:** распакуй `scenes-video-1.zip`, `-2`, `-3` и загрузи папки **в корень** репозитория (туда же, где уже лежат папки сцен), с заменой. Файлы до 25 МБ — веб-загрузка GitHub их принимает.
2. **Обновить основной репозиторий:** из `dota-7.9-files.zip` положи файлы поверх, с заменой. `data/scenes.json`, `data/all-data.js` и остальное, чего нет в архиве, не трогай.
3. Если ещё не сделано: `worker-6.0.js` в Cloudflare + **Cron** `0 * * * *` (напоминания).
4. Выбрать в лаборатории (Профиль → Админ-панель): субтитры, звуки, интерфейс — напиши мне, раскатаю на всех.
5. Название бота — в BotFather.

**Длинные сцены, которые не отправляются в чат.** Два способа: обрезать на телефоне до 2–3 минут (нужный момент), или загрузить ролик в GitHub (в репозиторий `scenes`, отдельную папку, или как Release) и прислать ссылку — с GitHub я могу скачать сам. Плюс английский srt (для немецких фильмов — немецкий).

## 4. Про клип Lil Pump и тексты песен

Тип `kind: "clip"` в системе сцен работает, архитектуру я не трогаю. Но **тексты песен я не пишу, не перевожу и не правлю** — это авторский контент. Запись клипа в `scenes.json` и mp3 я не менял и **в свои архивы не включаю** (поэтому `scenes.json` и `all-data.js` в архиве 7.9 нет — оставь свои). Клипы с текстами — только через лицензированный сервис (например, Musixmatch) или свои треки.

## 4а. Субтитры клипов из твоих файлов (7.9)

Текст песни в коде и данных не хранится — его кладёшь ты, приложение только читает файлы.

1. В репозитории `scenes` в папке клипа (например `lil-pump-welcome-to-the-party/`) положи:
   - `orig.srt` — оригинальные строки с таймингами;
   - `ru.srt` — твой перевод **с теми же таймингами** (проще всего: скопировать `orig.srt` и заменить строки текста);
   - `de.srt` — немецкий, по желанию.
2. Открываешь клип — приложение подтягивает файлы, показывает строки синхронно и делает из них задания (строки от 3 слов, где есть перевод).
3. Нет файлов — остаётся то, что было в `scenes.json`.

**«О треке»** — по желанию, файл `data/clipnotes.json` в основном репо:
```json
{ "id-клипа": { "about": "общая сводка: о чём трек, настроение, контекст", "slang": [["слово", "что значит"], ["ещё слово", "объяснение"]] } }
```
Сводку трека целиком и разбор отдельных сленговых слов делаю я (без цитирования строк песни). Построчные «что значит» по тексту песни — нет.

## 5. Словарь терминов

- **Сцена** — запись в `scenes.json`: эпизоды (`parts`), все реплики (`subs`: начало, конец, en, ru, de), учебные фразы (`ph`), музыка, сложность/польза, `kind` (`film` / `series` / `clip`), `show` (группа), `lang: 'de'` — немецкий оригинал.
- **Активная фраза** — идёт в проверки и повторение. **Пассивная** (`passive: true`) — только «для понимания».
- **`trap`** — 3 ручных похожих неправильных перевода для «Что это значит?».
- **`ex`** — примеры [en, ru, de]; **`exDe`** — немецкие примеры под жизнь в Германии [de, ru].
- **`topics`** — темы фразы (из `data/topics.json`).
- **Тон** — грубо / разговорное / официально / нейтрально (`scTag`, по словам фразы).
- **Шаблон** — рабочая конструкция из пояснения («have it better = жить лучше», `scPattern`).
- **Освоение сцены** — фраза держится надолго (3-й шаг повторения, 7+ дней) — `scMastered`.
- **`ASSET_BASE`** — откуда грузятся видео/картинки/музыка сцен.
- **`all-data.js`** — все данные одним файлом для запуска `index.html` двойным кликом.
- **`lite`** — облегчённый режим на ПК (без 3D и тяжёлых эффектов).
- **Маскот** — `js/mascot/mascot-engine.js`, события `correct / wrong / streak / learned / episodeComplete…`; модель `img/bateman.glb` (только телефоны), картинка `img/bateman.png`.

## 6. Теги

**Темы (12):**
- 👋 **знакомство** — представиться, имя, возраст, где живёшь, «рад знакомству»
- 💘 **свидание** — позвать, извиниться, комплимент, «можно я позвоню»
- 💬 **общение** — реакции и связки разговора: «дай угадаю», «бывает», «шучу»
- 💼 **работа** — офис, клиенты, правила, «перейдём к делу»
- 💰 **деньги** — зарплата, касса, «кто платит»
- 📚 **учёба** — правила, советы, «как часто»
- ☕ **кафе и магазин** — заказать, сдача, очередь
- 📞 **телефон и планы** — звонки, бронь, отмена, «заскочу»
- 💭 **эмоции** — чувства, настроение, «лучшее позади»
- 😤 **ссоры** — грубость, угрозы, «прояви уважение»
- 🩺 **здоровье** — самочувствие, врач, «ты не ранен?»
- 🏠 **быт** — дом, утро, повседневные мелочи

**Тон (4):** 😤 **грубо** (мат, оскорбления — только с друзьями или в кино) · 💬 **разговорное** (gonna, dunno, yeah…) · 🎩 **официально** (sufficient, circumstances, Umständen…) · ⚪ **нейтрально**.
