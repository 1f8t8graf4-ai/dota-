# ОТЧЁТ-gloss — словарик: слова из реплик героев

**Ветка:** `zai/dd-gloss` (от main). **Статус: готово.**

## Что сделано
- `data/gloss-dd.json` = `{"GLOSS_EN": {…}}` — **649 слов** из реплик героев (`en` из games-new.json ветки zai/dd-lines + games.json main), которых **нет** в `data/glossary.json`.
- Формы как в тексте (rats, shooting); имена героев/названия — «(имя)»; междометия — «(междометие)»; сленг героев переведён (crumbum — «фантик; ничтожество», venatah — акцентное «Венатор»).
- Сборка: `python3 tools/dd_gloss_build.py` (значения — из контекстной базы задачи ctx, `tools/dd_ctx_base.py` взят из ветки zai/dd-ctx).

## Проверки
- 0 слов осталось без значения; все добавленные отсутствуют в glossary.json (скриптом).
- Самые частые добавленные: baroness, die, it's, crumbum, welcome, fight, dead, evil, weren't, unforgettable — полный топ-20 печатает скрипт.
