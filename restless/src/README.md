# Исходники сайта Restless

`restless/index.html` собирается так: база из коммита c03b648 + слои отсюда.

```
git show c03b648:restless/index.html > restless/index.html
python3 restless/src/splice.py
```

`splice.py` вклеивает `lg.css … lg10.css` в главный `<style>` и `lg.js … lg10.js` перед `window.addEventListener('hashchange', route)`.
Пути в `splice.py` — на `/home/user/work/lg/` (рабочая папка); при сборке из репо поправь `P`/пути на `restless/src/`.

- `lg.js` — каркас как League of Graphs (профиль, герои, лайв, мета, лидеры, про, обновления)
- `lg2.js` — кэш запросов, свой сервер, «Статистика» (линия, смерти, экономика, бой)
- `lg3.js` — разбор матча по вкладкам, «Активность», подиум лидеров
- `lg4.js` — виды сайта «Латунь» / «Сталь»
- `lg5.js` — профиль «быстрый взгляд», «Статистика» по вкладкам, патчи по-русски (`restless/upd-ru.json`)
- `lg6.js` — вкладка «Коуч» в разборе матча: оценка, главная ошибка с доказательствами, моменты смертей, «честно о картине», «сохрани», план и задание на 3 игры с проверкой по следующим матчам (`localStorage rl-task`). Считает по цифрам матча, без нейросети
- `lg7.js` — «Коуч» подробно, как у ResoAI: драки (счёт, кто умер первым, был ли рядом), сколько лежал мёртвым, что команда потеряла после смерти, кто бил и чем (`damage_matrix`, способности по герою), падение здоровья, «ушёл живым на N%», предметы против топов на герое (`analytics/item-stats`), «Что делать» и «Почему это задание», «Другие варианты»
- `lg8.js` — вид сайта перенесён в «Настройки» (плашка поверх страниц убрана, `?skin=` работает); в профиле карточка «Коуч Restless»: разбор последнего матча и задание — проверяется само по трём следующим матчам (`coBuildX` собирает разбор без открытия матча)
- `lg9.js` — без перегруза (02.11, Андрей: «ебейшая перегрузка; нажимаю на матч — че за хуйню даёт; непонятно, что клацать»). Профиль: одна полоса «сводка» (ранг, форма за 20 игр, серия, средний матч, сколько играет), слева герои за 30 дней и с кем играет, справа коуч одной строкой и матчи в одну строку (результат, герой, У/С/П, души в минуту, 6 предметов, оценка); метки игрока — в шапке под ником. Матч: открывается «Обзором» — «лицом к лицу» (игроки двух команд парами по линиям) и рядом коротко про выбранного игрока; вкладки Обзор · Разбор · Сборка · Линии · Графики (экономика и урон) · Карта; игрок выбирается кнопкой справа от вкладок вместо ряда из 12 плиток. Верхние разделы: Профиль · Лайв-матч · Герои · Лидеры · Про-игры · Патчи.

- `lg10.js` (03.11, ночь): матч по номеру. В поиске просто число → выбор «Матч № … / Игрок с ID …», «матч 123…» + Enter → сразу матч; в профиле у списка матчей «＋ Матч по номеру». API дотягивает матч из Steam по номеру, даже если его ещё нет в истории. Свой матч, открытый по номеру, запоминается (`localStorage rl-xm`, 21 день) и стоит в истории профиля, пока его не подтянет сама база. Не нашёлся — «пока не нашёлся» и «Ещё раз».
- `lg10.js` (04.11, по отзыву Андрея со скринами):
  - **Анимации:** в базе было правило «меньше движения → гасить всё», у Андрея в Windows оно включено. `splice.py` вырезает такие блоки.
  - **Профиль заново, как League of Graphs.** Слева — ранг-карточка, форма, «что знать», с кем играет, коуч. Справа — «Часто играет» с выбором периода «30 дней / 3 месяца / Всё время» и «Последние игры» по 10. На телефоне сверху ранг и «что знать».
  - **Разбор (коуч) блоками:** заголовок — главная проблема. Дальше разделы «Картина игры · Как это происходит · Смерти · Почему так · Предметы · Что получилось · План» — каждая мысль отдельной строкой (`co10Fix`, `co10Late`).
  - **Раздел «Герои»** с двумя вкладками:
    - «Герои» — сетка как выбор героя в игре: при наведении карточка выпрыгивает, слева превью;
    - «Мета» — Тир-лист · Сильные дуо (герой — не больше 2 раз) · Контрпики · Предметы.
  - **Слова во фразе героя** — подсказка при наведении.
  - **Патчи:** только записи с текстом. Пустые записи форума (одна ссылка на Steam) — в «Новостях».
  - **Лайв:** лица в карточках.
  - **Лидеры:** номер в углу; у скрытого аккаунта — эмблема Eternus вместо пустой карточки.
