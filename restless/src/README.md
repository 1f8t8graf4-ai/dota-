# Исходники сайта Restless

`restless/index.html` собирается так: база из коммита c03b648 + слои отсюда.

```
git show c03b648:restless/index.html > restless/index.html
python3 restless/src/splice.py
```

`splice.py` вклеивает `lg.css … lg10.css` в главный `<style>` и `lg.js … lg10.js` перед `window.addEventListener('hashchange', route)`.
Пути в `splice.py` — на `/home/user/work/lg/` (рабочая папка); при сборке из репо поправь `P`/пути на `restless/src/`.

## lg16 (03.11, ночь) — рейтинг героя как в League of Graphs (Андрей: «суди не только по рангу»; правила — со скрина их «How are players ranked?»)
- **Правила LoG:**
  - два счёта — сезон и 30 дней, сезон весит 3/4;
  - +1 тир → ×5 (тир игры — средний тир врагов);
  - винрейт в 1,5 раза выше среднего по чемпиону → ×2; KDA вдвое выше → ×3;
  - каждый тир ниже — винрейт и KDA весят ×0,6;
  - флекс = 0,4 игры;
  - минимум 20 игр, от 20 до 80 счёт снижается;
  - нужна ранговая за 30 дней; меньше 5 игр за 30 дней → ×0,5 за каждую.
- **У нас** (`hlS`, `hlPool`):
  - всё в логарифмах;
  - обычная игра = 0,4 ранговой (отдельный запрос `match_mode=ranked`);
  - «тир вниз» — от Eternus (`HL_EM`);
  - от 20 до 80 игр — минус столько процентов, сколько игр не хватает до 80.
- **Чего нет в открытых данных:**
