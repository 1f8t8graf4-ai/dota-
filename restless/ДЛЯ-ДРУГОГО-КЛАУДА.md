## Грабли

- Класс `.it` занят базой (`white-space:nowrap` — строка вылезает за экран). Не использовать.
- Анимации входа — только `animation-fill-mode: backwards`, не `both` (иначе слой перекрывает выпадашки и ломает hover).
- `scoreboards/players` по умолчанию `min_matches=20` — на герое с меньшим числом игр пусто. Передавать `min_matches=1`.
- SVG с `preserveAspectRatio="none"` растягивает текст — подписи делать HTML-ом поверх.
- Liquipedia закрыта (ключ, лимиты) — турниров на сайте нет.
- Бот (`js/app.js`): ссылка `startapp=dl_<герой>` обрабатывается через `setTimeout(0)` — `GM` объявлен ниже старта.
