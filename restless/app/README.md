# Restless Overlay — программа поверх Deadlock (0.2)

Окно с панелью матча (наш сайт `?ov=1&app=1#ov`) поверх игры — как Porofessor.

**Почему 0.1 «не работала»:** сайт искал матч через открытый API, а он видит только ~150 топ-матчей — обычного матча там нет. Плюс программа ждала процесс `deadlock.exe`, а игра называется `project8.exe` (окно само не показывалось), и Alt+R занят оверлеем NVIDIA.

**Как в 0.2:**
- Кто в матче, говорит игра: мод Restless 0.13 шлёт на `127.0.0.1:27515` (`bridge.js`) ник, героя и ID каждого из 12. Программа передаёт это сайту (`window.rlGame`), сайт рисует карточки.
- Мод программа ставит сама (`install.js`): находит Deadlock по библиотекам Steam, дописывает строки в `gameinfo.gi` (копия `.restless.bak`), старые паки Restless (пробник 27.10 с плашкой Венатора, 0.10–0.12) переносит в `game/citadel/restless_old`, кладёт `pak42_dir.vpk` (номер занят чужим — 43…99). Пока игра запущена — ждёт, поставит после выхода.
- Начался матч — окно показывается само. **Ctrl+Alt+H** — показать / скрыть, **Ctrl+Alt+T** — клики сквозь окно (заняты — Ctrl+Shift+F10 / F11; какие достались — в меню трея). Тянуть окно — за шапку.
- Значок в трее (у часов) — меню: статус мода и связи с игрой, «Поставить мод заново», «Открыть папку модов», сайт, выход.
- Игру поставить в режим **«Оконный без рамки»** — поверх полноэкранного режима Windows окна не рисует.
- Первый запуск: найди себя в поиске в окне — программа запомнит.

## Сборка
Собирает GitHub Actions (`.github/workflows/restless-app.yml`) на Windows при изменениях в `restless/app/` и кладёт в релиз
`overlay-latest`: https://github.com/1f8t8graf4-ai/dota-/releases/download/overlay-latest/Restless-Overlay.exe

Руками: `npm install && npm run dist` (на Windows) → `dist/Restless-Overlay.exe`.
Новый мод → скопировать `mod/build/pak42_dir.vpk` в `restless/app/` (программа ставит именно его).

Проверка без Electron: `node tools/restless_test/app.js` (установщик на фейковой папке игры + приём данных), сайт — `tools/restless_test/tov.js`.

Программа без подписи — Windows при первом запуске покажет «Windows защитила компьютер» → «Подробнее» → «Выполнить в любом случае».
