# Restless Overlay — программа поверх Deadlock (0.3.1)

Твой профиль Restless поверх игры — как Porofessor. В окне весь сайт: профиль, лайв-матч, герои и вкладка «Оверлей» с настройками.

**Как в 0.3.1** (Андрей, 03.11: «зачем Ctrl+X, если мы всё на Ctrl+H»; «Лайв-матч должен выделяться, а не Оверлей, и только когда матч идёт»):
- **Одна клавиша — Ctrl+Alt+H**: показать / скрыть окно, всегда, и без игры. Ctrl+X больше нет (в Deadlock Ctrl — присесть, X — второй предмет).
  - Занята другой программой — сама берёт следующую: Ctrl+Shift+H → Alt+H → Ctrl+Shift+F10. Сменить — меню трея → «Клавиша».
  - **Ctrl+Alt+T** — клики сквозь окно (занята — Ctrl+Shift+F11).
- **Матч.** Мод шлёт игроков на `127.0.0.1:27515` (`bridge.js`), окно открывается само сразу на 12 игроках (`#ov`). Фокус у игры не забирает. Если в прошлом матче окно закрывали — в новом всё равно откроется. Выключается галкой «Открывать само».
- **LIVE.** Значок в трее:
  - серый — игры нет;
  - обычный — игра запущена;
  - живой с красной пульсирующей точкой — мод шлёт матч.

  Ещё LIVE видно на подсказке трея, во всплывашке «Матч найден», в полосе окна и на вкладке «Лайв-матч» сайта (горит красным только во время матча). Кадры — `ic/live0..5.png` (+ `@2x`).
- **Закрыть:** та же клавиша, ✕ или Esc в полосе окна сверху. Esc сначала закрывает окошки сайта (подсказки, патч, рейтинг), потом прячет окно. Полоса окна — тянуть окно, ‹ назад.
- **Страница → программа** — `preload.js` (`window.rlHost`): спрятать, клавиша (только из списка), «открывать само», клики сквозь. Работает только на нашем сайте, сообщения с других адресов программа не слушает.
- **Окно:** по умолчанию 1180×820 по центру, размер и место запоминает. Сайт закрыт замком разработки, поэтому в адресе ключ `dev=…`. Профиль другого игрока открывается в обычном браузере: в окне сайт запомнил бы его как «тебя».
- **Мод программа ставит сама** (`install.js`):
  - находит Deadlock по библиотекам Steam;
  - дописывает строки в `gameinfo.gi` (копия `.restless.bak`);
  - старые паки Restless переносит в `game/citadel/restless_old`;
  - кладёт `pak42_dir.vpk` (номер занят — 43…99).

  Пока игра запущена — ждёт выхода.
- Игру поставить в режим **«Оконный без рамки»** — поверх полноэкранного режима Windows окна не рисует.

## Сборка
GitHub Actions (`.github/workflows/restless-app.yml`) на Windows при изменениях в `restless/app/` → релиз `overlay-latest`:
https://github.com/1f8t8graf4-ai/dota-/releases/download/overlay-latest/Restless-Overlay.exe

Руками: `npm install && npm run dist` (на Windows) → `dist/Restless-Overlay.exe`.
Новый мод → скопировать `mod/build/pak42_dir.vpk` в `restless/app/`.

## Проверка без Windows
- `node tools/restless_test/app.js` — установщик на фейковой папке игры, приём данных от мода.
- `node tools/restless_test/appmain.js` — `main.js` с подменённым Electron, 22 проверки:
  - клавиша только при запущенной игре;
  - матч → окно само на `#ov`, без фокуса;
  - LIVE в трее;
  - страница → программа, чужой сайт игнорируется;
  - занятая клавиша.
- Сайт: `tools/restless_test/tovs.js` (вкладка «Оверлей», полоса окна, Esc), `tov.js` (12 игроков из игры).

Программа без подписи — Windows при первом запуске покажет «Windows защитила компьютер» → «Подробнее» → «Выполнить в любом случае».
