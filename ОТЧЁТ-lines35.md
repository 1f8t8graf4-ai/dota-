# ОТЧЁТ-lines35 — интересные фразы остальных 35 героев + mp3

**Версия:** код приложения не трогал (ветка данных: `data/games-new2.json`, `heroes-voice/`).
**Сделал:**
1. Докачал с deadlock.wiki сырые реплики 15 героев, которых не было у Зетки (paige, paradox, pocket, shiv, silver, sinclair, vindicta, viscous, vyper, warden, wraith, yamato, nurse-harrow, solomon, violet) — 420–1440 реплик на каждого. Итого сырьё на все 35: 29 героев из `data/dd-lines/` (ветка zai/dd-lines) + 15 новых.
2. Отобрал по 15 лучших фраз на героя (35 × 15 = 525): полезные в жизни или смешные, без названий способностей и чистых звуков, мат — матом. Переводы живые, не дословные; tag из набора девятки (подкол/шутка/угроза/идиома/приветствие/мудрость/издёвка/флирт/злость/усталость/пафос), use 2–5.
3. Скачал mp3 каждой фразы с cdn.deadlock.wiki, пережал в mono 80 кбит/с → `heroes-voice/<id>/<id>-<NN>.mp3` (525 файлов). Длительности проверены ffprobe (0.4–30 с), странных нет.
4. `data/games-new2.json` = {"heroes": {<id>: {name, lines: [{en, ru, tag, use, a}]}}} — id как в games.json (lady-geist, mo-krill, nurse-harrow…), `a` = `scenes/games/deadlock/v/<id>-<NN>.mp3`.
5. `tools/upload-queue-lines35.json` — очередь заливки (файл → ключ → content-type) на 525 позиций.

**Проверил:** каждое en дословно есть в сырых репликах своего героя (скрипт агентов + повторный проход); дубликатов нет; 525/525 mp3 скачались без ошибок; json собирается, у всех 35 героев ровно 15 фраз.

**Не сделал / не проверял:** заливку в R2 — в среде нет ключа заливки (PUT 403; `.r2-media-key` из прошлой сессии не сохранился). Когда Андрей даст ключ: `for q in tools/upload-queue-lines35.json: python3 tools/dd_r2_up.py <q.f> <q.k> audio/mpeg`, потом curl-проверка каждой ссылки `https://dota.1f8t8graf4.workers.dev/m/<a>` — до заливки они 404, это ожидаемо. Переводы не вычитал вторым взглядом (это отдельная задача proof — по девятке сделана, по этим 525 — нет).

**Риск:** нулевой для игроков — файл данных не подключён к приложению; подключит Клауд после заливки аудио.
