## 4. Как бот ловит «маленький патч» и стаггинг (Deadlock + Dota 2)

1. **Atom GameTracking — основной сигнал.** Коммит в `GameTracking-Deadlock` / `GameTracking-Dota2` = файлы игры изменились. Если Steam-поста с патчноутами нет, а коммиты есть — это маленький патч или стаггинг: короткая новость «в файлах игры что-то поменялось (перевод, фиксы), нотсов нет». Патч сообщений: сравнить какие папки тронуты (`citadel/resource/localization/...` = локализация/баланс-тексты, `panorama/...` = интерфейс).
2. **Steam RSS — подтверждение.** Появился пост в фиде → сверить с коммитами: есть и то и то = обычный патч с нотами; есть пост без коммитов = ивент/блог; есть коммиты без поста = тихое обновление.
3. SteamDB (`steamdb.info/app/1422450/depots/`) показывает ветки (`staging`, `main`) и их билды, но без RSS и с защитой от ботов — для бота не подходит, только руками смотреть.

## 5. Discord: канал объявлений «Подписаться» (Follow)

Никаких ботов в чужих серверах и чтения чужих API — против правил Discord. Правильный путь: у официальных серверов канал объявлений имеет тип **Announcement** — его можно «Подписаться» (Follow) из сервера Андрея, после чего посты приходят в канал-зеркало автоматически, и наш бот читает уже свой канал.

- **Deadlock** — `discord.gg/deadlock`, канал `#announcements` (тип Announcement — Follow доступен).
- **Dota 2** — `discord.gg/dota2`, канал объявлений.
- **Overwatch** — `discord.gg/overwatch`, канал новостей.

Действие ручное и одноразовое: делает Андрей в клиенте (кнопка «Подписаться» на канале). Бот после этого читает только зеркало у себя. Доступны ли конкретные каналы для Follow — проверить в клиенте (из облака Discord недоступен).

## 6. Что уже проверено на практике (из задачи TG-дайджеста, 24.10)

- Steam RSS по всем трём играм парсится; заголовки Deadlock криптовые — размер патча определять по тексту.
- `date.today()` → только `datetime.now(ZoneInfo("Europe/Berlin"))`.
- У Steam-постов двойное HTML-экранирование — снимать теги циклом до 3 раз.
- У Reddit RSS нужен браузерный User-Agent.
- Дубли: у одной новости бывает и Steam-пост, и Reddit-тред — дедуп по заголовку.
