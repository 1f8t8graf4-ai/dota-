## Пробник (27.10) — `build/pak42_dir.vpk`
Проверяет три вещи: игра грузит наш файл, скрипт работает (таймер), картинка по ссылке из интернета показывается.

**Что видно** (версия 3, 27.10 вечер):
- **в укрытии и в матче** — в верхней панели HUD слева сверху жёлтая надпись «RESTLESS: мод загружен» (без скрипта) и справа плашка «Restless работает · HUD»;
- **в главном меню (Esc)** — под логотипом «Restless: мод загружен» и плашка «Restless работает · меню».
- Версии 1–2 подключались только к главному меню, а Deadlock стартует в укрытии (`dl_hideout`) — там игровой HUD, меню видно только по Esc; у Андрея «ничего не показывало».

Плашка:
- «Restless работает · HUD / меню»;
- арт Венатора — грузится с нашего сервера R2;
- «таймер идёт: N с».

Нажал на плашку — она прячется. В консоли игры строка `[Restless] пробник загружен`.

**Что внутри** (исходники — `restless-probe/panorama/`):
- `scripts/restless.js` — наш скрипт. Сам создаёт плашку кодом, стили тоже из кода. Память игры не читает, ничего не отправляет;
- `layout/citadel_hud_top_bar.xml` — верхняя панель HUD (часы, герои), копия из игры: строка `<scripts>` и надпись `RestlessMark`;
- `layout/hud_escape_menu.xml` — игровое меню по Esc (укрытие, матч), копия из игры: строка `<scripts>` и кнопка `RestlessMenuBtn` под «Сменить героя»;
- `layout/dashboard.xml` — с 0.7 убран (главное меню не трогаем).

**Как поставить** (Андрею):
1. Steam → Deadlock → «Управление» → «Просмотреть локальные файлы».
2. **Включить моды в игре** — без этого игра папку `addons` не читает (27.10: у Андрея после удаления модов строки не было, пробник «ничего не показывал»):
   - открыть `game/citadel/gameinfo.gi` Блокнотом;
   - в блоке `SearchPaths` (внутри фигурных скобок) над строкой `Game				citadel` вписать три строки: `Mod citadel`, `Write citadel`, `Game citadel/addons`; перед `Game core` — `Mod core` и `Write core`. Как в гайде deadlockmodding.pages.dev/installing-mods;
   - **без `Mod citadel` игра не запускается:** «FATAL ERROR: Unable to read default keybinding configuration (user_keys_default)» — главной папкой становится первая `Game`, то есть `citadel/addons` (у Андрея 27.10);
   - сохранить.
   - DMM при установке модов вписывает эту строку сам. После обновления Deadlock строка может пропасть — вписать снова. Сломал файл — «Проверить целостность файлов» в Steam.
3. Положить `pak42_dir.vpk` в `game/citadel/addons` (папки нет — создать).
4. Запустить игру и посмотреть главное меню:
   - под логотипом вместо «Early Dev Build» — «Restless: мод загружен» — игра взяла наш файл (без скрипта);
   - справа сверху плашка с артом и таймером — скрипт работает.
5. Убрать: удалить файл.

Если меню выглядит не так (Valve могла поменять `dashboard.xml`) — удалить файл. Отдельные моды меню никто из стоящих у Андрея не трогает.

## 0.5 — кнопка в настоящем меню по Esc (27.10 вечер)
- Андрей на 0.4: надпись в HUD есть, кнопки Restless нет. Причина: в укрытии и в матче по Esc открывается **игровое меню `hud_escape_menu`** («Сменить героя», «Настройки», «Выйти из Deadlock»), а не главное меню `dashboard`. Кнопка теперь в `hud_escape_menu.xml` под «Сменить героя» (в `dashboard.xml` тоже осталась).
- Окно настроек вешается на само меню и закрывается вместе с ним — после Esc не остаётся висеть без курсора.
- Надпись в верхней панели показывает статус: «RESTLESS 0.5 · работает» — скрипт HUD запустился; «· кнопка в Esc есть» — скрипт меню тоже и настройки у них общие; «· ошибка: …» — что сломалось. Консоль не нужна.
- Настройки не роняют скрипт, если общий объект недоступен (свои внутри экрана); текст и видимость меняются, только когда поменялись — меньше перерисовок (Андрей заметил чуть меньше ФПС с модом).

## 0.6 — кнопка на своём месте, старые копии больше не мешают (27.10 вечер)
- Андрей на 0.5 (скрин Esc-меню): кнопка «RESTLESS» висела поверх логотипа, нажимается со звуком, но окно не открывается.
- **Место:** в `hud_escape_menu` у `#Menu` `flow-children: none`, каждая кнопка стоит по своему id (`#changehero` — `vertical-align: bottom; margin-bottom: 280px`), кнопка без своего места уезжает в левый верхний угол. Теперь она первой строкой в `#SubOptions` (столбик под «Сменить героя»: «Отзыв игрока», «Настройки», «Выйти из игры»), класс `nav_menu_item minor`, подпись янтарём.
- **Не открывалось:** справа на скрине — плашка версии 2 («нажми, чтобы скрыть»). DMM положил старый импорт как `pak01_dir.vpk`, а у меньшего номера приоритет выше — старый `restless_probe.vjs_c` перебивал новый, обработчика кнопки в нём нет. Скрипт теперь `scripts/restless.js`; перед установкой новой версии — удалить все старые файлы Restless в DMM и в `game/citadel/addons`.

## 0.7 — окно как у QoL Lock (27.10 поздно; Андрей на 0.6: «кнопка мелкая, налезает на „Сменить героя“, сквозь окно кликается меню, ничего не работает, кроме языка»)
- **Почему не работали переключатели:** меню по Esc и HUD — разные экраны со своими копиями скрипта, общий объект настроек (`GameUI.CustomUIConfig()` / `$`) между ними, видимо, не общий: окно менялось, HUD — нет. Теперь настройки — атрибутами корневой панели (`SetAttributeString` / `GetAttributeString` у самого верхнего родителя) — так меню и HUD связывает QoL Lock. В окне строка «HUD на связи» — значит, связь есть.
- **Кнопка:** `RESTLESS` отдельной строкой первой в `#SubOptions`, шрифт 34 px, янтарь. Чтобы не налезать, у «Сменить героя» в нашей копии отступ снизу 350 px вместо 280.
- **Окно** объявлено в разметке меню (как у QoL Lock), последними детьми `CitadelHudEscapeMenu`: подложка `RestlessShade` на весь экран (тёмная, ловит клики — сквозь окно в меню не нажать, клик мимо закрывает) и окно `RestlessWindow` по центру, 640 px, `hittest`. Скрипт только меняет тексты и цвета. Окно, созданное кодом в 0.6, стояло справа сверху: выравнивание из JS, судя по всему, не сработало.
- **Закрыть:** ×, «Закрыть», клик мимо, Esc (`oncancel` меню сначала закрывает наше окно, потом уже меню); закрыли меню — окно закрывается само (класс `ShowEscapeMenu`).
- Главное меню (`dashboard.xml`) больше не трогаем: Андрей его не видит, а подмена большого игрового файла — лишний риск после обновлений.
- **Совместимость:** QoL Lock и UMM тоже подменяют `hud_escape_menu.xml` — показывается одна копия (у кого меньше номер pak). Пока проверяем — других модов на меню не ставить.
- Проверка без игры: `node mod/tools/mock_panorama.js mod/restless-probe/panorama` — разбирает настоящую разметку, 27 проверок (кнопка, окно, подложка, переключатели → HUD, язык, все закрытия, Esc).

## 0.8 — кнопка как у других модов, меню больше не подменяем, КД ульты (27.10 ночь)
- **Андрей на 0.7** прислал скрин меню с модом Torfus Voice: «вот как выглядеть должно» — строка «TORFUS VOICE» тем же шрифтом и размером, что «Отзыв игрока» и «Настройки». На скрине нет нашей кнопки — Torfus Voice тоже подменяет `hud_escape_menu.xml`, а в игре остаётся одна копия файла (так же с QoL Lock и UMM).
- **Меню по Esc не подменяем.** Кнопку ставит скрипт — в то меню, какое загрузилось (ванильное или чужое): `Panel.SettingsRow` → `Button.nav_menu_item.minor` → `Label.menuButtonLabel` «RESTLESS», перед строкой «Настройки» (`MoveChildBefore`). Своих стилей у кнопки нет — вид берётся из стилей меню, как у кнопок игры. Если «Сменить героя» налезает на столбик, скрипт поднимает её ровно на нехватку (по `actualyoffset` / `actuallayoutheight`, в px разметки через `actualuiscale_y`).
- **Окно и подложка** — тоже кодом, последними в `#EscapeMenu`. Через такт скрипт проверяет: окно по центру, подложка на весь экран. Если нет — ставит по пикселям (`align: left top`, `x`/`y`, как перетаскиваемые окна QoL Lock). Внизу окна мелкая строка проверки: размер окна, экрана, по центру или поправлено, откуда запущен скрипт.
- **Куда подключён скрипт:** `citadel_hud_subtitles.xml` (субтитры — маленький файл, другие моды его не трогают) и, на всякий случай, `citadel_hud_top_bar.xml`. Работает одна копия: «хозяин» пишет в атрибут корня `RESTLESS_OWN` метку и время, вторая каждую секунду проверяет и подхватит, если хозяин пропал больше чем на 3 с. Надпись RESTLESS — кодом на `#Hud`, не в разметке верхней панели. В окне настроек игры (там тоже есть субтитры) скрипт молчит: нет `#EscapeMenu`.
- **КД ульты в верхней панели** (первая настоящая функция, переключатель, по умолчанию вкл.): игра кладёт секунды до ульты каждого игрока в переменную `{i:ult_cooldown}` верхней панели, но не показывает (QoL Lock её выводит). Скрипт кладёт в `UltimateStatusBG` каждого игрока скрытую подпись с этой переменной и показывает число поверх значка ульты. Ульта готова (`UltimateCooldownReady`), 0 или переменная не подставилась — ничего не показывает, мусора `{i:…}` не будет. В укрытии выключено. Подпись не подставилась — запасной способ: `$.Localize('{i:ult_cooldown}', игрок)`.
- **Настройки окна:** КД ульты, надпись RESTLESS, язык; «Скоро»; «Открыть бота».
- Проверка без игры: `node mod/tools/mock_panorama.js mod/restless-probe/panorama <ванильный hud_escape_menu.xml из GameTracking>` — 37 проверок: меню не подменяем, кнопка одна при двух копиях скрипта, место и класс, подъём «Сменить героя», окно, поправка по пикселям, переключатели, язык, закрытия, КД ульты (число, 0, готова, не подставилось, выкл, укрытие), подхват хозяина, не-HUD.

## 0.9 — запуск починен (28.10; Андрей на 0.8: «пропал Restless, все моды отключил, оставил только наш — не работает»)
- **Почему 0.8 молчала:** скрипт при запуске сразу искал `#EscapeMenu` у корня. Игра запускает скрипт файла раньше, чем вставляет его панель в HUD, — корнем оказывалась сама панель, скрипт писал «не HUD» и выключался насовсем. QoL Lock поэтому тоже ждёт перед стартом. Теперь `boot()` ищет корень каждые 0,25 с (первые 10 с), потом раз в секунду; нашёл `#EscapeMenu` — запускает всё как в 0.8.
- **Куда подключён скрипт:** `hud_escape_menu.xml` (наша копия ванильного меню — путь, который точно работал в 0.4–0.6), `citadel_hud_subtitles.xml`, `hud_movement_speed.xml` (маленькие файлы HUD, другие моды Андрея их не трогают). `citadel_hud_top_bar.xml` больше не подменяем: его подменяют QoL Lock, QoL Lite и ещё один мод (список — `ресёрч-моды-27.10.md`), наша копия либо проигрывала, либо ломала бы их верхнюю панель.
- **Если стоит QoL / Torfus:** их копия меню по Esc победит нашу (у кого меньше номер pak) — кнопку RESTLESS всё равно поставит скрипт из субтитров или скорости, тем же классом.
- **Если мод не грузится вообще:** проверить строки `Game citadel/addons` в `gameinfo.gi` (DMM, отключая все моды, может их убрать) и удалить старые Restless (`pak01_dir.vpk` от прошлого импорта DMM).
- В консоли (`~`) строки `[Restless] 0.9 файл загружен: …` и `запущен в HUD через …` — видно, какой файл сработал.
- Проверка без игры: `node mod/tools/mock_panorama.js mod/restless-probe <ванильный hud_escape_menu.xml>` — 41 проверка, в том числе: панель ещё не в HUD — скрипт ждёт; вставили — запустился во всех трёх, работает одна копия; чужое меню — кнопку ставит скрипт из файла скорости.
- **Сборка:** `s2bin compile mod/restless-probe … citadel_addons/restless_probe` — папка `restless-probe`, не `restless-probe/panorama` (иначе в архив лягут исходники без компиляции), потом `tools/vpk2.py`.

## Как собрано
- Компилятор Panorama (`.xml` → `.vxml_c`, `.js` → `.vjs_c`) и упаковщик VPK — пакеты `source2/{panorama,kv3,resource,vpk}` из Modlock (github.com/paralin/modlock, MIT, коммит `5198246`). Инструменты Valve, Дота и CS2 не нужны.
- Обёртка — `tools/s2cli.go` (`compile ПАПКА OUT.vpk ИМЯ`, `decompile ФАЙЛ`, `files АРХИВ [ПАПКА]`). Её собирать вместе с этими пакетами: импорты `github.com/paralin/modlock/source2/…` → `s2/…`, свой `go.mod` на go 1.24.
- Modlock пишет VPK версии 1, рабочие моды из DMM — версии 2. `tools/vpk2.py` переупаковывает в v2: тот же каталог и данные плюс блок MD5. Схема MD5 проверена на моде Mercurial Magnum Notifier.
- Проверено:
  - разметка из `.vxml_c` разбирается обратно в ту же XML (разница только в `&apos;` / `&#39;`);
  - в `.vjs_c` блок DATA = наш исходник байт в байт;
  - заголовки ресурсов такие же, как у файлов, собранных Valve (версия 12, блоки RED2 / DATA / LaCo);
  - v2 по содержимому = v1.
- **Сборку чужого кода в облачной сессии пускают только с разрешения Андрея** (проверка безопасности режет «код извне»).
