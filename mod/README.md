# Мод Restless для Deadlock

## Пробник (27.10) — `build/pak42_dir.vpk`
Проверяет три вещи: игра грузит наш файл, скрипт работает (таймер), картинка по ссылке из интернета показывается.

**Что видно** (версия 3, 27.10 вечер):
- **в укрытии и в матче** — в верхней панели HUD слева сверху жёлтая надпись «RESTLESS: мод загружен» (без скрипта) и справа плашка «Restless работает · HUD»;
- **в главном меню (Esc)** — под логотипом «Restless: мод загружен» и плашка «Restless работает · меню».
- Версии 1–2 подключались только к главному меню, а Deadlock стартует в укрытии (`dl_hideout`) — там игровой HUD, меню видно только по Esc; у Андрея «ничего не показывало».

Плашка:
- «Restless работает · HUD / меню»;
- арт Венатора — грузится с нашего сервера R2;
- «таймер идёт: N с».

Нажал на плашку — она прячется. В консоли игры строка `[Restless] пробник загружен`.

**Что внутри** (исходники — `restless-probe/panorama/`):
- `scripts/restless.js` — наш скрипт. Сам создаёт плашку кодом, стили тоже из кода. Память игры не читает, ничего не отправляет;
- `layout/citadel_hud_top_bar.xml` — верхняя панель HUD (часы, герои), копия из игры: строка `<scripts>` и надпись `RestlessMark`;
- `layout/hud_escape_menu.xml` — игровое меню по Esc (укрытие, матч), копия из игры: строка `<scripts>` и кнопка `RestlessMenuBtn` под «Сменить героя»;
- `layout/dashboard.xml` — разметка главного меню, копия из игры (SteamDatabase/GameTracking-Deadlock, коммит `d251cf9`, 26.10). Добавлена одна строка `<scripts>` с нашим скриптом. Ссылки на стили — с `_c`, как в собранных файлах игры.

**Как поставить** (Андрею):
1. Steam → Deadlock → «Управление» → «Просмотреть локальные файлы».
2. **Включить моды в игре** — без этого игра папку `addons` не читает (27.10: у Андрея после удаления модов строки не было, пробник «ничего не показывал»):
   - открыть `game/citadel/gameinfo.gi` Блокнотом;
   - в блоке `SearchPaths` (внутри фигурных скобок) над строкой `Game				citadel` вписать три строки: `Mod citadel`, `Write citadel`, `Game citadel/addons`; перед `Game core` — `Mod core` и `Write core`. Как в гайде deadlockmodding.pages.dev/installing-mods;
   - **без `Mod citadel` игра не запускается:** «FATAL ERROR: Unable to read default keybinding configuration (user_keys_default)» — главной папкой становится первая `Game`, то есть `citadel/addons` (у Андрея 27.10);
   - сохранить.
   - DMM при установке модов вписывает эту строку сам. После обновления Deadlock строка может пропасть — вписать снова. Сломал файл — «Проверить целостность файлов» в Steam.
3. Положить `pak42_dir.vpk` в `game/citadel/addons` (папки нет — создать).
4. Запустить игру и посмотреть главное меню:
   - под логотипом вместо «Early Dev Build» — «Restless: мод загружен» — игра взяла наш файл (без скрипта);
   - справа сверху плашка с артом и таймером — скрипт работает.
5. Убрать: удалить файл.

Если меню выглядит не так (Valve могла поменять `dashboard.xml`) — удалить файл. Отдельные моды меню никто из стоящих у Андрея не трогает.

## 0.4 — вкладка «Restless» в меню (27.10 вечер; Андрей: «добавь отдельную вкладку настроек, как „Настройки“, „Выйти“»)

- Кнопка открывает окно настроек поверх меню (кодом, `restless.js`):
  - «В игре»: «Плашка справа» и «Надпись RESTLESS» — переключатели, HUD подхватывает за полсекунды;

## 0.5 — кнопка в настоящем меню по Esc (27.10 вечер)
- Андрей на 0.4: надпись в HUD есть, кнопки Restless нет. Причина: в укрытии и в матче по Esc открывается **игровое меню `hud_escape_menu`** («Сменить героя», «Настройки», «Выйти из Deadlock»), а не главное меню `dashboard`. Кнопка теперь в `hud_escape_menu.xml` под «Сменить героя» (в `dashboard.xml` тоже осталась).
- Окно настроек вешается на само меню и закрывается вместе с ним — после Esc не остаётся висеть без курсора.
- Надпись в верхней панели показывает статус: «RESTLESS 0.5 · работает» — скрипт HUD запустился; «· кнопка в Esc есть» — скрипт меню тоже и настройки у них общие; «· ошибка: …» — что сломалось. Консоль не нужна.
- Настройки не роняют скрипт, если общий объект недоступен (свои внутри экрана); текст и видимость меняются, только когда поменялись — меньше перерисовок (Андрей заметил чуть меньше ФПС с модом).

## 0.6 — кнопка на своём месте, старые копии больше не мешают (27.10 вечер)
- Андрей на 0.5 (скрин Esc-меню): кнопка «RESTLESS» висела поверх логотипа, нажимается со звуком, но окно не открывается.
- **Место:** в `hud_escape_menu` у `#Menu` `flow-children: none`, каждая кнопка стоит по своему id (`#changehero` — `vertical-align: bottom; margin-bottom: 280px`), кнопка без своего места уезжает в левый верхний угол. Теперь она первой строкой в `#SubOptions` (столбик под «Сменить героя»: «Отзыв игрока», «Настройки», «Выйти из игры»), класс `nav_menu_item minor`, подпись янтарём.
- **Не открывалось:** справа на скрине — плашка версии 2 («нажми, чтобы скрыть»). DMM положил старый импорт как `pak01_dir.vpk`, а у меньшего номера приоритет выше — старый `restless_probe.vjs_c` перебивал новый, обработчика кнопки в нём нет. Скрипт теперь `scripts/restless.js`; перед установкой новой версии — удалить все старые файлы Restless в DMM и в `game/citadel/addons`.

## Как собрано
- Компилятор Panorama (`.xml` → `.vxml_c`, `.js` → `.vjs_c`) и упаковщик VPK — пакеты `source2/{panorama,kv3,resource,vpk}` из Modlock (github.com/paralin/modlock, MIT, коммит `5198246`). Инструменты Valve, Дота и CS2 не нужны.
- Обёртка — `tools/s2cli.go` (`compile ПАПКА OUT.vpk ИМЯ`, `decompile ФАЙЛ`, `files АРХИВ [ПАПКА]`). Её собирать вместе с этими пакетами: импорты `github.com/paralin/modlock/source2/…` → `s2/…`, свой `go.mod` на go 1.24.
- Modlock пишет VPK версии 1, рабочие моды из DMM — версии 2. `tools/vpk2.py` переупаковывает в v2: тот же каталог и данные плюс блок MD5. Схема MD5 проверена на моде Mercurial Magnum Notifier.
- Проверено:
  - разметка из `.vxml_c` разбирается обратно в ту же XML (разница только в `&apos;` / `&#39;`);
  - в `.vjs_c` блок DATA = наш исходник байт в байт;
  - заголовки ресурсов такие же, как у файлов, собранных Valve (версия 12, блоки RED2 / DATA / LaCo);
  - v2 по содержимому = v1.
- **Сборку чужого кода в облачной сессии пускают только с разрешения Андрея** (проверка безопасности режет «код извне»).
