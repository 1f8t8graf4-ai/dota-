# Мод Restless для Deadlock

## Пробник (27.10) — `build/pak42_dir.vpk`
Проверяет три вещи: игра грузит наш файл, скрипт работает (таймер), картинка по ссылке из интернета показывается.

**Что видно:** в главном меню справа сверху плашка:
- «Restless работает»;
- арт Венатора — грузится с нашего сервера R2;
- «таймер идёт: N с».

Нажал на плашку — она прячется. В консоли игры строка `[Restless] пробник загружен`.

**Что внутри** (исходники — `restless-probe/panorama/`):
- `scripts/restless_probe.js` — наш скрипт. Сам создаёт плашку кодом, стили тоже из кода. Память игры не читает, ничего не отправляет;
- `layout/dashboard.xml` — разметка главного меню, копия из игры (SteamDatabase/GameTracking-Deadlock, коммит `d251cf9`, 26.10). Добавлена одна строка `<scripts>` с нашим скриптом. Ссылки на стили — с `_c`, как в собранных файлах игры.

**Как поставить** (Андрею):
1. Steam → Deadlock → «Управление» → «Просмотреть локальные файлы».
2. Положить `pak42_dir.vpk` в `game/citadel/addons`.
   - Строку `Game citadel/addons` в `gameinfo.gi` DMM уже добавил.
   - Номер 42 свободен: у модов из DMM 01–07, 11, 15, 16, 99.
3. Запустить игру и посмотреть главное меню.
4. Убрать: удалить файл.

Если меню выглядит не так (Valve могла поменять `dashboard.xml`) — удалить файл. Отдельные моды меню никто из стоящих у Андрея не трогает.

## Как собрано
- Компилятор Panorama (`.xml` → `.vxml_c`, `.js` → `.vjs_c`) и упаковщик VPK — пакеты `source2/{panorama,kv3,resource,vpk}` из Modlock (github.com/paralin/modlock, MIT, коммит `5198246`). Инструменты Valve, Дота и CS2 не нужны.
- Обёртка — `tools/s2cli.go` (`compile ПАПКА OUT.vpk ИМЯ`, `decompile ФАЙЛ`, `files АРХИВ [ПАПКА]`). Её собирать вместе с этими пакетами: импорты `github.com/paralin/modlock/source2/…` → `s2/…`, свой `go.mod` на go 1.24.
- Modlock пишет VPK версии 1, рабочие моды из DMM — версии 2. `tools/vpk2.py` переупаковывает в v2: тот же каталог и данные плюс блок MD5. Схема MD5 проверена на моде Mercurial Magnum Notifier.
- Проверено:
  - разметка из `.vxml_c` разбирается обратно в ту же XML (разница только в `&apos;` / `&#39;`);
  - в `.vjs_c` блок DATA = наш исходник байт в байт;
  - заголовки ресурсов такие же, как у файлов, собранных Valve (версия 12, блоки RED2 / DATA / LaCo);
  - v2 по содержимому = v1.
- **Сборку чужого кода в облачной сессии пускают только с разрешения Андрея** (проверка безопасности режет «код извне»).
