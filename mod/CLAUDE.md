# mod/ — мод Restless для Deadlock

Подгружается сам при работе в `mod/`. Жёсткие правила ядра (`/CLAUDE.md`) и правила `restless/CLAUDE.md` главнее.

- **Полное описание:** версии, панели игры, как собирать и проверять — `mod/README.md`.
- **Журнал по дням** вместе с сайтом и программой — `restless/log.md`.
- **Сборка:** без Valve-инструментов — `mod/tools/s2cli.go` (пакеты Modlock, MIT) и перепаковка `mod/tools/vpk2.py`.
  - Проверка без игры: `node mod/tools/mock_panorama.js mod/restless-probe/panorama`.
- **Нельзя** по правилам GameBanana: читать память игры, показывать души в минуту и непотраченные души.
- **Комментарий `//` — только в конце строки.** Посреди строки он съедает код до конца строки.
- **Скрипт мода может запуститься раньше, чем панель встанет в HUD.** Нужно дождаться корня (`boot`), иначе ничего не работает — так было в 0.8.
