# Моды Deadlock: что умеют чужие моды и что из этого следует для нас (27.10)

Андрей прислал zip с 4 модами из Deadlock Mod Manager (DMM), скрины раздела FPS-конфигов в DMM и ссылку на OptimizationLock. Разобрал по файлам. Чужой код не копируем — смотрели только, что игра даёт моду.

## Что за моды

| № на GameBanana | Что это | Что внутри |
|---|---|---|
| 650634 | **QoL Lock** — большой мод «всё в одном» | ~200 своих скриптов, окно настроек в игре (вкладки, пресеты, темы, 14 языков, в том числе русский), свой «диктор» (5 слотов своих звуков), подмена экрана после матча, бенчмарк, мини-игры (блэкджек), проверка обновлений |
| 678180 | **QoL Lite** | уведомления о событиях карты, урна, мини-карта с туннелями, ранги друзей (картинка с deadlock-api.com), кнопка Statlocker, авто-похвала, «кто замьючен», недавние покупки, быстрые покупки |
| 623518 | недавние покупки + ранг в верхней панели | 3 скрипта, фильтры T1–T4 и по командам |
| 601444 | значки способностей + Mercurial Magnum | 4 варианта значков способностей, уведомление «бафф Mercurial Magnum / Split Shot / Blood Tribute активен» над патронами |

## Что игра даёт моду (главное)

1. **В моде есть JavaScript.** Скрипты Panorama (`.vjs_c`) работают в HUD, меню и на экране после матча. Можно строить свои окна, кнопки и настройки, а не только перекрашивать.
2. **Мод читает только то, что игра уже нарисовала.** Это классы и тексты панелей: «предмет на перезарядке», текст таймера, «ульта готова» в верхней панели, метки урны на мини-карте, часы матча `#GameTime`. Память игры никто не читает. Так и надо делать нам.
3. **Свои секунды — точно, чужие — только «готово / не готово».** Mercurial Magnum Notifier читает текст таймера своего предмета. У врагов в верхней панели есть только класс «ульта готова». QoL Lock показывает «примерный КД ультов под иконками игроков» — это оценка по времени, а не точные данные.
4. **Таймеры карты — по часам матча и расписанию.** Слабые лагеря 2:00, средние 5:00, сильные 8:00, руны на мосту каждые 5:00, Sinner's Sacrifice 8:00, первая урна 10:00. Урну ещё ловят по меткам на мини-карте. Уже сделано в QoL Lite (взято из открытого Map Event Reminders) и в QoL Lock (таймер мид-босса).
5. **Своё из интернета в игре — можно, двумя способами:**
   - **картинка по ссылке:** `Image.SetImage("https://…")`. Так QoL Lite показывает ранг друга (картинка с deadlock-api.com по ID игрока). Нам — картинка «сборка героя / винрейт предметов» с нашего сервера, обновляется каждый день без переустановки мода;
   - **встроенный браузер:** скрытая панель `CitadelHTMLPanel` (Chromium) грузит страницу. Мод передаёт ей данные через `#…` в адресе, страница отвечает сменой заголовка. Так QoL Lock хранит настройки (localStorage на странице github.io). Нам — страница с данными сборок, винрейта, разбора матча.
   - Обычного `fetch` в Panorama нет. Обновления QoL Lock проверяет по размеру картинки с GitHub (квадратная — актуально, широкая — вышла новая версия).
6. **Открыть ссылку из игры** — `SteamOverlayAPI.OpenURL`, оверлей Steam. Так сделана кнопка «STAT → Statlocker» в профиле игрока.

## FPS — уже сделано в самом менеджере, не дублируем

- В DMM есть раздел конфигов производительности. Шкала «Pretty · Balanced · Lean · Sweaty · Potato», 15 готовых конфигов (8 проверенных + 7 с GameBanana), «DMM Clean» помечен «Recommended». Есть «Apply», редактор настроек и история.
- Конфиги — это не autoexec. Это замена `gameinfo.gi` (`game/citadel/gameinfo.gi`, блок `Convars`). Так у OptimizationLock (Sqooky) и у всех из списка.
- **Риск:** в файлах игры есть строка «Unable to enter matchmaking while any party member has changes to ConVars in Gameinfo.gi or is running Tools-Mode». Valve может закрыть поиск игры с изменённым `gameinfo.gi`. Моды Panorama (HUD) это не задевает.
- Вывод: кнопка FPS у нас — это ссылка «Открой DMM → Performance → Apply «DMM Clean»». Свои конфиги не делаем. Пункт 5 ТЗ v15 Зетке снят.

## Что это значит для Restless

- Отдельный «ещё один QoL» не нужен: QoL Lock бесплатный, огромный и уже на русском. Таймеры, КД ультов, HP-предупреждения, мини-карта — всё там.
- Ниша, которой там нет:
  1. **сборки с винрейтом прямо в магазине** — картинкой или встроенной страницей с нашими данными (deadlock-api.com), раз в день;
  2. **после матча — кнопка «Разбор этого матча»** на экране итогов (QoL Lock этот экран подменяет, значит, можно): открывает наш разбор Restless в оверлее Steam;
  3. **язык:** двуязычные субтитры реплик героев (английский + русский) — проверить, можно ли модом подменить файлы субтитров (captions);
  4. «Языки по кино» и канал — вне игры.
- Работать вместе с QoL Lock, а не вместо: наш мод маленький и трогает свои файлы. Пересекающиеся файлы (`hud.vcss_c`, `citadel_hud_top_bar.vxml_c`) у разных модов конфликтуют — DMM ставит порядок. Значит, свои панели — своими файлами, по возможности без подмены общих.

## Что проверить дальше (Зетке, ТЗ v15 п. 6)

1. Какие картинки отдаёт deadlock-api.com (ранги — да; есть ли сборки, предметы, винрейт).
2. Субтитры реплик (captions): где лежат, можно ли подменить модом (VPK в `citadel/addons`), есть ли русские.
3. Экран после матча: какие панели и данные там есть (ID матча, герой, итог), чтобы дать ссылку на разбор.

## Пробник мода — можно без Доты (проверено по файлам модов)
- Внутри `.vjs_c` — обычный текст JavaScript: блок `DATA` = исходник как есть, плюс служебный блок `RED2` (метаданные сборки, KV3). У `.vcss_c` в `DATA` — 4 байта CRC32, 2 нулевых байта и текст CSS. Бинарный только `.vxml_c` (разметка в блоке `LaCo`).
- Значит, пробник можно собрать самому, без `resourcecompiler`: один скрипт, который сам создаёт панели кодом (`$.CreatePanel`) и стилизует их через `panel.style`. Разметка не нужна.
- Подключить скрипт — подменить один игровой скрипт HUD: его исходник лежит в `SteamDatabase/GameTracking-Deadlock`, наш код дописывается в конец. Когда Valve поменяет этот файл, подмену надо обновить.
- Риск: игра может не принять файл, собранный вручную (например, без правильного `RED2`). Это видно с первой проверки у Андрея. Не принимает — нужен `resourcecompiler` из Dota 2 Workshop Tools или CS2 Workshop Tools.

## Чем собирают моды (гайды deadlockmodding.pages.dev, прочитаны 27.10)
- **CSDK 12** — набор сообщества: файлы CS2 Workshop Tools плюс правки под Deadlock.
  - Ставить CS2 или Доту не нужно: «Reduced CSDK 12» качается архивом с Google Drive (ссылка на странице `modding-tools/csdk-12`).
  - Не ставить в папки с OneDrive: «Рабочий стол» и «Документы».
  - Запуск — `csdkcfg.exe` → «Create New Addon» (имя строчными, без пробелов) → «Launch Tools». Steam должен быть запущен.
  - Исходники мода — `content/citadel_addons/<имя>`, собранное — `game/citadel_addons/<имя>`.
  - У аддона есть «Compile All Assets» и «Create VPK».
  - **Panorama (разметка и скрипты HUD)** собирается в режиме `bin_server`. Для него нужны полные файлы игры:
    - скачать двумя командами DepotDownloader (нужен свой Deadlock в Steam);
    - распаковать `pak01_dir.vpk` через Source 2 Viewer;
    - всё описано на той же странице.
- **Упаковка в VPK:** CS2 Workshop Manager → New → Submit. Отправка падает, но VPK появляется в `game/citadel_addons`. Его переименовать в `pak##_dir.vpk`.
- **Установка мода:**
  - в `game/citadel/gameinfo.gi` в `SearchPaths` должна быть строка `Game citadel/addons`, DMM ставит её сам;
  - мод — `game/citadel/addons/pak##_dir.vpk`, где ## от 01 до 99, меньший номер главнее;
  - сломал `gameinfo.gi` — «Проверить целостность файлов» в Steam.
- **Modlock** (github.com/paralin/modlock, MIT):
  - `modlock panorama compile DIR` собирает `.xml` и `.js` из `DIR/panorama/` в VPK без Valve и без игры;
  - CSS — только компилятором Valve: стили задаём кодом;
  - ещё умеет `vpk unpack/pack`, `panorama decompile`;
  - формат (по коду): `.vjs_c` = блок RED2 (метаданные, KV3) + DATA (текст скрипта как есть), `.vxml_c` = RED2 + DATA (CRC исходника) + LaCo (дерево разметки в KV3).
- DeadPacker (github.com/Artemon121/DeadPacker) — автоматизация упаковки; Source 2 Viewer — VPK из папки; пример конвейера — github.com/mntbliss/Deadlock-QoL-HUD-Mod.
- **Вывод для пробника:**
  - Доту и CS2 качать не нужно;
  - самый короткий путь — собрать здесь, в облаке, Modlock-ом или своим сборщиком по его формату, и прислать Андрею готовый `pak##_dir.vpk`;
  - путь через CSDK 12 у Андрея — запасной: архив, DepotDownloader, распаковка, долго.

## 29.10 — QoL Lite и QoL Lock 4.0.5 от Андрея: что берём
Андрей прислал оба мода и 30 скринов окна настроек QoL Lock: «QoL Lite — больше нравится, как всё расставлено; QoL Lock — больше настроек». Файлы модов и скрины в репо не кладём: это чужие моды, репо публичный (выкладывать чужой мод нельзя), скрины конкурентов — только в архиве Андрея. Здесь — что из них следует.

**Решение для Restless:** расстановка элементов на экране — как у QoL Lite, настройки — как у QoL Lock.

**QoL Lite (678180, один VPK, 157 файлов)**
- Своего окна настроек нет. Настройки идут через UMM (отдельное меню модов, `qollite_*_umm_adapter`).
- Скрипты — `qollite_*`:
  - карта (`map_*`: урна, точки интереса, мини-карта);
  - уведомления о событиях по часам матча (`notifications_*`);
  - ранги друзей;
  - Mercurial Magnum;
  - авто-похвала, «кто замьючен», недавние покупки, быстрые покупки.
- Подменяет стили HUD: `hud`, `citadel_hud_top_bar`, `citadel_hud_hero_shop`, `hud_minimap`, `hud_abilities` / `hud_ability_icon`, `hud_quickbuy`, `hud_escape_menu`, `dashboard`, профиль, экран после матча. Подменяет разметку: `citadel_hud_top_bar_player`, `hud_escape_menu`, `citadel_hud_hero_shop`, `hud_quickbuy`, экран после матча.
- Что именно передвинуто, по файлам точно не понять: при пересборке стили меняют вид, и разница с игровыми файлами огромная (тысячи строк). Нужны скрины Андрея: один и тот же экран матча с QoL Lite и без него.

**QoL Lock 4.0.5 (650634, 2266 файлов) — как устроено окно настроек (по 30 скринам)**
- **Шапка:** «QOL LOCK by moglock.gg», поиск по настройкам, ✕.
- **Слева разделы** — две группы:
  - GENERAL: Поддержка, Настройки, Пресеты, Консоль, Аркада;
  - GAMEPLAY: Прицел, Полоса здоровья, HUD, Оверлей, Миникарта, Магазин, Аудио.
- **Внизу слева:** Discord, Save, номер версии.
- **У каждого элемента одинаковый набор:** переключатель; под ним мелкие переключатели и галки («Расширенный», фильтры); ползунки с полем для числа — прозрачность, масштаб, сдвиг по горизонтали, сдвиг по вертикали; палитра 3×10 цветов. Подсказка при наведении: что делает и «FPS impact: LOW».
- **«Настройки»:**
  - «Предварительный просмотр изменений», «Проверка обновлений», язык (есть русский), тема (Default / Emo / Midnight / Ocean / … / Cream / Psycho);
  - **экспорт и импорт настроек одной строкой** (`[QOL-4-0-5]:…`);
  - экраны 16:10, 4:3, 21:9 для стримов;
  - «Игра и интерфейс»: линия с пати, меню Esc по центру, друзья по центру, минималистичная пауза, тестовые инструменты, Behavior Summary.
- **HUD:**
  - верхняя панель: карта строений, таймер мид-босса, бафф на мосту, разница урн, таймер разлома, «пропавшие герои», ники, урон по строениям, **КД ультов**, фон панели, ранги игроков, предупреждение о HP врагов и союзников 25 / 65 / 75 %;
  - нижняя панель: подсказки, способности, активные предметы — масштаб и сдвиг;
  - предметы, души, таймер незащищённых душ, чат, отчёт об уроне, статистика игрока (слева / справа, прятать в обычном виде и на табло).
- **Прицел:** патроны, перезарядка, прицел предметов, КД предметов (фильтры: защитные / атакующие, пассивные / активные), активные статы, эффект урона, выносливость, числа урона.
- **Полоса здоровья:** индикатор боя, цвет при 25 / 65 / 75 %, тип, размер, цвет.
- **Миникарта:** минимализм, отражение, размер, цвета значков; дополнения — отметки высоты, таймер баффа на мосту, таймер мид-босса, ящики, туннели Рэма; Alt / Tab-зум.
- **Магазин:** быстрая покупка, недавние покупки, уведомления о покупках, вид магазина (статы, герой, минимализм, размытие, сдвиги).
- **Оверлей:** ID сборки, клавиатура, буст на канате, скорость, компас.
- **Консоль:** хитмаркеры, параметры миникарты, FPS / тики / память.
- **Аркада:** мини-игры при смерти.

**Технические выводы для нашего мода**
- **Видимое число КД ульты.** QoL Lock держит скрытую подпись `{i:ult_cooldown}` внутри `UltimateStatusBG` (как у нас), а **видимое число — отдельной подписью рядом, в `StatusRow`** (`UltimateCooldownTextShown`), не внутри `UltimateStatus`. У Андрея наших чисел не видно (скрины 29.10). Скорее всего, поэтому: `UltimateStatus` в этом виде панели свёрнут или обрезан. В 0.11 ставить своё число в `StatusRow`.
- **Не дублировать QoL Lock:** у Андрея там включены «Кулдауны ультов». Нашли в панели игрока `UltimateCooldownTextShown` — своё число не показываем.
- **Конфликты файлов:** оба мода подменяют разметку `hud_escape_menu` и `citadel_hud_top_bar_player`. Наш мод с 0.9 тоже везёт свою `hud_escape_menu.xml` — останется чья-то одна. Кнопку RESTLESS ставит скрипт из `citadel_hud_subtitles` / `hud_movement_speed`, которые не трогают ни Lite, ни Lock. Поэтому свою копию `hud_escape_menu` в 0.11 можно убрать.
- **DMM у Андрея** (`.dmm.json` в архиве): включён QoL Lock (650634); наш старый локальный `pak42` от 27.10 (22 КБ) в DMM выключен. Версию 0.10 он ставил руками в `addons`.
- **Настройки Restless — как у QoL Lock:**
  - разделы слева, поиск;
  - у элемента переключатель + прозрачность / масштаб / сдвиги + цвет;
  - экспорт / импорт строкой;
  - русский и английский;
  - подсказка «что делает».

  Где хранить настройки после выхода из игры: у QoL Lock — встроенная страница (`CitadelHTMLPanel`, localStorage на github.io), см. выше.
