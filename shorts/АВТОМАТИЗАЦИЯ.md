# Ролики на автомате — план «за копейку» (09.11)

## Что уже само (одна команда)
`./make6.sh nicw2-ru` — из текста и сцен:
- тайминг по фразам;
- звуки по событиям: что появилось на экране, то и щёлкнуло (`cue()` в сценах → `cues.json` → `sfxlib.py`);
- музыка: своя синтезом (`audio.py`, стиль на ролик) или трек Андрея (`MUSIC=трек.mp3` / `music/<ролик>.mp3`);
- сведение −14 LUFS, mp4 1080×1920 и сжатая копия.

Голос пришёл → `python3 voice.py <ролик> --audio файл.mp3 && VOICE=1 ./make6.sh <ролик>` — всё встанет под запись.

## Что делает человек сейчас
| Шаг | Кто | Сколько |
|---|---|---|
| Тема, текст, факты с источниками | Claude | 10–20 мин |
| Сцены (рисовка кодом) | Claude | 1–2 ч на новую тему |
| Голос | Андрей в ElevenLabs руками | 5 мин |
| Публикация | Андрей | 1 мин |

Сцены — самое дорогое. Чем больше готовых предметов и фонов (`v5.js`, `v6.js`), тем быстрее: никотин ×3 уже собран из одних и тех же деталей.

## Как поставить на автомат
1. **Голос — ElevenLabs по API.** Тариф Starter $5/мес ≈ 30 000 знаков ≈ 30 роликов → ~15 ₽ за ролик.
   - Андрей один раз: выбирает голос и вводит ключ API в защищённую форму окружения (в чат ключ не писать).
   - Дальше `eleven.py` сам отправляет текст и забирает mp3.
2. **Музыка.**
   - Бесплатно — мой синтез.
   - Лучше — Андрей один раз делает 5–10 треков разного настроения и кладёт в `music/`; ролик берёт трек по настроению.
   - Права: только треки, которые можно монетизировать в TikTok.
3. **Темы и сцены — задача по расписанию в Claude Code (облако).** Раз в день:
   - берёт следующую тему из `темы.md`, пишет текст с источниками;
   - собирает сцены из готовых деталей и сам проверяет кадры склейкой;
   - рендерит, озвучивает через API;
   - присылает Андрею mp4 + описание.

   Стоимость — в рамках подписки Claude, отдельно не платится. Через API вышло бы ~$1–3 за ролик.
4. **Публикация.** API TikTok для автопостинга требует проверки приложения — долго. Проще: ролик приходит Андрею в Telegram, он жмёт «опубликовать» (1 минута).

## Что нужно от Андрея один раз
- Выбрать формат из трёх версий (шизо / улучшенный / одна камера) — под него точу детали.
- Голос в ElevenLabs + ключ API (через форму окружения).
- 5–10 треков музыки (или «оставь синтез»).
- Список тем на месяц (или «бери сам»).
