# Тест графики «Духless» — опенинг 3 с (25.11)

ТЗ Андрея: 5 кадров за 3 с, 1080×1920, 30 к/с, полуреализм кодом (свет, объём, зерно, виньетка, глубина резкости, ручная камера, инерция, размытие движения), склейки — только жёсткие, шторка или свист. Звук — только сухие эффекты, без музыки.

| Кадр | Время | Что |
|---|---|---|
| 1 | 0,00–0,45 | защёлка кабинки: на 0,16 ручка на 90°, окошко белое → красное, щелчок |
| 2 | 0,45–1,05 | дорожка на чёрном стекле, рука с купюрой-трубкой, вдох |
| 3 | 1,05–1,90 | коридор в контровом свете, табличка 52R45, выход из двери, рука к носу, плечо закрывает кадр |
| 4 | 1,90–2,50 | удар света, белый стеклянный офис, полёт за героем, свист |
| 5 | 2,50–3,00 | голландский угол −6°, папка в стол, листы взлетают |

Файлы:
- `index.html` — всё рисование: `window.R(t)` — опенинг, `window.RC(t)` — две фотки каруселью (свайпы на 2-й и 4-й доле при 123 BPM, ровно по кадрам 29 и 59) → опенинг;
- `render.mjs` — кадры в PNG (Playwright): `node render.mjs shots <папка> 0.2,1.5,…` или `node render.mjs video <папка> R|RC [секунды] [fps]`;
- `sfx.py` — сухие звуки синтезом: `python3 sfx.py out.wav` (опенинг) или `python3 sfx.py out.wav rc` (с каруселью, сдвиг 59/30 с).

Фото карусели — `_media/p1.webp` (с собакой, «Zara drip»), `_media/p2.webp` (гардероб, «Money drip»); в git нет, как и кадры и ролики.

Сборка:
```bash
node render.mjs video ../../out/dl_open/full R 3 30
python3 sfx.py ../../out/dl_open/sfx.wav
ffmpeg -framerate 30 -i ../../out/dl_open/full/f%04d.png -i ../../out/dl_open/sfx.wav -c:v libx264 -crf 16 -preset slow -pix_fmt yuv420p -c:a aac -b:a 192k -shortest opening.mp4
```
Версия с каруселью: кадры `RC` с 0 по 58, дальше — кадры опенинга с 0 (кадр 59 карусели = кадр 0 опенинга).

90 кадров считаются ≈ 10 мин на 4 ядрах: на быстрых движениях до 22 подкадров на кадр.
