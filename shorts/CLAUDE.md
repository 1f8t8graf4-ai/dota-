# shorts/ — ролики: правила и где что

Подгружается сам, когда работа идёт в `shorts/`. Жёсткие правила ядра (`/CLAUDE.md`) главнее всего здесь.

## Правила роликов

- **Без «го» не начинать** ни черновик, ни рендер, ни голос. ТЗ Gemini или другой нейронки — не «го».
- **Платное только с «да»:** голос ElevenLabs, музыка, звуки, генерация картинок. Перед «да» — сколько кредитов уйдёт.
- **Картинка кодом:**
  - canvas / SVG, «чистый 2.5D» — перспектива, свет, тени, глубина резкости;
  - **Three.js — нельзя**;
  - HUD как у «Династии» — можно: тонкая строка «• место • год», часы, полоса глав;
  - **руки и пальцы людей не рисовать** — «руки-картошки» в реализме нельзя: предмет без руки уходит за край кадра.
- **В git не класть:** видео, стоки, кадры фильмов, чужие расшифровки, портреты актёров — репо публичное. Ассеты — в папке `P10A` вне репо.
- **Факты в тексте — только проверенные**, с источником. «Натяжки ради драматургии не правим» и «на YouTube в голосе можно» — решения Андрея от 12.11, только по его слову.
- **Тексты:**
  - без конструкции «не X, а Y»;
  - крючок в первые 2–3 секунды;
  - меньше устройства, больше ощущений.
- **Звук без тишины:**
  - речь 87–93 % времени, паузы не длиннее 0,5–0,9 с;
  - под голосом всё время фон или музыка;
  - −14 LUFS для TikTok и YouTube. Сведение — `tools/video/sfx_mix.py`.
- **Музыка из трендов** — Андрей ставит сам в TikTok при загрузке (10–15 %). В файл её не вшиваем.
  - YouTube-версия с музыкой — до 59 с, иначе Content ID блокирует.
- **Голос героя из фильма — можно** (решение 24.11): EN — оригинал, DE — дубляж, RU — известная озвучка.
- **Шортсы отдавать без пережатия** — `video.mp4` как есть, 1080×1920, 30 к/с.
- **Грабли кода:** комментарий `//` посреди строки съедает код до конца строки (было много раз). Комментарий — только в самом конце строки. После правок — скан добавленных строк `git diff`.

## Как делать ролик (конвейер)

1. Сценарий и факты → «го» Андрея.
2. Картинка кодом: `shorts/proba/p10/` (`render.mjs`, набор 2.5D — `dlx5a.js`). Приёмы — `docs/visual_patterns.md`.
3. Звук: звуки — `tools/video/sfx_fetch.py` → `sfx/`; сведение — `tools/video/sfx_mix.py` (`cues.json`, приседание под голос, −14 LUFS).
4. Проверка: `tools/video/critic/critic.sh ролик.mp4`, затем свежий агент-критик — `docs/critic.md`.
5. Отдать Андрею файлом; журнал ролика — в `shorts/log/<ролик>.md`.

Шпаргалка по всем скриптам — `tools/video/README.md`.
