# Своя музыка к роликам
Положи трек сюда под именем ролика — `nicw1.mp3`, `nicw2.mp3`, `nicw3.mp3` (подойдут mp3, wav, m4a) — и запусти `./make6.sh <ролик>-ru`.
Трек сам зациклится до длины ролика, в начале и конце — плавно (у nicw3 конец без затухания: ролик-петля).
Разово для одного запуска: `MUSIC=путь/к/треку.mp3 ./make6.sh nicw2-ru`.
Только треки, которые можно монетизировать в TikTok (свои или с такой лицензией).
