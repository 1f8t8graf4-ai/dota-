# Рендер 3D-ролика на ПК с видеокартой

Файл для Claude, запущенного на ПК Андрея (Windows, локально).
- Облачный Claude пишет код 3D-ролика: `shorts/ep/v166/`.
- В облаке нет видеокарты, ролик рендерится там ~2 часа.
- На видеокарте ПК — минуты.

Андрей не программист: всё делаешь сам. Ему пишешь коротко: что вышло и где файл.

## Что получится
- `shorts\out\v166a-ru\video-zvuk.mp4` — 3D-ролик 1080×1920, 105,8 с, со звуком пробы А.
- Копия на Рабочем столе: `3D-ролик.mp4`.

## 1. Где работать
- Папка `C:\render` — без русских букв и пробелов, не в OneDrive.
- Репо: `git clone https://github.com/1f8t8graf4-ai/dota-.git C:/render/dota-`. Если уже склонировано — `git -C C:/render/dota- pull`.
- Ничего не коммить и не пушить: рендер только читает репо.

## 2. Что поставить (один раз)
Проверь `node -v`, `git --version`, `ffmpeg -version`. Чего нет — поставь:
- `winget install -e --id OpenJS.NodeJS.LTS`
- `winget install -e --id Git.Git`
- `winget install -e --id Gyan.FFmpeg`

Новые программы видны только в новом терминале. Если `ffmpeg` всё равно не находится — укажи путь к нему в `FFMPEG=<полный путь к ffmpeg.exe>`. winget кладёт его в `%LOCALAPPDATA%\Microsoft\WinGet\Packages\Gyan.FFmpeg_*\ffmpeg-*\bin\`.

В папке `C:\render\dota-\shorts`:
- `npm install playwright@1.63.0`
- `npx playwright install chromium` — качает браузер, ~200 МБ.

## 3. Проверка видеокарты
`GPU=1 node capture.mjs v166a-ru gpu`

Скрипт пишет, на чём рисует WebGL и сколько секунд уходит на кадр.
- В строке «WebGL рисует» есть NVIDIA, RTX или Radeon — видюха работает, иди к шагу 4.
- Там SwiftShader («программно») — повтори с `GPU=1 CH=chromium` (полный Chromium вместо облегчённого).
- Опять SwiftShader — `GPU=1 HEADFUL=1`. Откроется окно браузера: не закрывать и не сворачивать до конца рендера.

Рендери тем вариантом, на котором заработала видюха.

## 4. Звук
- Нужен звук пробы А: файл `звук-A.m4a`. Андрей скачивает его из чата, обычно в «Загрузки».
- Нет его — подойдёт `Проба-A.mp4`: в нём тот же звук.
- Музыку в репо не класть: трек чужой.

## 5. Рендер
`GPU=1 AUDIO="$USERPROFILE/Downloads/звук-A.m4a" node capture.mjs v166a-ru video 30 4`
- Если в шаге 3 видюха заработала с `CH=chromium` или `HEADFUL=1` — добавь то же самое.
- С `HEADFUL=1` — одна вкладка: `… video 30 1`.
- В конце скрипт пишет «Готово со звуком: …video-zvuk.mp4».

## 6. Проверка
- `ffprobe -v error -count_frames -select_streams v -show_entries stream=width,height,nb_read_frames -of csv=p=0 out/v166a-ru/video-zvuk.mp4` → `1080,1920,3174`.
- В выводе не должно быть строки «ОШИБКИ:». Если есть — перепиши их Андрею, он передаст облачному Claude.
- Глянь три кадра: `GPU=1 node capture.mjs v166a-ru shots 10,50,95` (с теми же `CH` / `HEADFUL`) → `out/v166a-ru/shots/`.
- Скопируй ролик на Рабочий стол как `3D-ролик.mp4`.
