## 2. Фильм на YouTube — по шагам

Порядок на каждом канале: **сначала фильм, потом Часть 1** (шортс ссылается на фильм).

### Информация
- **Название** — и сразу «A/B-тестирование» → «Только название», два варианта (YouTube сам оставит лучший; пока идёт тест — не трогать):
  - EN: `Why You Can't Quit Smoking (It's Not an Accident)` / `Why You Can't Quit Nicotine (It's Not an Accident)`.
  - DE: `Warum du nicht mit dem Rauchen aufhören kannst (Kein Zufall)` / `Warum du nicht von Nikotin loskommst (Kein Zufall)`.
  - RU: `Почему вы не можете бросить курить (и это не случайность)` / `Почему вы не можете бросить никотин (и это не случайность)`.
- **Описание** — из `описания-YouTube-24.11.md`, без строки Instagram. В DE хэштеги: `#NightFabel #Nikotin #Vapes #Rauchen`.
- **Значок** — «Загрузить файл» → `YouTube_<ЯЗЫК>_3840x2160.jpg` (раздел 4).
- **Плейлисты** — пропустить.
- **Аудитория** — «Нет, это видео не для детей». **Возрастные ограничения** — не ставить (режут рекомендации).
- **Прямая реклама** — «Нет». **Сотрудничество с брендами**, **Коллаборация** — пропустить.
- **Использование ИИ** — «Нет»: голос сделан ИИ, но не выдаёт себя за реального человека, картинка рисованная — ни один из 4 пунктов YouTube не подходит.
- **Автоматическая разбивка на эпизоды** — оставить (возьмёт главы из описания). **Места**, **Объяснение понятий** — выключить.
- **Теги:**
  - EN: `nicotine, vaping, vape, juul, iqos, snus, zyn, nicotine pouches, disposable vape, marlboro, philip morris, tobacco industry, nicotine salt, documentary, why you can't quit`
  - DE: `Nikotin, Rauchen aufhören, Vape, E-Zigarette, Einweg Vape, Juul, IQOS, Snus, Zyn, Nikotinbeutel, Marlboro, Philip Morris, Tabakindustrie, Nikotinsalz, Doku, Dokumentation`
  - RU: `никотин, бросить курить, вейп, одноразка, электронная сигарета, джул, айкос, снюс, никотиновые пакетики, мальборо, филип моррис, табачные компании, солевой никотин, документальный фильм`
- **Язык видео** — язык канала. **Причина отсутствия субтитров** — не важно.
- **Лицензия** — стандартная; **встраивание** и **фид подписок** — галочки.
- **Ремиксы Shorts** — «Разрешить ремиксы с видео и аудио» (бесплатная реклама).
- **Категория** — «Образование». **Комментарии** — включены, модерация «Базовая», «Все», «Сначала интересные», лайки показывать.

### Дополнения
- **Субтитры** → «Загрузить файл» → «С временными метками» → `<ЯЗЫК>_Film_16x9.srt`.
- **Конечная заставка** — пока на канале один ролик, пропустить («Отменить изменения»): YouTube требует хотя бы один ролик или плейлист. Когда будет второй — «Подписаться» + «Видео → Самое новое загруженное».

### Доступ
- «Открытый доступ», **без премьеры** (премьера нужна, когда есть подписчики), «Опубликовать» сразу. Час публикации у нового канала почти не влияет.

## 3. Шортсы на YouTube

- Шортсом YouTube считает сам: вертикальное и короче 3 минут. Видно по ссылке `youtube.com/shorts/…`.
- **По одной части в день, первой — Часть 1.** Части 2–5 — «Доступ» → запланировать: EN — 18:00 по Нью-Йорку, DE — 18:00 по Берлину, RU — 19:00 по Москве.
- **«Похожие видео» (шаг «Дополнения») = фильм этого канала.** Это главное: под шортсом кнопка на полный фильм. Если на шаге нет — после публикации: Контент → Shorts → шортс → «Видео по теме»; или с телефона: шортс → ⋮ → «Изменить».
- Субтитры не добавлять — вшиты. Значок — можно `Cover_Part1_*.jpg` для Части 1, остальные — не обязательно.
- Теги — почти ничего не дают; можно короткий набор (DE: `Nikotin, Rauchen, Vape, Einweg Vape, Juul, IQOS, Snus, Zyn, Doku`).

## 4. Превью (значок) фильма — грабли

- Исходник Андрея — картинка из генератора 1024×572. Её апскейл: `esr.py` (Real-ESRGAN anime 6B на numpy, без torch; веса `RealESRGAN_x4plus_anime_6B.pth` — релиз `xinntao/Real-ESRGAN` v0.2.2.4 на GitHub, в git не кладём). Потом `yt_thumb_prep.py` → JPG.
  ```
  OMP_NUM_THREADS=2 python3 esr.py anime6b.pth вход.png x4.png 192 16
  python3 yt_thumb_prep.py x4.png YouTube_EN
  ```
- **Грузить JPG 3840×2160 < 2 МБ, не PNG.** PNG 4K весил 2,45 МБ — больше лимита YouTube на значок (2 МБ). JPG без прореживания цвета (`subsampling=0`) — тонкий красный текст на тёмно-синем не мылится после пережатия.
- **В окне студии значок всегда мутный** (маленькая пережатая копия + тень плеера) — это не то, что видят зрители. Проверка настоящего: после публикации скачать `https://i.ytimg.com/vi/<ID>/maxresdefault.jpg` (1280×720) и сравнить с файлом. 24.11 у EN разница с нашим файлом — 1,7 из 255 в среднем, т. е. то же самое.
- **«Качество: HD» в студии при 2560×1440 — нормально.** Значка «2K» у YouTube нет (только SD / HD / 4K). «Обработка завершена» = 1440p готов; проверить — ⚙ → «Качество» → 1440p.
- Варианты значка из кадров фильма (если A/B-тест значков): `yt_cover16x9.mjs` — «THE SAME PEOPLE» (пятёрка продуктов), «THEY PLANNED IT IN 1973» (записка R.J. Reynolds), «WHO'S BEHIND IT?» (змея вокруг башен). Андрей пока оставил свой значок.

## 5. TikTok (веб-версия на ПК)

- **«Turn on automatic content checks?» — Turn on.** «Content check lite» до публикации покажет, не заглушат ли музыку (у нас «No issues found»).
- **Description** — стереть имя файла и вставить:
  - EN: `Part 1/5: why your vape hits so hard 🧪 Full film on YouTube: NightFabel #nicotine #vape #vaping #juul #disposablevape #documentary #fyp`
  - DE: `Teil 1/5: Warum Einweg-Vapes so reinhauen 🧪 Ganzer Film auf YouTube: NightFabel · Geschichten #nikotin #vape #einwegvape #juul #doku #fyp`
  - RU: `Часть 1/5: почему одноразка так вставляет 🧪 Полный фильм на YouTube: NightFabel · Истории #никотин #вейп #одноразка #джул #документалка #рек`
  - Части 2–5: название шортса без `#shorts`, спереди «Part N/5:», в конце «Full film on YouTube…» и хэштеги.
- **Грабли:** автодополнение хэштегов склеивает слова (`#documentary tary #fy`) — допечатать слово и сразу пробел, проверить перед Post.
- **Cover** → «Edit cover» → загрузить `Cover_Part1_<ЯЗЫК>.jpg` (первый кадр шортса — красный фон, по нему не понять, о чём).
- **Location** — пусто. **Who can see** — Everyone. **High-quality uploads** — вкл.
- **Show more** — комментарии, дуэты, стичи разрешить; «AI-generated content» не включать.
- **When to post** — Часть 1 «Now», 2–5 «Schedule» по одной в день (вечер страны канала).
- Ссылка в профиле TikTok — только с 1000 подписчиков, поэтому «Full film on YouTube» — словами.
- TikTok сначала показывает ролик людям рядом с телефоном/IP: английские части из Германии первыми увидят немцы.
- Если TikTok всё же заглушил музыку (Кашалот) — перезалить эту часть в `_calm` / `_ruhig` / `_tiho`.
- Музыка: в Shorts и TikTok — обычные версии с Кашалотом (решение Андрея: «в шортсах и тиктоке — бодрый»), спокойные — запас.

## 6. Обложки шортсов / TikTok — как сделать

`tt_cover.mjs` — вертикальная 1080×1920: сверху жёлтая плашка («PART 1 · DISPOSABLES»), крупно «WHAT DO YOU KNOW ABOUT NICOTINE?» (последнее слово жёлтым, Manrope 800 из `shorts/fonts`), снизу кадр из 16:9 фильма (там нет вшитых субтитров, а в шортсе на каждом кадре субтитр).

```
ffmpeg -ss 26.5 -i EN_Film_16x9_2560x1440.mp4 -frames:v 1 dir/f_en.png   # RU — 23 с, DE — 26.5 с (ряд одноразок, глава 1)
NODE_PATH=/opt/node-tools/node_modules node tt_cover.mjs dir en,ru,de   # → dir/Cover_Part1_EN.jpg …
```
- Текст — объект `T` в скрипте (тег и две строки, `<b>` — жёлтым). Для Частей 2–5 — свой кадр и свой текст.
- Текст стоит в центральной 3:4 зоне (y 255–600): его не режет сетка профиля TikTok и не закрывают кнопки ленты.
- `yt_cover16x9.mjs` — то же для 16:9 (кадры `row.png` 12 с, `memo.png` 117,5 с, `ring.png` 593,5 с из EN-фильма; для RU/DE — свои секунды по `film.json`).
