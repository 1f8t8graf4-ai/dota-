## Как устроено
- `scripts.py` — тексты (`S[ep][lang]`), разметка `{ПОКАЗ|как говорить}`, `*жёлтым`, `!красным`; ключ = сцена. `python3 scripts.py` считает слова и ищет шаблоны нейронки (`BAD`).
- `voice.py <ep-lang>` — голос: EN — Kokoro `af_heart` + время слов Vosk; RU — Piper `ru_RU-dmitri-medium` (MIT, датасет CC0; `pip install piper-tts`; модели `/home/user/wdyk/models/piper`), время слов по слогам. **Свой голос:** `python3 voice.py <ep-lang> --audio файл.mp3` — режет запись по паузам на фразы.
- `eleven.py` → `eleven/<ep>.txt` и `eleven/ВСЕ-ТЕКСТЫ.md` — тексты для ElevenLabs и описания к постам (≈ 1 000 знаков на ролик, 11 700 на все 12).
- `stage.html` + `lib.js` + `ep/<ep>.js` — картинка кодом, кадр = функция времени `render(t)`.
  - Стиль (по «Что вы знаете о Coca-Cola / Google / Apple», Соболеве, World of Tanks, МДК, Хованском — одна студия): палитра 4–5 цветов на ролик; **линия поверх сдвинутой заливки** (`ink`) — «печать мимо»; тени **растром точек** (`dots`); блики-чёрточки (`shine`); бумажное зерно и виньетка; линии рисуются (`line(d, k)`); **один предмет перетекает в другой** (`morph`: лист → сигарета → вейп, кристалл → кошка, O → 0, капля → вирус); табло с прокруткой цифр (`odo`); штампы; камера всегда чуть едет.
  - Сцена: `EP.D[ключ](t, S, T)`; `T.c('слово')` — когда слово прозвучало. Переходы `EP.tr`: `push`, `up`, `zoom`, `iris`, `wipe`, `fade`, `flash`, `cut` (стык, когда сцены сами продолжают друг друга).
  - `EP.over(t)` — поверх всех сцен: счётчик Макса (`nicstory`), часы (`mephnight`).
  - Персонаж по плечи — `bust()` (настроение, моргание, рот, пот), фигура целиком — `person()` (лучше не использовать крупно).
  - Субтитры по 1–3 слова, с обводкой (читаются на светлом и тёмном), текущее слово — цветом ролика.
- `audio.py <ep-lang>` — своя музыка (синтез), бит с поворота (`claim` / `TURN`), удары (`BOOM`), щелчки на выделенных словах, вжух на сменах сцен (`../snd/kino`, CC0), сведение `../tools/tt_audio.py`.
- `capture.mjs <ep-lang> shots t1,t2…` — пробные кадры; `… video 30 4` — видео в 4 вкладки.
- `make.sh <ep-lang> [voice]` — всё сразу → `out/<ep-lang>/final.mp4` + сжатая копия в `/home/user/wdyk/deliver2/`.

## Шрифты
`fonts/` — Manrope (субтитры, подписи), Oswald (цифры), Unbounded (заголовки), все с кириллицей, OFL (`@fontsource` из npm).

## Новый ролик
1. Текст в `scripts.py` (+ источники в шапке), `python3 scripts.py <ep-lang>` — нет ли шаблонов нейронки.
2. `python3 voice.py <ep-lang>`.
3. `ep/<ep>.js` по образцу: палитра `C`, сцены `D.<ключ>`, `window.EP`. Кадры — `capture.mjs … shots`, смотреть склейкой.
4. Тоника и поворот — `KEYS`, `TURN`, `BOOM` в `audio.py`. `./make.sh <ep-lang>`.

## Проверка кадров
- Важное — между y 260 и 1250; субтитры 1330–1500; ниже — интерфейс TikTok.
- Подписи `L('en', 'ru')` — в русской версии проверить длину (капс `cap()` широкий).
