Все 130 таймкодов сверены с кадрами роликов: каждый кусок показывает описанное.

- `bob130.json` — исходник списка. Поля:
  - `id`, `v` — номер и ролик;
  - `a`, `b` — начало и конец, с;
  - `tags` — ПЕРЕХОД / АНИМАЦИЯ / ХУД. ЭЛЕМЕНТ;
  - `n` — название;
  - `w` — что в кадре, `tech` — техника кода, `ours` — применение у нас;
  - `s` — оценка, `d` — E/M/H;
  - `hot` — 🔥 из списка;
  - `x` — пометка, например «УЖЕ ТЕСТИРУЕМ!».
- `make_clips.py` — нарезка в `out/bob_fx_clips/fx_NNN.mp4` и `out/fx130.json`:
  - клип — сам приём ±0,3 с;
  - x264 crf 20, preset slow, GOP 12, без звука;
  - путь к оригиналам — `REF` в начале файла или переменная `BOB_REF`.
- `thumbs2.py` — превью для каталога: самый детальный кадр приёма → `out/thumbs.jpg`, сетка 10×13.
- `build.py` — вставляет данные в `pult.tpl.html` → `out/pult_130_bob_fx.html`.
- `md130.py` — тот же список текстом для другого Claude → `BOB_130_TRANSITIONS_FOR_CLAUDE.md`.

Фильтры пульта:
- теги: ПЕРЕХОД, АНИМАЦИЯ, 🎨 ХУД. ЭЛЕМЕНТ — у приёма их может быть несколько;
- 🔥 Хочу;
- сложность;
- ролик.

Карточка приёма: «Что в кадре (покадрово)», «Техника кода (как повторить на Canvas)», «Применение у нас в ролике», штамп в ТЗ.

Публикация: страница + `thumbs.jpg` + клипы частями ≤ 60 МБ (`root` = папка `out`, `files` списком) на тот же адрес. Всего клипов около 200 МБ — лимит версии 256 МБ.

Отметки Андрея — база страницы, коллекция `fx`, doc id = номер приёма (`001`…):
- поля: `want` (🔥), `note`, `t`;
- нет документа — 🔥 берётся из списка (`hot`);
- нажал в пульте — сохраняется его выбор;
- читать: `ArtifactData list fx`.

Клип по номеру: `Artifact read` с `path` = `bob_fx_clips/fx_NNN.mp4`.
