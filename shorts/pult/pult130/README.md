Все 195 таймкодов сверены с кадрами роликов: каждый кусок показывает описанное. Во втором списке Gemini 10 раз описал то, чего в ролике нет (кофе сверху, прожектора ПВО, неоновая сетка, нити у рамок и т. п.): там взят ближайший настоящий момент, а в поле `x` — пометка «Gemini ошибся: …» (в пульте — ⚠ и жёлтая плашка).

- `bob195.json` — исходник списка (до 15.11 вечера — `bob130.json`). Поля:
  - `id`, `v` — номер и ролик;
  - `a`, `b` — начало и конец, с;
  - `tags` — ПЕРЕХОД / АНИМАЦИЯ / ХУД. ЭЛЕМЕНТ;
  - `n` — название;
  - `w` — что в кадре, `tech` — техника кода, `ours` — применение у нас;
  - `s` — оценка, `d` — E/M/H;
  - `hot` — 🔥 из списка;
  - `x` — пометка, например «УЖЕ ТЕСТИРУЕМ!» (🧪) или «Gemini ошибся: …» (⚠).
- `make_clips.py` — нарезка в `out/bob_fx_clips/fx_NNN.mp4` и `out/fx195.json` (`--only 131,132` — только эти):
  - клип — сам приём ±0,3 с;
  - x264 crf 20, preset slow, GOP 12, без звука;
  - путь к оригиналам — `REF` в начале файла или переменная `BOB_REF`.
- `thumbs2.py` — превью для каталога: самый детальный кадр приёма → `out/thumbs.jpg`, сетка 10 в ряд.
- `build.py` — вставляет данные в `pult.tpl.html` → `out/pult_195_bob_fx.html` (и размер спрайта превью).
- `md195.py` — тот же список текстом для другого Claude → `BOB_195_TRANSITIONS_FOR_CLAUDE.md`.

Фильтры пульта:
- теги: ПЕРЕХОД, АНИМАЦИЯ, 🎨 ХУД. ЭЛЕМЕНТ — у приёма их может быть несколько;
- 🔥 Хочу;
- 🆕 Новые 131–195;
- сложность;
- ролик.

Карточка приёма: «Что в кадре (покадрово)», «Техника кода (как повторить на Canvas)», «Применение у нас в ролике», штамп в ТЗ.

Публикация: страница + `thumbs.jpg` + клипы частями ≤ 60 МБ (`root` = папка `out`, `files` списком) на тот же адрес; старые клипы можно не передавать — они остаются. Всего клипов 252 МБ — лимит версии 256 МБ, новые приёмы сюда больше не влезут (нужна вторая страница или клипы покороче).

Отметки Андрея — база страницы, коллекция `fx`, doc id = номер приёма (`001`…):
- поля: `want` (🔥), `note`, `t`;
- нет документа — 🔥 берётся из списка (`hot`);
- нажал в пульте — сохраняется его выбор;
- читать: `ArtifactData list fx`.

Клип по номеру: `Artifact read` с `path` = `bob_fx_clips/fx_NNN.mp4`.
