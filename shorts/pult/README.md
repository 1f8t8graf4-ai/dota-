# Пульт v16.3 — сборка, проверка, публикация

Страница с выбором для Андрея: https://claude.ai/artifact/LvK8pmXj9YEK2DVvtjWngr (версия 8). Ответы — документ `answers/v16-3` в базе страницы (`ArtifactData list answers`); черновик — в браузере Андрея (`pult-v16-3-draft`).

## Файлы
- `data163.py` — вкладки и вопросы; `plot_data.py` — большие вопросы-карточки (фильм, шортсы, фраза на доске).
- `build163.py` — собирает `pult-v16-3.html` (кадры base64 внутри, ~1,7 МБ). В git НЕ кладём.
- `frames163.py` — кадры в `img/` из рендеров v16.2 (`shorts/out/v162*`, `/home/user/wdyk/deliver162/`). Рендеров в git нет.
- `tests/` — проверки: `check5.js` (вкладки, счётчики, «Советы», запоминание вкладки, без кода страницы), `check4.js` (чужой iframe с перехватом ссылок и по высоте содержимого).

## Как собрать и проверить
```
python3 frames163.py && python3 build163.py
cd tests && python3 wrap.py ../pult-v16-3.html T_new.html
python3 -m http.server 8090 --bind 127.0.0.1 &   # в tests/
(cd harness && python3 -m http.server 8091 --bind 127.0.0.1 &)
NODE_PATH=/opt/node-tools/node_modules node check5.js
NODE_PATH=/opt/node-tools/node_modules node check4.js   # нужен ещё T_old.html — любая прошлая версия
```
Числа в `check5.js` («Выбрано N из 42», «Горло 1/6») — поправить, если меняется число вопросов.

## Если рендеров нет (новая сессия)
Собрать заново нельзя — нет кадров. Тогда: `Artifact read` по ссылке (Андрей — «writer», страница сохранится файлом) → правки `edits` в этом файле → `Artifact publish` с тем же `url`.

## Грабли
- Никаких ссылок-якорей `<a href="#…">`: просмотрщик Claude их глотает — «вкладка не открывается». Вкладки — скрытые переключатели + подписи, раздел показывает CSS `:has()`, код только помогает.
- Номер версии — в шапке («версия N»): по скрину сразу видно, свежая ли страница.
- Классы `.pay`, `.toc`, `.seg` заняты — смотреть, не пересекаются ли новые.
- Сервер для тестов без `charset` даёт кашу вместо кириллицы — тесты ходят только через `wrap.py`.
