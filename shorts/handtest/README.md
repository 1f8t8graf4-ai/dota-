# Тест «передача папки в архив» (руки из референса)

Повтор сцены Google «ОТКРОЙ ГЛАЗА» 0:32,0–0:42,5 со стопкой «СОЛЬ 1979», 1080×1920, 30 к/с, 10,5 с. Видео — `test_hand_archive_1979.mp4`, отправлено Андрею 15.11.

Руки не нарисованы, а сняты с кадров (векторы по цветовым маскам OpenCV):
- 0:33,5 — рука №1 держит;
- 0:35,16 — рука №1 раскрытая;
- 0:36,5 — рука №2 с перстнями.

Тайминг — покадровый трек референса: стопка, обе руки, стол, папки, наклон камеры. В git только код: кадры и векторы рук собираются заново из оригинала (чужое видео).

Сборка, всё в одной рабочей папке:
1. Кадры референса: `ffmpeg -ss 32 -i google.mp4 -t 10.6 -vf fps=25 f25/%03d.png` — 001 = 32,00 с.
2. `python3 hand_vec.py` → `hands.json`, `check.png` (оригинал | вектор).
3. `python3 trackh.py h1` и `python3 trackh.py h2` → `trk_h1.json`, `trk_h2.json` — поза спрайта в каждом кадре (matchTemplate по маскам, угол перебором).
4. Треки стола, папок и стопки:
   - `python3 stack_rect.py` → `stack.json`;
   - `python3 meas.py` → `stack2.json`, полный угол по надписи;
   - `python3 table_slide.py` → `tableD.json`;
   - `python3 folder_x.py` → `folderX.json`.
5. `python3 tracks.py` → `test/tracks.json`, `test/data.js`:
   - треки 30 к/с;
   - камера 9:16 следует за стопкой, масштаб 1,12;
   - конец сцены — в координатах кадра.
6. Шрифты Manrope 600/800 — в `test/fonts/` (копия из `shorts/fonts`).
7. Проверка и рендер:
   - `node test/sheet.mjs 1.5,3,6 лист.jpg` — лист кадров;
   - `node test/render.mjs кадры` — 315 JPEG;
   - склейка: `ffmpeg -framerate 30 -i кадры/%04d.jpg -i sfx.wav -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac -shortest test_hand_archive_1979.mp4`.

Звук теста — наши эффекты из `shorts/sfx13`, `sfx16`, `sfx17`, `sfx8`.

Опубликовать точные обводки чужих рук — риск по авторским правам. Для ролика лучше перерисовать руки по этим векторам.
